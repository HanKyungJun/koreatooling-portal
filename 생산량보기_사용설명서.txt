재연마 NC 생산량 보기 — 사용 · 설치 메모
(2026-11-02 작성 · 한경준 개인용 · ERP 읽기 전용)

■ 실행
  - 창 프로그램 : 생산량보기.bat 더블클릭  (바탕화면 바로가기: 오른쪽 클릭 → 보내기 → 바탕 화면에 바로 가기 만들기)
  - 콘솔 화면   : 생산량확인.bat 더블클릭  (Enter 새로고침 · 날짜 입력 · s 요약/상세 · t 오늘 · q 끝)

■ 창 프로그램 사용법
  - F5 / 새로고침        : 빠른 조회. 지난 날 = 일일보고 저장본(매일 16:00), 오늘분만 ERP 에서 읽음 (10초 안팎 예상)
  - Shift+F5 / 전체 다시 읽기 : 이번 달 전체를 ERP 에서 다시 읽음 (1분 가까이). 숫자가 이상할 때 사용
  - ◀ 전날 · 다음날 ▶ · 오늘 · 날짜 칸에 YYYY-MM-DD 입력 후 Enter
  - 자동 갱신 없음 — F5 를 눌러야 새로 읽음
  - 탭 : 목록 · 형상 · 지름 · 코팅 · 시간 · 불량 · 기타
         기타 = 표준공수 DB 에 맞는 품목이 없어 추정 시간에서 빠진 줄
  - 열 머리 클릭 = 정렬 / 항상 위 = 창을 맨 위에 고정 / 표 복사 = 지금 보이는 표를 엑셀에 붙여넣기
  - 표시 : 분홍 줄 = 불량 있음 · 회색 글자 = 기타 · 시각 옆 * = 다음 날 이후 입력

■ 숫자 읽을 때 주의
  - 수량 = ERP 에 입력된 만큼만 (속보값). 작업 중인 날은 낮게 나옴
  - 추정 가공시간 = 표준공수 DB 중앙값(초/개) × 개수 → 추정값 · 참고용. 실제 가공시간 아님
  - 빠른 조회는 저장본 이후 지난 날짜에 늦게 입력된 실적이 빠질 수 있음 → 전체 다시 읽기
  - 시각 = 실적 시작 입력 시각(fr_tm). ERP 종료 시각은 대부분 20:00 고정이라 안 씀

■ 다른 PC 에 설치할 때
  1) Python 3.10 이상 설치 (설치 때 「Add python.exe to PATH」 체크)
  2) 명령 프롬프트에서:  pip install pandas openpyxl requests
  3) 아래 파일을 같은 폴더 구조로 복사
       생산량보기.bat · 생산량확인.bat
       scripts\today_output.py · scripts\today_output_gui.py
       erp\erp_worklog.py · erp\trico_client.py
       wiki\measurements\재연마_표준공수DB_2022-2026_통합본_20261023.xlsx   (없으면 추정 시간만 빠짐)
  4) 사내망에서 ERP 서버(주소는 erp/trico_client.py 의 SVC_URL) 접속되는지 확인 후 생산량보기.bat 실행
  - 다른 PC 는 일일보고 저장본이 안 생기므로 F5 도 매번 이번 달 전체 조회 (1분 가까이)

■ 다른 사람에게 공유할 때 (꼭 바꿀 것)
  - erp\trico_client.py 안 ERP 사용자 ID 가 한경준 계정으로 고정돼 있음
    → 그대로 주면 그 사람 조회가 한경준 이름으로 남음. 그 사람 계정으로 바꾸거나 계정 고르게 고쳐서 줄 것
  - 단가 열은 기본으로 막혀 있음 (조회만 · 저장 안 함)
  - 빠르게 쓰려면 일일보고 저장본(erp\snapshot\pw_nc_*.csv)을 공유 폴더에 두는 방법 필요
  - Python 설치가 번거로우면 exe 로 묶기 (erp\dist\TricoERP.exe 와 같은 PyInstaller 방식, 이 PC 에서 빌드)

■ 안 될 때
  - 「ERP 조회 실패」 창 : 사내망 · ERP 접속 확인 후 F5
  - 창이 아예 안 뜸 : 명령 프롬프트에서  python scripts\today_output_gui.py  실행 → 나오는 오류 확인
  - 「표준공수 DB 읽기 실패」 : 위 엑셀 파일 위치 확인 (수량은 정상)
