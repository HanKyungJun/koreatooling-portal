## 6. 조작 절차 (사내 SOP) ★★

> 신뢰도: 사내 경험값. 출처: [INT-TOOLKOREA-PRODMANUAL-2026] §6 MCT (p162~175)
> 조작 패널 구성: ①전원·위치 알림·에러 알림 ②모니터 ③키보드 ④제어패드 ⑤이송 핸들

### 6.1 전원 투입

1. 장비 후면 **주 전원 스위치**를 ON 방향으로 회전
2. 녹색 스위치로 전원 ON → 빨간 비상정지 버튼을 우측으로 돌려 해제
3. 부팅·프로그램 작동 확인 → **RESET** 버튼 클릭 → 경고등 비활성화 확인

### 6.2 원점 작동

1. `MODE SELECT`를 **ZERO RETURN**(3시 방향)으로 이동
2. 공작물 충돌 반경 확인 후 녹색 **CYCLE START** 클릭 → 원점 이동
3. 이동 완료 시 `STATUS` 하단 X, Y, Z **녹색 불 점등** = 원점 도착 확인

### 6.3 프로그램 조작

- 프로그램 코드 **O0010** 확인 → `MODE SELECT`를 **EDIT**(10시 방향)으로 이동
- 키패드로 `1`, `0` 입력 → `>10_` 확인 → **O 검색** 하단 버튼 클릭(스크린 터치 아님) → 상단 파랑 부분 또는 프로그램 O0010 확인

### 6.4 워밍업 (예열)

> 참고: 장비 내장 기능이 아니라 **워밍업 전용으로 제작된 서브프로그램 P0100**을 이용.

1. `PROG` 버튼 클릭
2. 프로그램 **O0010** 확인, 서브프로그램 **P0100** 확인(프로그램 화면 노란색 = 현재 위치)
3. `MODE SELECT`를 **AUTO**(11시 방향)로 이동 → 피삭재·공구 간섭 확인 후 **CYCLE START**
4. P0100이 아닌 경우 → P0100 위치로 이동 → P0100 입력 → 노랑색 위치 확인 → **ALTER** 클릭
