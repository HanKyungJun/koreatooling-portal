# FAST Wrist A — 에어호스 절단 수리 (2026-06-11)

## 1. 증상

| 항목 | 내용 |
|------|------|
| 장비 | FAST (Wrist A / Wrist Down 축) |
| 증상 | Wrist Down 동작 시 에어 방출 소음 크게 발생 |
| 최초 발견 | 2026-06-01 |
| 발생 빈도 | 매 작업마다 반복 |

## 2. 원인

- **에어호스 절단** — 4×0.75 mm 공압 호스 내부 절단 확인 (사내 경험값)
- Wrist 내부 호스 라인이 복잡하게 배선되어 있어 절단 부위가 육안으로 확인되지 않다가 소음으로 발견

## 3. 수리 이력

| 날짜 | 작업 내용 | 결과 |
|------|----------|------|
| 2026-06-01 | Wrist Down 동작 시 소음 발생 최초 확인 | 원인 미파악 |
| 2026-06-11 | 내부 확인 → 4×0.75 에어호스 절단 발견 | 원인 확정 |
| 2026-06-11 | 내부 호스 교체 시도 → 배선 복잡으로 중단 | 실패 |
| 2026-06-11 | **절단 후 4mm 원터치 피팅으로 연장 연결** | ✅ 완료 |

## 4. 수리 방법 (최종 채택)

**방법: 절단부 커팅 후 원터치 피팅 연결 (연장)**

사용 부품:
- **4mm 원터치 피팅 커넥터** (유공압 일자형 커넥터, 양방향 Push-in)
- 기존 4×0.75 mm 에어호스 (절단 후 재활용)

작업 순서:
1. 절단된 호스 양 끝을 깨끗하게 재절단 (버 제거)
2. 4mm 원터치 피팅에 양쪽 호스 삽입 → 원터치 고정
3. 에어 공급 후 누기 확인
4. Wrist Down 반복 동작으로 소음·작동 이상 최종 확인

> ⚠️ 주의: 피팅 연결 후 호스 인장 방향으로 빠짐 여부 반드시 확인. Wrist 가동 중 반복 굴곡이 발생하는 위치에 피팅이 있을 경우 주기적 점검 권장.

## 5. 결과

- **소음**: 이상 없음 ✅
- **작동**: 정상 ✅

## 6. 재발 방지

- 동일 증상(Wrist Down 소음) 재발 시 → 피팅 연결부 누기 먼저 점검
- FAST Wrist 내부 배선은 복잡하여 교체보다 **연장 커넥터 활용이 효율적**
- 정기 점검 시 Wrist A 호스 굴곡부 육안 확인 항목 추가 권장
