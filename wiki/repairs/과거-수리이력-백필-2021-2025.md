## 1. 소프트리밋 경고 (ALM 3521) — 2021-02-01 {#1}

> ⚠️ **폴더명과 실제 내용이 다릅니다.** 원본 폴더명은 `축 모터 고장 에러`이지만, 캡처 3장은 전부 **모터 고장이 아니라 소프트웨어 리밋(Soft Limit) 경고**입니다. 실제로 축 모터 고장이 함께 있었는지는 **확인 필요**.

| 항목 | 내용 |
|---|---|
| 발생 | 2021-02-01 08:21 → 08:24 → 08:25 (캡처 3장 시각) |
| 설비 | GX7 추정 — 바탕화면에 `GX7 801268 customer_de…` 파일 확인 [신뢰도: 추정값] |
| 경보 | **5DX SYSTEM PLC WARNING — Soft Limit Warning (ALM 3521)** |
| 메시지 | *"Joint 5 has received a request for an invalid soft limit."* |
| 실측값 | Actual Position **−91.124500** / Requested SLM **−117.000000** / Requested SLP **−116.000000** |
| 축 대응 | 좌표 화면에 **C −91.124** 표시 → **Joint 5 = C축**(회전축)으로 판단 [신뢰도: 실측 검증 — 동일 화면 좌표 일치] |
| 장비 안내 조치 | ①Ensure joint is clear to move ②Move joint to a safe position ③Clear message and press Reset |

**부수 관찰 — 08:21 첫 캡처는 메시지 본문이 아예 표시되지 않았습니다.**

```
A warning or error message needs to be displayed, but the text cannot be found.
The database key for the message was:
EP buffer is full. Some messages are lost.msg
```

경보 메시지 버퍼가 가득 차 원문을 못 띄운 상태입니다. 즉 **이 시점에 경보가 연속 다발**했을 가능성이 있습니다(추정).

**§확인 필요**: ①실제 축 모터 고장이 있었는지, 아니면 소프트리밋 경고만이었는지 ②원인(수동 조작 중 리밋 초과 / 파라미터 이상 / 홈 위치 소실) ③조치 내용과 재발 여부 ④설비가 GX7이 맞는지.

**참고**: C축 관련해서는 [[machines/anca-cnc-tool-grinder]]의 "C축 Travel 스캔 판독 불명" 이월 항목과 연결될 수 있습니다.
