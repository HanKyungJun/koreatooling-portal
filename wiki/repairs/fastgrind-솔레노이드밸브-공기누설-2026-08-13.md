## 3. 원인 진단 절차 — 누설 지점 특정

**⚠️ 작업 전 필수 안전조치**: 공압 메인 라인 공급 차단(공급 밸브 잠금) → 회로 내 잔압 배출(블리드) 확인 → 전원(24V DC) 차단·LOTO(잠금/표시) 적용 → 위 순서 확인 후에만 다음 진행.

1. **어느 유닛인지 먼저 특정**: COLLET 1 / COLLET 2 배선 태그를 육안으로 재확인하고, 실제 공기가 새는 쪽(청음·비눗물)을 먼저 좁힐 것.
2. **육안·청음 점검**: 밸브 본체 이음부, 포트 1·2·4번(QS-6 푸시인 피팅 결합부 — 피팅 슬리브 눌러 튜브 재체결 상태 확인), 포트 3·5번(G1/8 나사산), 수동 오버라이드, 전기 커넥터 결합부를 순서대로 확인.
3. **비눗물(soap solution) 테스트**: 압력 인가 상태에서 각 지점에 비눗물 분무 → 기포 발생 지점이 누설 지점. ([Festo Leakage diagnostics](https://www.festo.com/us/en/app/leakage-diagnostics.html) 참조 [신뢰도: 제조사 기준])
4. **지점별 원인 구분**:
   - **QS-6 푸시인 피팅부 누설** → 튜브를 피팅에 완전히 밀어 넣었는지 확인(원터치 피팅은 절반만 삽입돼도 겉보기엔 고정된 것처럼 보일 수 있음), 튜브 끝단 손상 시 재절단 후 재삽입. 그래도 새면 피팅 자체 손상(래칫 파손)일 수 있어 교체 필요.
   - **G1/8 나사산(포트 3·5) 누설** → 실테이프 재시공 또는 피팅 재체결.
   - **밸브 몸체 이음부/스풀 내부 누설(배기구 과다 배출 포함)** → CPE14 시리즈는 고정 실 구조로 설계되어 현장 분해·실(seal) 교체 절차가 문서화되어 있지 않음 — **밸브 전체 교체가 원칙**(신뢰도: 제조사 자료 기반 추정 — "수리 불가" 명시 문구까지 확인된 것은 아님, 확인 필요).
   - **수동 오버라이드 나사 누설** → 나사 재체결로 우선 시도, 지속 시 밸브 교체.
5. ✅ **본 건은 진단 완료** — 사용자 확인(2026-08-13)으로 **포트 1(공급, P)에서 "장치 내부"로 누설**임이 확정됨. 이는 위 세 유형 중 "밸브 몸체/스풀 내부 누설"에 해당 — QS-6 피팅 재체결·G1/8 실테이프 재시공 등 경미한 조치로는 해결되지 않는 유형이므로 **아래 §4 밸브 전체 교체로 바로 진행**.

## 4. 조치 절차 — 밸브 교체 (포트 1 내부 누설 확정 — 교체 확정)

1. 공압 공급 차단 + 잔압 배출 + 전원 차단 확인(§3 안전조치와 동일, 재확인).
2. 전기 커넥터 분리.
3. QS-6 푸시인 피팅(포트 1·2·4)과 G1/8 배관(포트 3·5) 분리 — 분리 전 각 포트 번호와 배관 위치를 사진으로 기록(재조립 시 오배관 방지). QS 피팅은 슬리브를 누른 상태로 튜브를 당겨 분리.
4. 마운팅 나사 제거 → 구 밸브 탈거.
5. 신품 장착 — **포트 번호(1·2·3·4·5)와 배관을 원래 위치와 동일하게 재연결**. 장착 방향은 제조사 기준 자유 방향(구속 없음).
6. 마운팅 나사 재체결 — ⚠️ 권장 체결 토크는 데이터시트에 명시되지 않음(확인 필요). 과다 토크 시 하우징(다이캐스트 알루미늄) 손상 우려.
7. 전기 커넥터 재연결.
8. **기능 테스트**: 전원 인가 전 수동 오버라이드로 먼저 공압 절환 동작 확인 → 이후 전원 인가하여 정상 신호 절환 확인.
9. §3의 비눗물 테스트를 재실시하여 신품 장착부에 누설이 없는지 재확인.
10. 정상 확인 후 콜렛 클램프 동작을 저속·수동 모드로 먼저 확인(척 클램프/언클램프 전 구간) — 클램프 계통은 공작물 파지와 직결되므로 오작동 시 가공 중 이탈 위험, 신중히 확인할 것.
