## 8. 용어집 (Glossary) — 핵심 약어

- **CNC** — Computer Numerical Control
- **MCT** — Machining Center
- **G-code** — Geometric/Preparatory code (ISO 6983 기준)
- **M-code** — Miscellaneous/Machine function code
- **STEP-NC** — STandard for Exchange of Product model data — Numerical Control (ISO 14649)
- **ATC** — Automatic Tool Changer
- **HRC** — Rockwell Hardness C scale (경도 단위)
- **Ra** — 산술평균 표면조도 (μm)
- **재연마 (Re-grinding)** — 마모된 공구를 다시 연삭해 수명을 연장하는 작업
- **GASH** — 절삭 홈 가공 (cnc-wiki/wiki/_handoff/context.md 정의)
- **휠 (Wheel)** — 공구 연삭에 사용하는 숫돌/연삭 휠
- **스택 (Stack)** — ANCA 등 연삭기에서 휠을 조합해 장착한 구성
- **ADR** — Architecture Decision Record
- **SSOT** — Single Source of Truth
