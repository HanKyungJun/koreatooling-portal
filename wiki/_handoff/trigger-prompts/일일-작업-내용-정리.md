### 0. 오늘 날짜는 KST 로 정한다 (2026-10-07 신설)

`device_bash` 에서 `TZ=Asia/Seoul date '+%F %a %H:%M'` 를 실행해 오늘 날짜·요일·작성 시각(KST)을 정합니다. 환경이 알려 주는 날짜(UTC)와 다르면 이 값을 따릅니다. 아래 「오늘」은 모두 이 KST 날짜입니다.

### 1. 데이터 수집

(1) `mcp__session_info__list_sessions` 도구가 있으면 오늘 세션 목록을 조회하고, 각 세션을 `mcp__session_info__read_transcript` 로 읽습니다.

(2) 🔴 **세션 조회 도구가 없거나 결과가 비어 있으면 빈 템플릿으로 끝내지 마세요.** 예약 실행에서는 이 도구가 보통 없습니다 — 2026-09-30 ~ 10-06 다섯 번 연속 「세션 데이터 접근 불가」 빈 리포트만 만들어졌습니다. 대신 로컬 폴더 `C:\Users\TOOLKOREA\Desktop\cnc-wiki` 를 `device_bash` 로 읽어 오늘 작업을 재구성합니다. `raw/cowork-daily-reports/2026-09-22.md` 가 이 방식으로 작성된 좋은 예시입니다.

- `wiki/_handoff/worklog.md` 맨 위부터 **오늘 날짜(`## YYYY-MM-DD`)로 시작하는 블록 전부** — 가장 중요한 근거
- `wiki/_handoff/decisions.md` 맨 위부터 **오늘 날짜 항목 전부**(제목 · 결정 · 영향 줄)
- `wiki/log.md` 의 오늘 날짜 항목
- `git --no-optional-locks log --since="<오늘> 00:00 +0900" --format='%ci %h %s'` — 오늘 커밋
- 오늘 수정된 파일: `find . -path ./.git -prune -o -type f -newermt '<오늘> 00:00 +0900' -printf '%TY-%Tm-%Td %TH:%TM %p\n'` — 🔴 출력 시각은 **UTC** 이므로 +9h 해서 KST 로 적습니다. `.bak_*` · `__pycache__` · `dist/` · `internal/` · `outputs/` · `raw/cowork-daily-reports/` 는 빼고 봅니다

🔴 git 규칙: git 명령에는 반드시 `--no-optional-locks` 를 붙이고 **읽기 명령(log·status·diff·show)만** 씁니다. `add`·`commit`·`push` 는 절대 하지 마세요 — `.git/index.lock` 이 남으면 16:00 정규 자동화의 push 가 조용히 실패합니다. `.git` 안의 파일은 건드리지 않습니다.

(3) 리포트 머리(작성 시각 줄 아래)에 **「작성 근거: 세션 조회」 또는 「작성 근거: 파일 재구성(worklog·decisions·log.md·git log·파일 수정시각)」** 을 한 줄로 밝힙니다.

(4) 위 자료 어디에도 오늘 기록이 없으면 본문은 **「오늘 기록된 작업 없음 — 휴무이거나 기록되지 않음」 한 줄**만 쓰고, 「확인 필요」로 채운 빈 섹션은 만들지 않습니다.

- 이모지 사용 금지
- 간결하고 명확한 문체 유지
