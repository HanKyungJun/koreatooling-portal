> 2026-09-21 개편: 「주간 위키 검수」를 폐지하고 그 lint 항목을 이 월초 점검의 ⑤로 옮겼습니다(빨간 링크·고아 페이지는 주 단위로 급변하지 않아 월 1회로 충분). 확인 필요 대장 재생성은 월요일 통합 브리핑이 맡습니다.

### ① 🔴 전월 일일보고 ↔ 원본 xls 전수 대조 (가장 중요)

**배경**: 2026-08-27 진단으로 확인된 구조적 문제 — `daily_report.py` 는 매일 **16:00** 에 원본 `raw/출하현황/재연마 작업일지(YYYY)/재연마_월간생산일지 (M월).xls` 를 읽는데, 현장에서 Excel 저장(Ctrl+S)이 그보다 늦어 **미완성 스냅샷이 일일보고로 굳어집니다.** 2026년 8월은 16건 중 **11건(69%)** 이 불일치했습니다.

**방침(2026-08-27 확정)**: 실행 시각은 **현행 16:00 유지**. `generate.py` 가 매 실행 원본을 전량 재파싱하므로 포털·누적 수치는 자연 치유되고, 영구 고정되는 것은 개별 일별 xlsx 뿐입니다. 그래서 **월초에 한 번 몰아서 확인**합니다.

**할 일**: `wiki/reports/daily/YYYY-MM-DD_일일보고.xlsx` 전월분 전체를 원본 xls 일자 시트와 대조해 불일치 목록(날짜 · 보고서값 · 원본값 · 차이)을 만드세요.

- **보고서 값이 실제보다 작은 경우** → 16:00 이후 작업분 누락. 소급 재생성 대상입니다.
- 🔴 **보고서 값이 실제보다 큰 경우** → 값이 나중에 줄어들 수는 없으므로 **별개 원인**입니다. **경위 확인 전에는 재생성하지 마세요** — 원본 쪽이 잘못 정정된 것이라면 맞는 값을 지우게 됩니다.

**소급 재생성은 2줄 세트로** (날짜 치환):
```
python scripts\daily_report.py YYYY-MM-DD
python scripts\update_calendar_artifact.py YYYY-MM-DD
```
⚠️ `daily_report.py` 단독 실행은 캘린더 아티팩트 체이닝이 걸리지 않습니다.

### ② 당월 작업일지 xls 존재 확인

`raw/출하현황/재연마 작업일지(YYYY)/재연마_월간생산일지 (M월).xls` 가 **당월분**으로 있는지 확인.
없으면 `find_xls()` 가 조용히 실패하고 **`generate.py` 까지 통째로 실행되지 않아 포털이 멈춥니다**(2026-08-05 실제 발생). 없으면 즉시 알리세요.

### ⑤ 위키 검수 (2026-09-21 「주간 검수」에서 이관)

`wiki-lint` 스킬을 쓰되, 없으면 아래를 직접 점검하세요.

1. **프론트매터 누락** — `wiki/` 하위 `.md` 중 `---` 로 시작하지 않는 문서
2. **출처 ID 미등재** — 본문의 `[XXX-YYY]` 인용 중 `wiki/_handoff/sources.md` 에 없는 것
3. **빨간 링크** — `[[페이지명]]` 중 실제 파일이 없는 것
4. **고아 페이지** — 어느 문서에서도 링크되지 않은 페이지

⚠️ `wiki/_handoff/` 와 아카이브 폴더(`decisions-archive/`·`worklog-archive/`)는 **검수 대상에서 제외**하세요 — 핸드오프 기록물이라 프론트매터·링크 규칙이 다릅니다.
⚠️ 검수 결과를 `worklog.md` 에 자동으로 쓰지 마세요. 한경준님이 원하시면 그때 기록합니다.
심각한 항목(빨간 링크·출처 미등재)이 5건 이상이면 목록을 보여주세요.

### ⑥ 전월 출하현황 반영 여부 확인 (2026-09-21 「월간 출하현황 마감 알림」에서 이관)

- 채워져 있으면 → 이미 처리됨. 넘어갑니다.
- 비어 있으면 → 한경준님께 **3~4문장으로** 안내: 반영하려면 TricoERP 에서 전월 「출하현황」 리포트를 export 한 xlsx 가 필요하다는 것, 진행을 원하시는지.
- 진행을 원하시면 `decisions.md` **2026-08-05 (3)** 항목을 먼저 읽어 그 방식(납품처명 그룹핑, 출고 = 출고합계 − 연마불가, 원본 합계행과 대조 검증)대로 처리하세요.

⚠️ 원하지 않으시면 더 진행하지 않습니다. 다음 달에 다시 묻습니다.
⚠️ `raw/` 는 읽기 전용입니다 — 업로드받은 파일을 `raw/` 에 쓰지 마세요.
