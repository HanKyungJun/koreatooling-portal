## ③ 자동화 상태

🔴 **git 명령은 반드시 `--no-optional-locks` 를 붙이세요. 이유가 있습니다.**
2026-09-03 이 점검의 캐치업 실행이 `git status` 를 그냥 돌려 `.git/index.lock` 을 남겼고, 한경준님 커밋이 `fatal: Unable to create index.lock` 으로 막혔습니다. 락이 남으면 **16:00 정규 자동화의 push도 조용히 실패**합니다.

- `wiki/reports/daily/generate.log` 마지막 30줄 — 이번 주 `[git] push` 실패가 있었는지
- `git --no-optional-locks log --oneline origin/main..HEAD` — 미푸시 커밋
- `git --no-optional-locks status --porcelain` — 커밋 안 된 변경

**③-b 잔여 락 점검 (신설)**

```bash
find .git -maxdepth 2 -name "*.lock" -printf '%p size=%s mtime(UTC)=%TF %TT\n'
```
- 아무것도 안 나오면 → 통과
- `index.lock` 이 나오면 → ⚠️ **경고로 올리세요.** 크기·생성시각(UTC이므로 **+9h 해서 KST로 환산**)을 함께 보고하고, 다음을 안내하세요:
  - **10분 이상 지난 0 byte 락은 껍데기**입니다. 다만 **직접 삭제하지 마세요** — 한경준님께 아래를 안내만 하세요.
  - `Get-Process git,git-remote-https -ErrorAction SilentlyContinue` 로 확인 → 비어 있으면 `Remove-Item .git\index.lock`
  - 결과가 나오면 삭제하지 말고 실제 실행 중인 작업을 먼저 확인
