# 프로젝트 컨텍스트 (cnc-wiki)

> 챗·Cowork·Code 어디서든 일을 시작하기 전에 이 파일을 먼저 읽습니다.
> 큰 그림이 바뀔 때 여기를 갱신합니다. (자주 바뀌어선 안 됨)

## 한 줄 정의

사내 CNC/MCT 가공·공구 연삭 노하우와 재연마/출하/KPI 운영 데이터를 모아 정리하는 지식 위키 및 자동화 작업 공간.

## 배경

- 누구를 위한 위키인가: TOOLKOREA 내부 작업자·관리자, 특히 재연마/공구 연삭/출하 현황을 확인하고 개선해야 하는 사람.
- 어떤 문제를 풀고 있는가: 현장 노하우, 엑셀 작업일지, 출하 데이터, 연삭 조건, 휠/스택 정보가 흩어져 있어 검색·비교·재사용이 어려운 문제.
- 이전에는 어떻게 했는가: 원본 엑셀/이미지/문서와 대화형 AI 작업 결과가 개별 파일로 쌓였고, Claude/Cowork/Code 환경 사이의 컨텍스트가 끊기기 쉬웠음.

## 범위

### 포함
- `raw/` 원본 자료 보존 (일부 서버 이동 — 아래 §raw 폴더 현황 참조)
- `wiki/` Markdown 위키 정리
- 재연마 작업일지, 출하현황, KPI 비교 분석
- 공구 연삭 조건, 휠/스택, 장비, 트러블슈팅 문서화
- 일일보고 및 Google Drive/Sheets 연동 자동화
- `dist/` 정적 웹 화면과 간단한 Flask 대시보드

### 제외
- 검증되지 않은 조건을 확정값처럼 기록하는 것
- 민감정보·토큰·비밀번호를 외부 저장소나 공개 배포물에 포함하는 것
