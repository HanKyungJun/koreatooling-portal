# grinding-calc 스킬

연삭 조건 계산을 중간 과정과 함께 수행합니다. 모든 결과는 검산 가능하도록
계산 과정을 명시합니다.

---

## 지원 계산 유형

### 1. 원주속도(Vc) ↔ RPM 변환

**RPM → Vc:**
```
Vc (m/s) = π × D(mm) × N(rpm) ÷ 60,000
```

**Vc → RPM:**
```
N (rpm) = 60,000 × Vc(m/s) ÷ (π × D(mm))
```

D = 휠 또는 공구 직경 (mm)

### 2. 비재료제거율 Q'w (Specific Material Removal Rate)

```
Q'w (mm³/(mm·s)) = ae(mm) × vw(mm/s)
```

- `ae` = 절입 깊이 (Depth of Cut, mm)
- `vw` = 공작물 이송 속도 (Workpiece Feed, mm/s)
  - mm/min으로 주어지면: vw = vw_mmmin ÷ 60

**역산 (Q'w와 ae로 vw 계산):**
```
vw (mm/s) = Q'w ÷ ae
```

**역산 (Q'w와 vw로 ae 계산):**
```
ae (mm) = Q'w ÷ vw
```

### 3. 접촉호 길이 lc

```
lc (mm) = √(ae × ds)
```

- `ds` = 휠 직경 (mm)

## 실행 방법

### 입력에서 필요한 값 추출

요청 문장에서 다음을 파악합니다:
- 계산 목표 (RPM? Vc? Q'w? feed?)
- 직경 D 또는 ds (mm)
- 알고 있는 값 (Vc, RPM, ae, vw, Q'w 중)

모르는 값이 있으면 **한 번만** 확인합니다. 단, 직경은 필수값이므로 반드시 확인합니다.

### 출력 형식

```
## 연삭 계산 결과

**입력값**
- 직경 D: [값] mm
- [입력 변수]: [값] [단위]

**계산 과정**
[수식에 값을 대입한 전개]
예: N = 60,000 × 20 ÷ (π × 125) = 1,200,000 ÷ 392.7 = **3,056 rpm**

**결과**
- [계산 결과]: [값] [단위]

**신뢰도:** 추정값 (입력값이 사내 실측 기반이면 사내 경험값으로 변경하세요)
```

## 안전 체크 (자동 적용)

계산 결과에 따라 아래 경고를 자동으로 추가합니다:

| 조건 | 경고 메시지 |
|------|------------|
| Vc > 30 m/s | ⚠️ **경고:** Vc가 30 m/s를 초과합니다. Resin Bond 휠의 최대 사용 속도를 초과할 수 있습니다. 휠 스펙 시트의 최대 원주속도(Vc_max)를 반드시 확인하세요. |
| Vc > 25 m/s | ⚠️ **주의:** Vc가 25 m/s를 초과합니다. 사내 권장 범위(18–25 m/s) 상단입니다. 첫 적용 시 단계적으로 상향하세요. |
| Q'w > 12 mm³/(mm·s) | ⚠️ **주의:** Q'w가 사내 권장 상한(12 mm³/(mm·s))을 초과합니다. 열 발생·휠 마모 증가 가능성이 있습니다. |
| RPM이 장비 최대 RPM 초과 (기입 시) | ⚠️ **경고:** 장비 최대 RPM을 초과합니다. 적용 불가 조건입니다. |

권장 범위 참고값 (출처 별도 확인 필요):
- Vc 권장: 18–25 m/s [VEN-NORTON-WINTER-2023] (제조사 기준)
- Q'w 권장: 6–12 mm³/(mm·s) [VEN-ANCA-GRAF2011] (제조사 기준)

## 계산 예시

**예시 1: RPM 계산**
> "D125 휠을 Vc 20 m/s로 운전하려면 RPM이 얼마야?"

```
N = 60,000 × Vc ÷ (π × D)
N = 60,000 × 20 ÷ (3.14159 × 125)
N = 1,200,000 ÷ 392.70
N = 3,056 rpm
```
→ Vc < 25 m/s: 정상 범위

**예시 2: Q'w 계산**
> "ae=0.3mm, 공작물 이송 1000 mm/min이면 Q'w는?"

```
vw = 1,000 mm/min ÷ 60 = 16.67 mm/s
Q'w = ae × vw = 0.3 × 16.67 = 5.0 mm³/(mm·s)
```
→ Q'w < 6 mm³/(mm·s): 권장 하한보다 낮음. 가공 효율 개선 여지 있음.

**예시 3: feed 역산**
> "Q'w 8, ae 0.5mm 이면 공작물 이송(mm/min)은?"

```
vw = Q'w ÷ ae = 8 ÷ 0.5 = 16 mm/s
vw = 16 × 60 = 960 mm/min
```
