# source-add 스킬

`wiki/_handoff/sources.md`에 새 출처를 ID 형식으로 등재합니다.

## ID 체계

출처 성격에 따라 접두사를 선택합니다:

| 접두사 | 의미 | 예시 ID |
|--------|------|---------|
| `[STD-XXX]` | 국제 표준 (ISO, JIS, DIN, ASTM, ANSI) | `[STD-ISO12413]` |
| `[ACA-XXX]` | 학술 논문, 핸드북, 교재 | `[ACA-DAVIM2014-SS]` |
| `[VEN-XXX]` | 제조사 카탈로그·기술 자료 | `[VEN-NORTON-WINTER-2023]` |
| `[CAT-XXX]` | 보유 카탈로그 (raw/Catalog/ 폴더 내) | `[CAT-HID]` |
| `[IND-XXX]` | 산업 보고서·뉴스·협회 자료 | `[IND-HKKE-EHWA2022]` |
| `[SYS-XXX]` | 핸드오프 시스템 근거 문헌 | `[SYS-KLEPPMANN]` |

---

## ID 생성 규칙

`[접두사-식별자]` 형식으로 만듭니다.

식별자 예시:
- 표준: `ISO12413`, `JIS-B4131`
- 논문: `저자성(연도)` → `DAVIM2014`, 복수 저자면 첫 번째만, 동일 저자 동년도면 `-SS` 등 구분자 추가
- 제조사: `브랜드-시리즈-연도` → `NORTON-WINTER-2023`, `ANCA-ESHARP-ARCHIVE`
- 카탈로그: 업체 약어 → `HID`(홍익다이아), `IHWA`(이화다이아), `JJ`, `COGO`
- 산업보고서: 기관약어-연도

기존 ID와 중복되면 구분자를 추가합니다 (예: `-2` 또는 `-B`).

## 실행 순서

### 1단계: 정보 수집

요청에서 아래 항목을 파악합니다. 없으면 한 번에 모아서 확인합니다:

- 출처 종류 (논문 / 표준 / 제조사 카탈로그 / 보유 카탈로그 / 산업보고서)
- 제목 (또는 문서명)
- 저자 / 발행기관
- 연도
- 식별자 (DOI, ISBN, 표준번호, URL 등 — 있으면)

### 2단계: sources.md 읽기

현재 파일을 읽어서:
1. 같은 ID가 이미 있는지 확인합니다 (중복 방지)
2. 등재할 섹션 위치를 파악합니다

### 3단계: ID 생성 및 등재

APA 형식으로 항목을 작성합니다:

**논문 형식:**
```
**[ACA-XXX]** 저자(연도). 제목. *저널명*, 권(호), 페이지. https://doi.org/...
```

**표준 형식:**
```
**[STD-XXX]** 기관명. (연도). *표준번호: 제목*. 발행기관.
```

**제조사 카탈로그 형식:**
```
**[VEN-XXX]** 제조사명. (연도). *문서 제목*. [제조사 기술 자료]
```

**보유 카탈로그 형식:**
```
**[CAT-XXX]** 업체명. (연도). *카탈로그 제목*. 보관 위치: raw/Catalog/파일명
```

### 4단계: sources.md 업데이트

해당 섹션에 새 항목을 추가합니다. 기존 항목은 절대 수정하지 않습니다.

### 5단계: 인용 스니펫 제공

등재 완료 후 바로 사용할 수 있는 스니펫을 출력합니다:

**프론트매터용:**
```yaml
sources:
  - "[새-ID]"
```

**본문 인용 예시:**
```markdown
[핵심 내용 예시 문장] [새-ID].
```

## 주의사항

- 기존 항목은 수정하거나 삭제하지 않습니다.
- 확인되지 않은 정보(연도 미상 등)는 `(n.d.)` 또는 `(추정 YYYY)` 표기합니다.
- 블로그·커뮤니티 글은 `[IND-XXX]`로 등재하되, 본문에서 단독 인용은 피하도록 안내합니다.
- 등재 후 해당 위키 페이지 프론트매터에도 ID를 추가하도록 안내합니다.
