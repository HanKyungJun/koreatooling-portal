# test-record 스킬

사내 가공·연삭 테스트 결과를 CLAUDE.md §9 표준 형식으로 기록합니다.

---

## 실행 순서

### 1단계: 정보 수집

요청에 포함된 값을 추출하고, 없는 항목은 **한 번에 모아서** 확인합니다.
모르거나 아직 미측정인 항목은 `—` 또는 `미측정`으로 처리합니다.

**필수 확인 항목 (9개):**
1. 장비명 (예: ANCA MX7)
2. 휠 사양 (예: 11V9 Ø125 Resin Diamond D46)
3. RPM 및 Vc (m/s)
4. Feed 및/또는 Q'w (mm³/(mm·s))
5. DOC / Ae (절입 깊이, mm)
6. 쿨런트 (종류, 농도, 압력)
7. 피삭재·공구 (예: D6 4날 초경 엔드밀 WC-Co)
8. 측정 장비 (예: Mitutoyo SJ-210)
9. 결과 (Ra μm, 수명 개수/드레싱, 외관 등)

**설비 상태 항목 (선택, 알면 기록):**
- 스핀들 런아웃·열변형 여부
- 휠 밸런스 (iBalance 측정값)
- 드레싱 상태 (마지막 드레싱 시점·횟수)
- 쿨런트 농도·pH
- 장비 예열 여부

**불량 발생 시 추가 항목:**
- 증상 (표면 거칠기 악화·날 끝 치핑·연삭 화상·버·코어 편심·런아웃 증가)
- 발생 위치
- 추정 원인
- 대응 방법

---

### 2단계: 마크다운 블록 생성

아래 템플릿에 값을 채웁니다:

```markdown
### 테스트 — [날짜] / [테스트 목적 한 줄]

| 항목 | 값 |
|------|-----|
| 장비 | [장비명] |
| 휠 | [사양] |
| RPM / Vc | [N] rpm / [Vc] m/s |
| Feed / Q'w | [feed] mm/min / Q'w [값] mm³/(mm·s) |
| DOC / Ae | [값] mm |
| 쿨런트 | [종류] [농도]%, [압력] bar |
| 피삭재·공구 | [소재 + 공구 사양] |
| 측정 장비 | [장비명] |
| **결과** | Ra [값] μm, 수명 [개수]/드레싱 |

**신뢰도:** 실측 검증 ← (사내 테스트로 재현 확인된 경우) / 사내 경험값 ← (반복 경험, 체계적 검증 미완)

**설비 상태**
- 스핀들 런아웃: [값 또는 "확인 안 됨"]
- iBalance: [값 또는 "미실시"]
- 드레싱: [마지막 시점 또는 "직전 드레싱 후 N번째"]
- 쿨런트 농도/pH: [값]
- 예열: [예/아니오]
```

불량이 발생한 경우 아래 섹션을 추가합니다:

```markdown
**불량 기록**
- 증상: [내용]
- 발생 위치: [내용]
- 추정 원인: [내용]
- 대응: [내용]
- 재발 여부: [추적 중/재발 없음]
```

조건이 이전과 다를 경우 버전 이력 테이블을 추가합니다:

```markdown
**조건 변경 이력**

| 날짜 | 변경 내용 | 사유 | 양산 적용 |
|------|----------|------|----------|
| [날짜] | [변경 전 → 후] | [이유] | [✅ 적용 중 / 🔄 검증 중 / ❌ 미적용] |
```

### 3단계: 저장 위치 안내

기록된 블록을 어느 페이지에 넣을지 제안합니다:

- 특정 공구 테스트 → `wiki/tools/` 해당 페이지의 `## 사내 데이터` 섹션
- 특정 소재 테스트 → `wiki/materials/` 해당 페이지의 `## 8. 사내 데이터` 섹션
- 휠 테스트 → `wiki/tools/wheels/` 해당 페이지의 `## 6. 사내 측정 데이터` 섹션
- 신규 공구 프로젝트 → `wiki/projects/` 새 페이지 생성 (wiki-new-page 스킬 권고)

사용자가 원하면 해당 페이지에 직접 추가합니다.

---

### 4단계: 검증 안내

기록 후 자동으로 아래를 확인합니다:

- Vc > 25 m/s → `⚠️ 주의: 권장 범위 상단` 메시지 추가
- Vc > 30 m/s → `⚠️ 경고: Resin Bond 한계 초과 가능` 메시지 추가
- Q'w > 12 mm³/(mm·s) → `⚠️ 주의: 권장 상한 초과` 메시지 추가
- 출처가 없는 수치 → "추정값" 명시

---

## 주의사항

- 기존 테스트 기록은 수정하지 않습니다. 새 데이터는 항상 추가(append)합니다.
- 조건 변경 시 이전 값을 삭제하지 말고 변경 이력 테이블로 남깁니다.
- 단가·금액 정보는 기록하지 않습니다.
- 신규 조건은 테스트→측정→검증 후에만 양산 적용 권장으로 표시합니다.
