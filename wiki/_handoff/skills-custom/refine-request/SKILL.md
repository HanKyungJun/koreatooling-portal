# 요청 다듬기

대충 쓴 한 줄 요청을, AI가 한 번에 제대로 해낼 수 있는 짧은 요청문으로 바꾼다.
요청문을 길고 화려하게 만드는 것이 목적이 아니다. **결과를 바꾸는 정보 3가지가 빠지지 않게 하는 것**이 목적이다.

## 언제 쓰나 / 안 쓰나

- 쓴다: 「이거 다듬어 줘」「프롬프트로 만들어 줘」「이렇게 시키려는데 괜찮아?」처럼 **AI에게 맡길 요청 자체**를 정리해 달라고 할 때
- 안 쓴다: 보고서·메일 같은 **문서의 문장**을 고쳐 달라는 것 → 그건 일반 교정으로 처리

## 핵심 3가지 (항상 이것만 본다)

| 항목 | 묻는 것 | 예 |
|---|---|---|
| ① 목적·독자 | 누가 어디에 쓰나 | 신입 교육용 / 거래처 제출 / 내 확인용 / 팀장 보고 |
| ② 볼 자료·대상 | 무엇을 보고, 어떤 조건 기준인가 | 첨부 파일, 위키 페이지, 장비·휠·소재, 기간 |
| ③ 완료 기준 | 무엇이 나오면 끝인가 | 표 1장 / 3줄 요약 / 가능·불가 결론만 / docx 파일 |

필요할 때만 ④ **지킬 조건**을 더한다: 안전(검증 전 양산 적용 금지), 정보 분류(단가는 대외비, 거래처 A/B/C), 바꾸면 안 되는 원본.

## 순서

1. **요청 읽기** — 위 3가지 중 이미 있는 것과 빠진 것을 가른다.
2. **맥락으로 채우기** — 채울 수 있는 것은 묻지 않고 채운다.
   - 작업 폴더에 `CLAUDE.md`·위키가 있으면(예: cnc-wiki) 거기 정해진 규칙(출처 우선순위, 신뢰도 4단계, 단위 표기, 보고서 양식 A·B·C, 역할 검토표)은 **요청문에 다시 풀어 쓰지 않는다.** 「위키 규약대로」 한마디면 된다.
   - 맥락 파일이 없는 사람(동료 등)이면 아무것도 지어내지 않는다. 빠진 것은 3단계에서 묻는다.
3. **빠진 것만 한 줄로 묻기** — 최대 3개, 각 항목에 Claude의 추정을 기본값으로 붙인다.
   - 예: 「목적은 신입 교육용, 형식은 표 1장으로 가정할까요? 장비·휠 기준만 알려 주세요.」
   - 사용자가 「그냥 해」라고 하거나 답할 사람이 없으면 추정값으로 진행하고, 요청문에 `(가정)`이라고 표시한다.
   - ⚠️ 가공·연삭 조건 요청인데 **장비·휠·소재가 없으면 반드시 묻는다.** 추정으로 채우지 않는다.
4. **완성 요청문 보여 주기** — 복사하기 쉽게 코드 상자 하나에, 8줄 이내로.

```
목적: 
대상·자료: 
할 일: 
완료 기준: 
지킬 것:    (없으면 줄 삭제)
```

5. 상자 아래에 한 줄: 「이대로 실행할까요?」 — 「응」이면 이 대화에서 바로 실행한다.

## 넣지 않는 것

- 「당신은 ○○ 전문가입니다」 같은 역할 부여 — 정보가 늘지 않는다
- 「단계별로 생각해 줘」 — 지금 모델은 알아서 한다. 계산 검산이 필요하면 「중간 계산식 표시」처럼 결과물 요구로 쓴다
- 말투·톤 지정 — 대외 문서처럼 독자가 바깥사람일 때만 넣는다
- 사용자가 말하지 않은 수치·조건 — 모르면 3단계에서 묻는다

## 예시

**예 1 — cnc-wiki 안에서 (경준님)**

입력: 「넥 연삭 조건 정리해 줘」

질문(한 줄): 「신입 교육용 표 1장으로 가정할까요? 장비·휠·소재 기준을 알려 주세요.」

답: 「ANCA, D125 레진 다이아, 초경. 교육용 맞아.」

```
목적: 신입 교육용 참고표
대상·자료: ANCA / D125 레진 본드 다이아몬드 휠 / 초경 엔드밀 넥 원통연삭 — 위키 넥 원통연삭 시험결과 기준
할 일: 연삭 조건(RPM·Vc m/s·Feed mm/min·DOC mm)을 표로 정리
완료 기준: 표 1장 + 주의사항 3줄 이내, 모든 수치에 출처 ID와 신뢰도
지킬 것: 위키 규약대로. 검증 안 된 값은 추정값 표시
```

**예 2 — 맥락 파일 없는 동료**

입력: 「회의록 정리해 줘」

질문(한 줄): 「팀장 보고용으로, 결정·할 일·미정 세 칸 표로 가정할까요? 회의 메모를 붙여 주세요.」

```
목적: 팀장 보고용 회의록
대상·자료: 아래 붙인 회의 메모 (11-16 생산회의)
할 일: 결정된 것 / 할 일(담당·기한) / 아직 미정인 것으로 나눠 정리
완료 기준: 표 1장, 메모에 없는 내용은 쓰지 않음, 담당·기한 없으면 빈칸
```

## 점검 (내보내기 전)

- 3가지(목적·자료·완료 기준)가 모두 채워졌거나 `(가정)` 표시가 있는가
- 사용자가 말하지 않은 수치를 넣지 않았는가
- 8줄 이내인가
