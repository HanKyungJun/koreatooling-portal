# 치수 기호도 (dimension-symbol-sheet)

공구 한 계열(예: 4날 코너R 넥 엔드밀)의 형상을 기호로만 그리고, 품번별 값과 계산식은 표에서 읽게 하는 설명 그림을 만든다. 제작 도면이 아니다 — 공차 · 표제란 · 축척이 있는 도면은 tool-generator(「공구 만들어 줘」)가 만든다.

양식: cnc-wiki `wiki/templates/치수기호도-양식/치수기호도_양식_v1.html` (2026-11-25, 견본 = 4날 코너R 넥 엔드밀). 그리기 도구는 dimensional-drawing(github.com/enesozturk/dimensional-drawing, MIT)에서 가져와 고친 것이고, 고지문은 같은 폴더 `LICENSE-dimensional-drawing.txt` 에 있다. 양식 머리 주석을 지우지 않는다.

## 순서

1. 확인 — 공구 종류 · 날 수 · 그릴 기호 · **값 출처**(카탈로그 표 · 도면 STEP · tool-generator 결과 · 없음). 빠진 것은 한 번에 모아 한 줄로 묻는다.
   - 품번으로 치수를 해석하지 않는다. 품번 표기는 업체 · 작성자마다 달라서, 값은 도면 · 카탈로그 표를 보고 정한다.
   - 생크경은 언제나 **d** 로 표기한다(「S」「샹크」라고 불러도 d).
2. 복사 — 경준님 PC 쪽 shell(device_bash)에서 양식을 `outputs/치수기호도/<이름>_v1.html` 로 복사한다. 같은 이름이 있으면 v2, v3 … 으로 올린다(덮어쓰지 않음).
3. 고치기 — 파일 안에서 python 으로 읽고 고쳐 쓴다(내용을 손으로 다시 치지 않음).
   - ① 머리칸(제목 · 도면 번호 · 판 · 값 출처) ② `<script>` 의 `V` 값 ③ 오른쪽 기호 표 ④ 시리즈 표 ⑤ 주기
   - 형상이 견본과 다르면(볼 · 스퀘어 · 드릴 · 넥 없음) 정면도 외곽 `path` 와 끝면도 · 상세도를 그 형상에 맞게 고친다.
4. 규칙
   - 흑백이다. 검정 · 회색만 쓰고, 구분은 선 굵기 · 점선 · 빗금으로 한다.
   - 그림 위 치수는 모두 기호로 쓴다. 값과 식은 표에 적는다. 파생값은 식 = 결과로 적고 중간 과정을 남긴다(예: `Lt = c ÷ tan θ = 0.15 ÷ 0.268 = 0.56`).
   - 근거가 없는 값은 `[TBD]` 로 둔다. 값을 지어내지 않는다.
   - 소재 · 코팅 칸은 비워 두고 도면을 쓸 때 채운다.
   - 단위는 mm · °, 투상법은 3각법이다(끝면도는 정면도 왼쪽).
   - 그림은 비례가 아니다. 넥 단차처럼 과장해서 그린 곳이 있으면 주기에 「과장해서 그림」을 적는다.
   - 값 출처와 신뢰도(제조사 기준 · 실측 검증 · 사내 경험값 · 추정값)를 머리칸이나 주기에 적는다.
   - AI(Claude) 사용 표기는 넣지 않는다.
5. 명의 — 사내용은 상호 없이 만든다. 쇼핑몰 · 카탈로그 등 대외로 내보낼 판은 발신 명의 (주)코리아툴링을 넣는다. 대외 공개이므로 추천 1개 + 이유를 내고 승인을 받은 뒤에 넣는다.
6. 검사 — 파일을 작업 공간으로 staging 해서 Playwright 로 1800 px 폭으로 렌더한다. 스크린샷은 Read 로 직접 본다.
   - 글자 겹침 · 시트 테두리 넘김 · 페이지 오류를 확인하고, 고칠 것이 있으면 한 번에 고친 뒤 다시 렌더한다.
   - 그림에 있는 기호가 모두 표에 있는지, 표에 있는 기호가 모두 그림에 있는지 대조한다.
   - 식은 python 으로 검산하고, 그 결과를 검토 줄 증거로 쓴다.
   - PNG 를 같은 폴더에 같은 이름으로 저장한다.
7. 보고 — PNG 를 보여 준다. 저장 폴더 · 파일 이름, `[TBD]` 목록, 값 출처 · 신뢰도만 짧게 적는다. 「제작 도면 아님」을 한 줄 붙인다. 끝에 검토 줄(R2 주)과 결론 블록을 둔다.

## 하지 않는 것

- 제작 도면을 대신하지 않는다. 공차 · 기하공차 · 표면거칠기는 적지 않는다(필요하면 tool-generator 와 도면 양식으로).
- 시리즈 표의 빈 품번 값을 추정해서 채우지 않는다.
- 색 · 로고 · 질감 그림을 넣지 않는다(대외판 명의 글자는 5번대로).
- 파일 삭제 · 이동은 먼저 묻는다. 시각은 KST 로 말한다.
