# 자료 조사 (research-deep)

넓게 훑고 → 걸러서 → 중점을 뽑는다. 좁은 검색어 하나로 끝내지 않는다.
계기: 2026-11-17 「AI 탑재 MCT」 조사 — 「MCT · CNC + AI」 검색으로는 상담형 AI 만 나왔고, 「マシニングセンタ」 로 바꾸고서야 실제 판매 중인 아룸 TTMC 가 나와 결론을 고쳤다.

## 0. 범위 — 묻지 말고 기본값으로 시작

- 기본: 최근 12개월 · 한국 · 일본 · 미국 · 유럽 · 결과는 답 + (주제가 남길 만하면) 위키 페이지
- 답 첫 줄에 잡은 범위를 적는다. 범위가 크면(주제 둘 이상 · 기간 3년 이상) 시작 전에 「사용량이 큼」 한 줄 알림
- 사용량 참고: 넓게 훑으면 좁은 검색의 약 2배(2026-11-17 1회 실측 — 첫 조사 29회 → 세 번 합계 61회, 검색 · 읽기 호출 수 기준 · 사내 경험값)

## 1. 검색어 펼치기 — 장비 × 기능 × 언어

| 축 | 펼치는 법 (예: 「AI MCT」) |
|---|---|
| 장비 | 요청 장비 + 같은 계열 · 상위 · 이웃 장비 — MCT · 머시닝센터 · 수직 / 수평 · 5축 · CNC 선반 · 복합가공기 · 연삭기 · 공구연삭기 · 방전 · CNC 장치(컨트롤러) · CAM |
| 기능 | 요청 기능 + 다른 이름 — AI · 인공지능 · 생성 AI · AI 에이전트 · 피지컬 AI · 머신러닝 · 자율 · 자동 프로그래밍 · 디지털 트윈 |
| 언어 | 한국어 · 일본어(현지 용어: マシニングセンタ · 工作機械 · 研削盤 · 工具研削盤) · 영어(machining center · VMC · HMC · turning center · tool grinder). 유럽 업체는 영어로 시작, 부족하면 독일어(Bearbeitungszentrum · Schleifmaschine) |

- 같은 턴에 여러 검색을 함께 보낸다. 기본 standard, 결과가 얇거나 오래됐으면 extended
- 결과가 안 나오는 조합도 「검색함 · 없음」으로 기록(빠뜨린 것과 구분)

## 2. 출처 경로 — 다섯 갈래를 모두 훑는다

1. 전시회 — 기간 안에 **실제로 열린 행사부터 확인**(목록 고정 금지). 주기 참고(2026-11-17 확인): JIMTOF · IMTS · SIMTOS · GrindingHub = 짝수 해, EMO = 홀수 해
2. 제조사 1차 — 보도자료 · 전시 안내 · 제품 페이지
3. 업계지 — MONOist · 日刊工業 · MMS · 산업일보 등
4. 스타트업 · 투자 · 협업 뉴스 — 대기업 밖 제품은 이 경로로만 걸린다
5. 표준 · 학술 — 원리 · 정의가 필요할 때만

## 3. 후보 목록 (원자료)

항목마다: 업체 · 제품 · 주장 내용 · 날짜(종류) · 출처 URL · 읽음 여부. 이 단계에서는 거르지 않는다.

## 4. 걸러내기

| # | 규칙 |
|---|---|
| F1 | **1차 자료로 거슬러 확인** — 기사에서 본 내용은 제조사 보도자료 · 페이지에서 다시 찾는다. 못 찾으면 「기사 경유」 표시 |
| F2 | 상태 분류 — 판매 중 / 출시 예정 / 참고출품 / 컨셉 · 개발 |
| F3 | 이름만 「AI」 와 실제 기능 구분 — 무엇을 하는지 설명이 없으면 「세부 미공개」 |
| F4 | 신뢰도 4단계(CLAUDE.md §2) — 제조사 원문에서 직접 확인 = **제조사 기준** · 기사 · 보도로만 확인 = **추정값(제조사 주장 · 기사 경유)** · 사내 실측만 **실측 검증** |
| F5 | 기사끼리 다르면 둘 다 적는다(삭제 · 하나 고르기 금지) |
| F6 | 정리 사이트 · 블로그 · 협력사 홍보 기사 = 5순위 보조 — 표시하고 **단독 인용 금지** |
| F7 | 날짜 종류 구분 — 기사일 · 발표일 · 행사일 · 출시(예정)일 |
| F8 | **못 읽은 출처 목록** — 유료 본문 · 접근 차단 · 잘림. 잘린 페이지는 offset 으로 끝까지 읽는다. 차단된 곳을 다른 방법(curl · 캐시 · 미러)으로 우회하지 않는다 |

## 5. 중점 뽑기

1. 핵심 3줄 — 무엇이 실제로 나왔고 무엇이 아직인가
2. 업체 · 제품 표 — 상태 · 시기 · 출처 ID
3. 사내 장비 · 업무와의 관계 — 사내 보유 장비 페이지(`wiki/machines/`)와 대조, 모르면 「확인 필요」
4. 「확인 필요」 목록

## 6. 확인 필요 재추적 1회

「확인 필요」 로 남긴 항목은 묻지 말고 한 번 더 직접 찾는다(1차 자료 · 다른 언어 · 남은 페이지). 그래도 남는 것만 답에 「확인 필요」.

## 7. 기록

- 위키에 남길 때: 새 페이지는 wiki-new-page 스킬 순서(스키마 · index · log), 출처는 source-add 스킬 형식으로 `sources.md` 에 먼저 등재(뉴스 = §5 `[IND-…]`, 제조사 = `[VEN-…]`) + §7 페이지 매핑
- 원자료 전부를 옮기지 않는다 — 걸러낸 결과와 출처, 못 읽은 출처 목록만
- 답 끝에 Sources 목록(링크) · 검토 줄(R1 주 · R5)

## 하지 않는 것

- 검색 한두 번으로 「없음」 단정 — 1 · 2단계를 다 돌린 뒤에만 「찾지 못함(확인 범위)」
- 제조사 주장 수치를 확정값처럼 쓰기
- 사내 ToolRoom .tom 통계를 근거로 쓰기
