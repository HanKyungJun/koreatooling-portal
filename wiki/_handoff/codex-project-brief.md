# Codex 프로젝트 요약 — cnc-wiki

> Codex가 새 작업에서 빠르게 맥락을 잡기 위한 요약입니다. 세부 사실과 현재 상태는 원본 핸드오프·위키 페이지를 확인합니다. 비밀값이나 개인정보는 넣지 않습니다.

## 목적과 구조

- TOOLKOREA의 CNC/MCT 가공, 공구 연삭, 재연마, 출하/KPI 지식을 모으고 업무 자동화를 돕는 사내 작업 공간입니다.
- 자료 흐름: `raw/` 원본 → `wiki/` 정리·분석 → `dist/` 웹 화면 → 필요할 때 Drive/Sheets 연동.
- `wiki/_handoff/`는 Claude, Cowork, Codex 사이의 공용 작업 맥락입니다. `context.md`는 범위, `decisions.md`는 결정, `tasks.md`는 할 일, `worklog.md`는 완료·인계 이력입니다.
- Claude와 Codex의 별도 시험 기록은 `ai-worklog-claude.md`, `ai-worklog-codex.md`; 현재 담당자와 작업은 `ai-handoff-current.md`에 둡니다.

## 협업 선호

- 사용자에게는 한국어로, 전문 개발 용어를 풀어 실제 작업 순서와 근거를 설명합니다.
- 현장 지식·실측과 AI를 함께 사용합니다. 검증되지 않은 가공·연삭 조건을 확정값으로 쓰지 말고 신뢰도를 구분합니다.
- 기존 문서와 의견이 다르면 최신 결정을 우선하고, 근거 파일을 대조합니다. 피드백은 가능하면 작성자·날짜가 있는 추가 의견으로 남깁니다.
- AI 간 검토는 초안 작성자와 검증자의 기록을 분리합니다. 확인하지 않은 실행·시험을 통과로 적지 않습니다.

## 보존·보안 규칙

- `raw/`는 원본 보존소입니다. 삭제·이동하지 않습니다.
- 단가·금액은 민감정보로 분리합니다. 거래처별 자료는 필요하면 익명화하고, 개인정보·토큰·비밀번호·API 키를 답변·문서·공개 산출물에 복사하지 않습니다.
- 외부 공개·배포·서비스 변경은 저장소 코드 수정과 구분하고, 사용자 지시 및 기존 결정에 맞춰 진행합니다.

## 작업 시작 시

- `AGENTS.md`의 작업 시작 문서와 이 요약을 확인한 뒤, 이번 일과 관련된 결정·작업 큐·위키 원문을 좁혀 읽습니다.
- 큰 문서 전체를 불필요하게 다시 불러오지 않습니다. 최신 핸드오프와 작업 범위에 필요한 근거부터 확인합니다.
- 의미 있는 변경은 `wiki/_handoff/worklog.md` 맨 위에 기존 형식으로 기록합니다. Claude/Codex 비교 작업은 각자 전용 기록에도 결과를 남깁니다.
- Git 변경 전후 상태를 확인하고, 사용자가 요청하지 않은 테스트는 추가하거나 실행하지 않습니다.
