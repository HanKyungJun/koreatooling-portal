## 역할 분담 (2026-11-27~)

Codex는 무료 요금제입니다 — **월 사용량 한도, 매월 26일 초기화**(2026-11-27 Codex 화면 확인: 남은 사용량 77%, 다음 초기화 12-26). 그래서 판단 · 작성은 Claude가 맡고, Codex는 Claude가 만든 작업 카드의 작은 일만 합니다.

| 담당 | 맡는 일 | 맡기지 않는 일 |
|---|---|---|
| **Claude** (주 담당) | 자료 조사, 공구 도면 · 3D, 보고서 · 대외 자료, 위키 작성, 검수, **Codex 작업 카드 작성** | — |
| **Codex** (작은 일) | Windows에서 파이썬 실행 · 문법 확인, 엑셀 · ERP 숫자 검산, 작은 코드 수정, git 상태 확인(읽기), Claude가 낸 숫자 재검산 | 긴 자료 조사, 도면 · 그림, 긴 문서 작성, worklog · decisions 전체 읽기 |

- 작업 카드 1장 = 한 번에 끝낼 수 있는 일 1개, 읽을 파일 최대 3개.
- Codex 한도가 차서 멈추면 Claude가 이어받습니다. 담당 변경은 `ai-handoff-current.md`에 기록합니다.
- Claude 한도가 찼을 때 Codex는 카드에 적힌 일만 하고, 새 판단(가공 조건 · 대외 · 규칙 · 삭제 · 이동)은 Claude 또는 사용자 확인까지 보류합니다.
- 숫자 · 조건은 한쪽이 초안, 다른 쪽이 검산합니다(교차 검토).
- 월 한도 관리: Codex 남은 사용량이 30% 아래면 검산 카드만 맡깁니다(코드 수정 · 실행 카드는 초기화 뒤로).

## 작업 카드 양식 (`ai-handoff-current.md`에 씀)

```markdown
## 작업 카드 — <작업 ID>
- 담당: Codex | Claude
- 상태: 대기 | 진행 중 | 마침 | 한도로 멈춤
- 목적: (1줄)
- 읽을 파일: (최대 3개, 경로)
- 할 일: (번호 3개 이내)
- 끝 기준: (무엇이 확인되면 끝인지)
- 결과 위치: (파일 경로 또는 「ai-worklog-<담당>.md 에만 기록」)
- 하지 말 것: (수정 금지 파일 · 외부 전송 등)
```

## 기록 구분

| 기록 | 기록자 | 쓰임 |
|---|---|---|
| `ai-worklog-codex.md` | Codex | Codex가 실제로 확인·수정한 내용, 증거, 남은 일 |
| `ai-worklog-claude.md` | Claude | Claude가 실제로 확인·수정한 내용, 증거, 남은 일 |
| `ai-handoff-current.md` | 작업을 넘기는 쪽 | 지금 이어받을 작업, 상태, 다음 담당자 |
| `worklog.md` | Cowork/공통 기존 흐름 | 기존 핸드오프 형식을 유지. 시험 중 중요한 요약만 추가 |

각 AI는 자기 작업 기록에만 새 블록을 추가합니다. 상대 기록은 읽되 고쳐 쓰지 않습니다. 공용 인계 파일은 넘기는 쪽이 최신 상태로 갱신합니다. 오래된 기록은 삭제하지 않습니다.

## 인계 절차

1. 인계받는 AI는 양쪽 기록과 인계 파일을 읽고, 현재 파일 상태를 확인합니다.
2. 인계 파일에 지정된 작업만 진행합니다. 범위가 바뀌면 그 이유와 미완 사항을 기록합니다.
3. 자기 작업 기록 맨 위에 날짜, 변경 파일, 확인 방법과 결과, 미완·블로커를 적습니다.
4. 인계 파일의 상태와 다음 담당자를 갱신합니다. 사용자 확인이 필요한 일은 임의로 완료 처리하지 않습니다.
5. 기존 운영 큐나 결정사항에도 영향이 생기면 `tasks.md` 또는 `decisions.md`에도 반영합니다.

## 작업 충돌 방지

- 동시에 같은 파일을 편집하지 않습니다. 인계 파일에서 담당자와 상태를 확인합니다.
- 기존 변경을 덮어쓰거나 무관한 파일을 정리하지 않습니다.
- 수정 전후의 파일 경로와 검증 근거를 기록합니다. 실행하지 않은 시험은 통과라고 쓰지 않습니다.
- 고객 공개, 외부 전송, 배포, 민감정보 취급은 기존 승인·보안 규칙을 따릅니다.

## 시험 작업

첫 시험은 `overview.md`의 현황 문구를 실제 저장소와 대조합니다. 지정된 다음 담당자가 검토와 실행을 맡고, 그 결과는 자기 기록 파일에 남깁니다. 다른 AI가 사용 불가 상태면 사용자 지시에 따라 Codex 단독으로 이어갈 수 있으며, 담당 변경은 공용 인계 파일에 기록합니다.
