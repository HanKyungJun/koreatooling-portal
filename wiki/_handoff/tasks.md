# 작업 큐 (tasks)

> 머릿속 할 일을 외부화하는 곳. 챗·Cowork·Code 어디서든 같은 큐를 봅니다.
> 완료 시 체크 후 [[tasks-archive]]로 이동 (삭제 X) — `python scripts/archive_handoff.py --apply` 가 자동으로 수거합니다.
> 📁 완료 항목 **87건**은 2026-08-28에 [[tasks-archive]]로 분리했습니다. 이 파일에는 **미완 항목만** 있습니다..
> "한 일"은 worklog.md, "왜 그렇게 할지"는 decisions.md, "할 일"은 이 파일.

---

## 우선순위 정의
- **P0** — 즉시 (오늘 안)
- **P1** — 이번 주
- **P2** — 이번 달
- **P3** — 백로그 (시간 날 때)

## 항목 형식

```
- [ ] [제목] (P0/P1/P2/P3)
  - 담당: 한경준 / 챗 / Cowork / Codex
  - 메모: 추가 컨텍스트
  - 관련: decisions.md 항목, sources.md ID, 파일 경로
```
