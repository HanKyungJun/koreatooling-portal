# 보고서 양식 C — 정기 업무 보고 (일일 · 주간 · 월간)

> 공통 규칙: [[standards/보고서-작성-규칙]] · 근거 결정: decisions 2026-10-28 (5) 7 · 8번
> 정기 보고는 상황 · 정보 보고서형이다 — **결론 먼저, 사실 위주, 짧게** [SYS-BLUEHOUSE2005] §6.2.
> 범위 밖: AI 주간브리핑(`reports/09_업무일정/주간브리핑/`, 내부 기록)

## 1. 일일보고 (자동 생성 xlsx — `scripts/daily_report.py`)

지금 형식(일일 요약 · 작업 상세 시트)은 유지하고, 「일일 요약」 시트 제목 아래에 3줄을 더한다.

```
① 결론 : 10월 27일 NC 생산 66개(양품 65개, 불량 1개), 월평균 66.2개 대비 0.3 % 적음
② 근거 : 10월 누계 1,059개(작업일 16일), ERP 작업실적 기준 속보값
③ 요청 : 확인 요청, 불량 1개 발생(작업지시 ○○○○○○○○○○)
```

| 줄 | 만드는 규칙 |
|----|------|
| ① | 오늘 합계 · 양품 · 불량, 월평균 대비(%) |
| ② | 이번 달 누계 수량 · 작업일, 데이터 기준 |
| ③ | 기본 「요청 없음」. **불량이 1개 이상**이거나 **합계가 월평균 대비 ±20 % 를 넘으면** 「확인 요청, (사유)」 |

- ±20 % 는 사내 경험값이다. 1달 운영 후 조정한다(decisions 2026-10-28 (5) 8번)
- 적용 방법: 스크립트에 넣고 **1주 동안 기존 보고서와 나란히 확인한 뒤** 켠다 → ✅ 2026-10-30 켬 — 지난 ERP 기준 보고서 4일 재계산 대조(4 / 4 일치)로 나란히 확인을 대신함(§4-2 · decisions 2026-10-30 (4))
- 함께 고칠 표기: 제목의 「─」, 표의 「▲▼」 → 「+ / −」 숫자로(공통 규칙 §8)

## 2. 주간 업무보고 (회사 양식 표)

회사 양식 그대로 쓴다. 보고 기간은 **목요일 ~ 수요일**(한경준님 확인, 2026-10-30).

```
| 부서   | 금주 중점업무                              | 시기            | 차주 예정업무                    | 시기       |
| 생산팀 | 1. 클로드 활용 업무 자동화                  | 10. 22. ~ 10. 28. | 1. 재연마 정가 자동 답변          | 10. 29. ~ |
|        |   가. ERP 생산실적 자동 추출(일일보고 전환)  | 10. 23. ~ 10. 27. |   가. 정가표 및 ERP 정가 오류 정정 | 10. 29. ~ 10. 30. |
|        |   나. 설계 및 가공 프로그램 연동 시험         | 10. 22. ~ 10. 23. |   나. 견적 문의 페이지 예상 정가   | 11. 2. ~  |
|        | 2. 파일럿 2기 발표자료 작성 및 제출          | 10. 22. ~ 10. 27. | 2. 자동화 효과 지표 재점검        | 11. 4.    |
```

| 규칙 | 내용 |
|------|------|
| 항목 | 1. → 가. 두 단계까지. 한 칸에 한 항목 |
| 끝맺음 | 명사형(「~ 추출」 「~ 제출」). 「~했음 · ~함」 종결이나 말투 쓰지 않음 |
| 숫자 | 실적은 숫자로: 「일일보고 ERP 조회 517회에서 263회로 줄임」처럼 바뀐 것을 한 개만 |
| 시기 | 「10. 22. ~ 10. 28.」 형식. 하루면 날짜 하나 |
| 금주 | 끝난 일 · 진행 중인 일. 진행 중이면 「(진행 중)」 |
| 차주 | 다음 주에 실제로 손댈 일만. 막연한 계획은 넣지 않음 |

## 3. 월간 보고 (신규, A4 1쪽)

```
[월간 보고]  생산팀 2026년 ○월 업무 보고

| 보고 기간 | 2026. ○. 1. ~ ○. ○○. | 보고일 | 2026. ○. ○. | 작성 | 생산팀 ○○○ |

요약
 ○ 결론 :
 ○ 근거 :                          (생산 수량, 불량률, 전월 대비)
 ○ 요청 :

1. 생산 실적                       → 표 1
   표 1. 월 생산 실적 (단위: 개)
   | 구분 | 이번 달 | 전월 | 전월 대비 | 전년 같은 달 | 비고 |
   | 양품 | | | | | |
   | 불량 | | | | | |
   | 불량률 (%) | | | | | |
   | 작업일 (일) | | | | | |
   | 일평균 | | | | | |

2. 주요 업무 실적                   (개조식 3 ~ 5개, 결과 숫자 포함)
3. 문제 및 조치                     (설비 고장, 불량, 납기의 원인과 조치, 남은 일)
4. 다음 달 계획                     (3개 이내, 시기 포함)
```

- 데이터: ERP 작업실적(NC) 월 합계 — 일일보고와 같은 기준. 금액은 넣지 않는다
- 1쪽을 넘기지 않는다. 상세는 별도 보고서(양식 A)로 돌린다
