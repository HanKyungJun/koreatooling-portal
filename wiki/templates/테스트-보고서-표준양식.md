## 1. 배경

가공·연삭 테스트를 진행할 때마다 서로 다른 형식의 보고서가 쓰여 왔다. 비교·재사용이 어렵고, 일부 항목은 CLAUDE.md 표준(§9)과 정합하지 않았다. 2026-07-09 세션에서 기존 양식 3종을 비교해 하나의 표준 양식으로 통합했다.

## 3. 최적화 내용

1. **단가·정가·할인율 컬럼 삭제** — CLAUDE.md §4 정보 분류 원칙(단가·금액만 대외비)에 따라 표준 양식에서 원천 제외.
2. **절삭조건 계산기를 보고서 본문에 수식으로 내장** — 별도 계산 파일 없이 D·Vc 입력 시 N(rpm)·Vf·fr·MRR·Q'w를 Excel 수식으로 자동 계산(`N=1000×Vc÷(π×D)` 등). AL엔드밀 실측값(D10·Vc207.3·N6600)으로 검산해 일치 확인.
3. **CLAUDE.md §9 필수 항목 신규 반영** — 신뢰도 4단계(드롭다운), 출처 ID, 설비상태(런아웃·밸런스·드레싱·쿨런트 농도/pH·예열여부), 조건 변경 이력 표(기존 값 삭제 없이 추가), 불량 발생 시 기록 섹션.
4. **비교 대상 수를 4개로 일반화** — 기존 양식은 3사 벤더 비교 전용 구조였으나, 2개(대조군/실험군)~4개 비교 테스트에 모두 대응 가능하도록 변경.
5. **인쇄 최적화** — A4 세로, 구간별 색상 헤더, 격자선 숨김.

## 4. 사용 흐름

1. 테스트 전: ①기본정보(목적 포함)·②비교대상·③절삭조건 작성
2. 가공 중/후: ④설비상태·⑤결과 기록
3. 불량 발생 시: ⑥ 작성

## 7. 실제 사용 양식과의 격차 분석 (2026-07-10, v1.2 검토)

hwp→pdf 변환 완료된 사내 원본 보고서 7건(아큐센터·드릴·NC드릴·맥스드릴·4F측면가공·AL엔드밀, 2024.07~2024.11 작성)을 원본 그대로 재검토한 결과입니다.

### 7-1. 실제로 최소 3가지 문서 유형이 혼재되어 있었음

| 유형 | 사용 사례 | 구조 특징 |
|------|-----------|-----------|

| Q'w 단위폭당 연삭량 (연삭 전용) | 원본 7건 전부 절삭(드릴·엔드밀) 테스트라 해당 없음 | 연삭 휠 테스트용 계산기 겸용이라 유지. 절삭 공구 테스트에는 참고하지 않아도 됨(라벨에 "[연삭 전용]" 명시됨) |

### 7-4. 반영하지 않은 것 (별도 과제로 남김)

- **연구계획서 표준양식**: 대규모 비교테스트 착수 전 기획서 양식(배경/목적/제안범위/방법/절차/일정/조직) — 필요 시 별도 템플릿(`wiki/templates/테스트계획서-표준양식.xlsx` 등)으로 신규 검토 가능. 현재는 미착수.
- **제품 사진 삽입 위치 표준화**: 실험결과보고서·제품비교분석 모두 사진(마모관찰 전/후, 제품형상, 부속 등)이 핵심 증빙인데 xlsx 표준양식에는 사진 삽입 셀/영역이 지정돼 있지 않음. 현재는 `raw/report/.../1.캡쳐/` 폴더 경로만 §6 참조파일 등에 텍스트로 기록하는 방식으로 대체.

## 8. 국제표준(ISO/KS) 대조 및 방법론 보완 (2026-07-10)

한경준님이 "이렇게 작성하는 게 맞는지" 의문을 제기해 국제표준·1차 방법론 문헌을 조사했다. 결론: 현재 §1~§8 구조는 국제표준의 규정 항목과 대체로 일치한다. 아래는 대조 결과와 이번에 보완한 내용이다.

### 8-1. ISO 3685 / ISO 8688 규정 항목과 구조 대조

절삭공구 수명시험의 국제표준은 **ISO 3685**(선삭, `[STD-ISO3685]`, 국내 KS B ISO 3685로 채택)와 **ISO 8688-1/2**(밀링, `[STD-ISO8688]`, 국내 KS B ISO 8688-1로 채택 — 정면밀링) 두 가지다. 두 표준 모두 아래 8개 요소를 시험 문서에 규정하도록 요구하며, 표준양식 섹션과 대응된다.

| ISO 규정 항목 | 표준양식 대응 섹션 |
|---|---|
| 피삭재(Workpiece) | §1 기본정보(피삭재) |
| 공구(Tools) | §2 비교대상 공구 |
| 절삭유(Cutting fluid) | §1 기본정보(냉각방식) |
| 절삭조건(Cutting conditions) | §3 절삭조건 계산기 |
| 장비(Equipment) | §1 기본정보(장비모델) + §4 설비상태 |
| 공구손상·수명 평가(Assessment of tool deterioration and tool life) | §5 결과 기록(파손형태·수명) |
| 시험절차(Test procedures) | 전체 작성 흐름(§4 사용흐름) |
| 기록·평가·결과제시(Recording, evaluation, presentation of results) | §5 결과기록 + §8 출처·후속조치 |

→ **구조 자체는 국제표준과 정합.** 세부 필드 명칭·순서는 사내 실사용 습관(§7)에 맞춰 조정했을 뿐, 요구 요소 8개를 빠뜨리지 않았음을 확인.

### 8-2. Walter Graf(ANCA, 2011) 원문 재확인 — 1회 1변수 원칙

기존에 인용해온 [VEN-ANCA-GRAF2011]의 "How to run a Grinding Test" 원문을 다시 확인한 결과, Evaluate 단계에 아래 원칙이 명시되어 있다.

> "good engineering is to change only one parameter at a time, observe changes, evaluate and only then make further adjustments."

이 원칙은 **AL엔드밀(호닝) 테스트에서 실제로 겪은 문제**([[comparisons/AL엔드밀-호닝-비교]] — Overhang·절삭속도·피삭재 두께·코팅·호닝이 동시에 바뀌어 개별 효과를 분리할 수 없었던 사례)와 정확히 일치한다. 표준양식 사용 시 다음을 원칙으로 삼는다.

> ⚠️ **재현성 원칙**: 대조군(§2 대상1)과 비교할 때는 변수를 1개만 바꾼다. 여러 변수가 동시에 바뀌면 §2·§3에 "조건 차이" 비고를 반드시 남기고, §8 종합판정에서 단일 변수 효과로 단정하지 않는다.

### 8-3. 연삭(휠) 전용 Record 항목 — 현재 미포함, 필요 시 추가

Walter Graf 원문의 Record 단계는 아래 9개 항목을 권장한다: 휠속도 vc, 드레싱 절입 ad, 이송 vw, 재료제거율 Q'w, **평균 칩두께 hm**, **공격성 인자 Fa**, **드레싱 비율 qd**, Amp 부하(%), 사이클타임 tc.

현재 §5에는 hm·Fa·qd가 없다. 이는 §7-3에서 이미 확인했듯 **원본 7건이 전부 절삭(드릴·엔드밀) 테스트**였기 때문— hm·Fa·qd는 그라인딩 휠 테스트 전용 지표라 지금까지는 필요 없었다. **ANCA 휠 연삭 테스트를 실제로 기록할 때는 §5에 이 3항목을 추가 검토**할 것 (수식은 원문에 이미지로만 제공돼 텍스트 확인 안 됨 — 실제 반영 시 [VEN-ANCA-GRAF2011] 원문 이미지 재확인 필요, 확인 전까지 임의 수식 기재 금지).

### 8-4. Preparation 단계 체크리스트 — §4 설비상태 보완 참고

원문은 §4(설비상태)보다 구체적인 준비 체크리스트를 제시한다: 노즐 손상 확인, 냉각수 온도 조·석 2회 측정, 드레싱 파라미터(속도비 qs 등) 사전 확인, air grinding 시간 확인(원문: "actual grinding time is often only 20 to 30% of total cycle time" — 사이클타임 단축은 이송 증가보다 공회전 제거가 우선). 연삭 테스트 도입 시 §4 항목 확장 후보로 남긴다.
