- [[s45c]] — C45 / S45C / 1045 중탄소강. 본 위키 가공 테스트의 **표준 baseline 피삭재**. 표준 등급명·화학 조성·열처리 상태별 물성·미세구조·절삭성 지수·BUE 메커니즘·추천 등급/코팅. (2026-05-12 신규)
- [[알루미늄]] — Al 6061·7075·5052 합금 클래스 페이지 (N그룹). 절삭성 300 (S45C 57의 5배), HSM Vc 1,000~3,000 m/min, PCD 1순위 / TiAlN 회피 (Al-Al 응착). AA 4자리 + 템퍼 표기 + 화학·물성·미세조직·코팅 trade-off. (2026-05-18 신규)
- [[sus304]] — SUS 304 / AISI 304 / 1.4301 / X5CrNi18-10 오스테나이트계 스테인리스 (M그룹). 절삭성 45 (난삭재 baseline), 가공경화 + 점성칩 + 낮은 열전도 3대 문제, Vc 황삭 120-150 / 정삭 160-180, TiAlN·CVD TiCN+Al₂O₃ 1순위 / PCD 절대 금기 (Fe 확산), HPC 70bar+ 권장. (2026-05-18 신규)
