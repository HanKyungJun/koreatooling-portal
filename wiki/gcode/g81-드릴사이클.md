# G81 — 단순 드릴 사이클 (Drilling Cycle)

> **단순 드릴**: 펙(peck) 없이 한 번에 지정 깊이까지 내려가고 빠르게 복귀하는 가장 기본적인 드릴 고정 사이클. **얕은 구멍(L/D ≤ 3)** 가공의 표준.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 — 고정 사이클의 기본 드릴 코드로 G81 명시
- **분류**: Canned Cycle (고정 사이클) — 단순 반복 드릴링 작업을 단일 코드로 표현
- **목적**: 펙 불필요한 얕은 구멍의 빠르고 간단한 드릴링

**FANUC 정의** (B-64604EN §10): G81 X_ Y_ Z_ R_ F_ K_

[출처: ISO 6983-1:2009 / FANUC Operator's Manual B-64604EN §10 Canned Cycles]

---

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)             ← 복귀 모드 선택
G81 X_ Y_ Z_ R_ F_ K_    ← G81 실행
G80                       ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 | 예시 |
|---|---|---|---|
| **X, Y** | 구멍 위치 (XY 평면) | 절대값(G90) 또는 증분(G91) | `X50.0 Y30.0` |
| **Z** | **최종 깊이** (가공 끝점) | 음수(아래 방향), mm | `Z-15.0` |
| **R** | **복귀점** (R-point, 안전 시작점) | 공작물 표면 위 2~5mm, 양수 | `R3.0` |
| **F** | **이송속도** | mm/min | `F150` |
| **K** | (선택) 반복 횟수 | 정수, 기본 1 | `K2` |

> G81에는 G83·G73의 Q 파라미터(펙 깊이)가 **없습니다**. 한 번에 Z까지 내려갑니다.

### 2.2 G98 vs G99 (복귀 모드)

| 모드 | 동작 | 사용 시기 |
|---|---|---|
| **G98** | 매 구멍 후 **초기점**으로 복귀 | 구멍 사이에 장애물 있을 때 |
| **G99** | 매 구멍 후 **R점**으로만 복귀 | 평탄한 공작물 (사이클 시간 단축) |

[출처: FANUC B-64604EN §10.1 / Smid 2008 Ch.19]

---

## 3. 동작 시퀀스 ★★★

G81의 1 사이클 동작 (한 구멍 가공) — 4단계:

```
1. 빠른 이송 (G00) → 구멍 위치 (X, Y)
2. 빠른 이송 → R점 (R)
3. 절삭 이송 (F) → R점에서 Z까지 한 번에 굴착
4. 빠른 후퇴 → G98: 초기점 / G99: R점
```

> **핵심**: 중간 후퇴(peck) 없이 직선으로 내려가고 올라옵니다.  
> G83과 달리 칩 배출을 위한 후퇴 사이클이 없으므로 **L/D ≤ 3** 얕은 구멍에서만 신뢰성 있습니다.  
> 깊은 구멍에 G81을 사용하면 칩이 쌓여 드릴 파손 위험이 있습니다.

---

## 4. 사용 예시 — 실제 코드 ★★★

### 4.1 기본 예시

```g-code
%
O0010 (G81 DRILL EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T1                            ← 공구 교환 (드릴 Ø8)
G43 H1 Z100.0                    ← 공구 길이 보정
M03 S1500                         ← 주축 회전
M08                               ← 쿨런트 ON
G00 X30.0 Y20.0                  ← 첫 구멍 위치
G99 G81 Z-12.0 R3.0 F150         ← G81 사이클 시작 (깊이 12mm)
X60.0 Y20.0                       ← 두 번째 구멍
X90.0 Y20.0                       ← 세 번째 구멍
X30.0 Y50.0                       ← 네 번째 구멍
G80                               ← 사이클 취소
M09                               ← 쿨런트 OFF
M05                               ← 주축 정지
M30                               ← 프로그램 종료
%
```

해석:
- Ø8 드릴로 깊이 12mm (L/D = 12/8 = 1.5 → G81 적합 범위)
- 4개 구멍을 연속 가공 후 G80 취소
- G99 모드: 각 구멍 후 R점(+3mm)으로 복귀 → 이동 시간 최소화

### 4.2 다른 깊이 혼용 (Z 재정의)

```g-code
G99 G81 X30.0 Y20.0 Z-12.0 R3.0 F150   ← 12mm 구멍
X60.0 Y20.0 Z-8.0                        ← 8mm 구멍 (Z 재정의)
X90.0 Y20.0                              ← 8mm 유지 (Z 생략 시 이전 값)
G80
```

> G81 사이클 내에서 Z를 다시 지정하면 해당 구멍부터 새 깊이 적용.

## 5. G81 / G73 / G83 비교 ★★★

| 코드 | 명칭 | 후퇴 방식 | 적용 L/D | 사이클 시간 |
|---|---|---|---|---|
| **G81** | 단순 드릴 | **없음** (연속 굴착) | **≤ 3** | 가장 빠름 |
| **G82** | 드웰 드릴 | 없음 + 바닥 정지 | ≤ 3, 정밀 깊이 | 빠름 + 드웰 |
| **G73** | 고속 펙 드릴 | 부분 후퇴 (d만큼) | 3~5 | 중간 |
| **G83** | 펙 드릴 | 완전 후퇴 (R점) | **> 5** | 가장 느림 |

### L/D 기준 선택 트리

```
구멍 깊이(L) ÷ 드릴 직경(D) = ?
├─ ≤ 3      → G81 (단순 드릴) ✅ 이 페이지
├─ 3~5      → G73 (고속 펙) — 칩 배출 보조
└─ > 5      → G83 (펙 드릴) — 칩 배출·냉각 필수
   > 10      → G83 + 펙 크기(Q) 줄임 + 고압 쿨런트 권장
```

[출처: Sandvik Coromant 드릴링 가이드 / Smid 2008 Ch.19]

## 6. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **깊은 구멍에 G81 사용** | 칩 적체 → 드릴 파손 | L/D > 3이면 G73 또는 G83으로 교체 |
| **R 음수 설정** | 공구 충돌 가능 | R은 공작물 표면 **위쪽** 양수 |
| **G80 누락** | 이후 X/Y 이동이 드릴 사이클 실행 | 사이클 종료 후 항상 `G80` 명시 |
| **F 이송 과도** | 날 파손, 구멍 정밀도 저하 | 권장값: 드릴 직경별 F = (0.02~0.06mm/rev) × RPM |
| **냉각수 없이 가공 (M08 누락)** | 열 집중 → 드릴 수명 급감 | `M08` 필수 (특히 SUS·알루미늄) |
| **G98/G99 미지정** | 모드 불확실 | 항상 명시적으로 G98 또는 G99 기재 |

## 7. 컨트롤러별 변종 ★★☆

### 7.1 FANUC 표준

위 §2 문법대로. Q 파라미터 없음.

### 7.2 Siemens (SINUMERIK 840D)

```
CYCLE81(RTP, RFP, SDIS, DP, DPR)
```

| 파라미터 | 의미 |
|---|---|
| RTP | 복귀 평면 (Retract plane) |
| RFP | 기준 평면 (Reference plane, 공작물 표면) |
| SDIS | 안전 거리 (= FANUC R점 역할) |
| DP | 최종 깊이 (절대값) |
| DPR | 최종 깊이 (증분값, DP 대신) |

[출처: Siemens SINUMERIK 840D sl Programming Manual §2.1]

### 7.3 HAAS

FANUC와 동일 문법. 주의: HAAS에서 Q가 있는 G83의 Q 단위는 mm(소수점) — 하지만 G81에는 Q 없으므로 차이 없음.

### 7.4 Mazak (EIA 모드)

FANUC 호환 문법. Mazatrol 대화 모드에서는 드릴 사이클 대화창으로 동일 동작.
