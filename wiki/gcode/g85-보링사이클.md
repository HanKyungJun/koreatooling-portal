# G85 — 보링 사이클 (이송 진입 · 이송 복귀, Boring Cycle Feed In / Feed Out)

> **G85**: 절삭 이송(F)으로 Z 깊이까지 내려가고, **같은 절삭 이송으로 R점까지 올라오는** 고정 사이클.
> 바닥 드웰 없음, 주축 정지 없음 — 주축은 사이클 내내 회전합니다.
> 주 용도: **리밍(reaming, 리머 가공)** · 황삭/중삭 보링. 빠른 이송 후퇴(G81)로 벽을 긁는 일을 피하려고 복귀도 이송으로 합니다.
>
> ★★★ = 표준·제조사 문서 직접 근거 | ★★☆ = 산업 통례 · 2차 대조 | ★☆☆ = 현장 관찰 · 추정

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 — 고정 사이클 코드 체계 [STD-ISO6983]
- **분류**: Canned Cycle (고정 사이클), 보링 계열 G76 · G85 ~ G89
- **핵심 차이**: 복귀 동작이 **절삭 이송** — G81(빠른 이송 복귀) · G86(주축 정지 후 빠른 이송 복귀)과 다름
- **동작 근거**: LinuxCNC 매뉴얼 — 진입 "Move the Z-axis only at the current feed rate to the Z position", 복귀 "Retract the Z-axis at the current feed rate to clear Z" [VEN-LINUXCNC-GCODE] · HAAS 명칭 "Bore in~Bore out Canned Cycle" [VEN-HAAS-MILLWB] · Siemens "Different feedrates for boring and retraction"(CYCLE85) [VEN-SIEMENS-PGZ0400]

> 출처 대조 메모(2026-11-16): FANUC 매뉴얼 원문(B-64604EN)은 이번 작성 때 직접 열람하지 못했습니다. 동작은 LinuxCNC · HAAS · Siemens 문서와 Smid 교재 [ACA-SMID2008] 가 일치하는 내용만 적었고, FANUC 고유 사항(파라미터 번호 등)은 넣지 않았습니다.

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)              ← 복귀 모드 선택
G85 X_ Y_ Z_ R_ F_ K_     ← G85 실행
G80                        ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 |
|---|---|---|
| **X, Y** | 구멍 위치 (XY 평면) | G90 절대 / G91 증분, mm |
| **Z** | **최종 깊이** (가공 끝점, 공작물 표면이 아님) | 보통 음수, mm |
| **R** | **R점** (이송 시작점이자 이송 복귀 끝점) | 공작물 표면 위, mm |
| **F** | 절삭 이송속도 — **진입과 복귀에 똑같이 적용** | mm/min |
| **K** | (선택) 반복 횟수 | 정수, 생략 시 1 |

- G85 에는 **P(드웰) · Q(펙 · 시프트)가 없습니다.** 바닥 드웰이 필요하면 G89(= G85 + 드웰 P, §5)를 씁니다 [VEN-LINUXCNC-GCODE].
- 진입 · 복귀 이송을 **따로** 줄 수 없습니다(FANUC · HAAS). 따로 주려면 Siemens CYCLE85(§7.3) 처럼 별도 파라미터가 있는 제어기가 필요합니다.

### 2.2 G98 vs G99 (복귀 모드)

| 모드 | G85 에서의 동작 |
|---|---|
| **G98** | Z → R점까지 **이송 복귀** → R점 → 초기점까지 **빠른 이송** |
| **G99** | Z → R점까지 **이송 복귀** 후 R점에 머묾 → 다음 구멍으로 |

> G98 이어도 Z → R 구간은 이송입니다. 빠른 이송은 R점 위에서만 일어납니다 [VEN-LINUXCNC-GCODE].

## 3. 동작 시퀀스 ★★★

```
1. 빠른 이송 (G00) → 구멍 위치 (X, Y)
2. 빠른 이송 → R점
3. 절삭 이송 (F) → Z 깊이              ← 리밍·보링 절삭
4. 절삭 이송 (F) → R점까지 복귀         ← ★ G85 의 특징 (빠른 이송 아님)
5. G98 이면 빠른 이송 → 초기점 / G99 이면 R점 유지
```

- 3 ~ 4 단계 동안 **주축은 계속 회전**합니다(M05 없음). 바닥 정지 · 방향 정지(오리엔테이션)도 없습니다.
- 공구가 회전하면서 같은 경로로 올라오므로, 복귀 때 공구 날이 벽에 닿은 상태로 지나갑니다(§5 · §6 참고).

## 4. 사용 예시 — 하부 구멍 → 리밍 ★★★

> 아래 S · F 는 **문법 설명용 빈칸**입니다. 조건은 공구 제조사 카탈로그와 사내 시험으로 정합니다(§8.2).

```g-code
%
O0085 (G85 REAM EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T5                            ← 리머 공구 교환 (하부 구멍은 이전 공정에서 가공 완료)
G43 H5 Z100.0                    ← 공구 길이 보정
M03 S___                          ← 주축 회전 (리머 카탈로그 기준)
M08                               ← 쿨런트 ON
G00 X30.0 Y20.0                  ← 첫 구멍 위치
G98 G85 Z-20.0 R2.0 F___         ← 이송 진입 → 이송 복귀, 매 구멍 초기점 복귀
X60.0 Y20.0                       ← 두 번째 구멍
G80                               ← 사이클 취소
M09
M05
M30
%
```

### 4.1 사이클 시간 계산 (G85 는 이송 구간이 2배)

이송 구간 길이 L = R − Z, 이송 시간 t = 2 × L ÷ F (min)

예(계산 방법 설명용 값): R = 2.0 mm, Z = −20.0 mm, F = 100 mm/min
- L = 2.0 − (−20.0) = 22.0 mm
- t = 2 × 22.0 ÷ 100 = 0.44 min = 0.44 × 60 = **26.4 s** (구멍 1개, 빠른 이송 시간 제외)
- 같은 조건 G81(빠른 이송 복귀)이면 이송 시간 = 22.0 ÷ 100 = 0.22 min = 13.2 s → G85 는 이송 구간이 약 2배

## 5. 보링 사이클 비교 ★★★

| 코드 | 바닥 동작 | 복귀 방식 | 벽 긁힘 | 주 용도 |
|---|---|---|---|---|
| **G85** | 없음 | **절삭 이송**, 주축 회전 | 날이 벽을 따라 올라옴 | **리밍**, 황삭·중삭 보링 |
| **G89** | 드웰 P | 절삭 이송, 주축 회전 | G85 와 같음 | 리밍·보링 + 바닥면 정리(막힌 구멍) |
| **G86** | 주축 정지 | 빠른 이송 | 정지한 날이 벽에 끌린 자국 가능 | 황삭 보링 |
| **G76** | 주축 방향 정지 + 시프트(Q) | 빠른 이송 | 날이 벽에서 떨어져 올라옴 | **정삭 보링**(단인 보링바) |
| **G88** | 드웰 후 주축 정지 | 수동 복귀 | — | 수동 확인용 |
| **G87** | — | — | — | 백 보링 |

[출처: [VEN-LINUXCNC-GCODE] G85 · G89 동작 / [[fanuc-고정사이클-개요]] §5 / [ACA-SMID2008]]

### G85 를 고르는 기준 ★★☆

```
무엇으로 가공하나?
├─ 리머 (다날, 하부 구멍 있음) → G85 (막힌 구멍 바닥 정리 필요하면 G89)
├─ 단인 보링바 · 정삭, 벽면 조도가 중요 → G76 (복귀 자국 피함)
└─ 단인 보링바 · 황삭/중삭 → G85 또는 G86
```

> ★★☆ 근거: 리밍에 G85 를 쓰는 이유는 빠른 이송 후퇴 때 리머가 벽을 긁는 것을 막기 위함이고, 단인 정삭 보링에 G76 을 쓰는 이유는 복귀 때 날이 벽에 닿지 않게 하기 위함입니다(산업 통례, [ACA-SMID2008]). **G85 복귀가 리밍 면을 좋게 하는지 나쁘게 하는지는 공구 · 소재마다 다르다는 의견이 갈립니다 — 사내 실측 없음(추정값 단계).** 구멍 벽 Ra 를 비교하려면 §8.2 시험으로 확인합니다.

## 6. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **Z 를 공작물 표면으로 지정** | 가공 안 됨 또는 깊이 부족 | Z = 구멍 끝 깊이 |
| **하부 구멍 없이 리머 진입** | 리머 파손 | 드릴(G81 · G83) → 리머(G85) 순서 |
| **드릴 이송을 리머에 그대로** | 면 거칠음 · 리머 파손 | 리머 카탈로그 이송 사용 |
| **드웰을 기대하고 P 기입** | 드웰 안 함(G85 는 P 없음) | 드웰이 필요하면 G89 |
| **사이클 시간을 G81 기준으로 계산** | 시간 과소 견적 | §4.1 처럼 이송 구간 2배로 계산 |
| **G80 누락** | 이후 XY 이동마다 G85 실행 | 항상 `G80` 명시 취소 |
| **R 을 너무 낮게 · 클램프 무시 G99** | 다음 구멍 이동 중 충돌 | 장애물 있으면 G98 |

> ⚠️ 주의: 이송 오버라이드는 진입과 복귀에 모두 걸립니다(복귀도 절삭 이송이므로). 첫 가공 때 오버라이드를 낮춰 놓으면 복귀도 같이 느려집니다 — 사이클 시간 실측은 오버라이드 100 % 에서 합니다. (★★☆, FANUC 원문 대조 확인 필요)

## 7. 컨트롤러별 변종

### 7.1 FANUC ★★★

§2 문법. 반복 K. 진입 · 복귀 이송 같음 [VEN-FANUC-0iMF] · [ACA-SMID2008].

### 7.2 HAAS ★★★

- 명칭 "Bore in~Bore out Canned Cycle", 주소 **X, Y, A, B, Z, R, L, F** [VEN-HAAS-MILLWB]
- **반복은 L**(FANUC 의 K 와 다름) — "repeat count for some canned cycles"
- G85 주소 목록에 P · Q 없음

### 7.3 Siemens SINUMERIK — CYCLE85 ★★☆

```
CYCLE85(RTP, RFP, SDIS, DP, DPR, DTB, FFR, RFF)
```

| 파라미터 | 의미 |
|---|---|
| RTP | 복귀 평면 (절대) |
| RFP | 기준 평면 (절대) |
| SDIS | 안전 거리 (부호 없음) |
| DP / DPR | 최종 깊이 (절대 / 기준 평면에서 상대) |
| DTB | 최종 깊이 드웰 — 초(s) 단위 |
| **FFR** | **진입(보링) 이송** |
| **RFF** | **복귀 이송** — FANUC 과 달리 진입과 따로 지정 |

- 옛 문서(PGZ 04.00)는 "Boring 1", 최근 840D sl 문서는 "Reaming (CYCLE85)" 로 표기
- ★★☆ 사유: 파라미터 이름 · 순서는 Siemens PGZ 04.00 의 화면 항목 목록과 일치 확인, 해당 절(§2.1.7) 원문 표는 이번에 열람하지 못함 [VEN-SIEMENS-PGZ0400]
- G89 처럼 드웰이 필요하면 DTB 로 줍니다(별도 코드 아님)

### 7.4 LinuxCNC (RS274/NGC) ★★★

G85 = 이송 진입 · 이송 복귀, G89 = G85 + 드웰 P(**초**) [VEN-LINUXCNC-GCODE]. FANUC 의 P 단위(ms)와 다르므로 G89 이식 때 주의 — [[g82-드웰드릴]] §7 와 같은 문제.

### 7.5 Mazak (EIA)

확인 필요 — 이번에 원문 확인하지 못함.
