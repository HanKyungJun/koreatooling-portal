# G83 — 펙 드릴 사이클 (Peck Drilling Cycle)

> **펙 드릴(Peck Drilling)**: 드릴을 한 번에 끝까지 내리지 않고 일정 깊이씩 후퇴(retract)하며 굴착하는 방식. **칩 배출**과 **냉각** 효과로 깊은 구멍(L/D > 3 권장) 가공에 필수.
>
> 본 위키의 첫 G-code 레퍼런스 페이지. 향후 G73(고속펙)·G81(단순드릴)·G84(탭핑) 등 동족 코드 페이지의 표준 모델입니다.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 (G-code 국제 표준) — 고정 사이클의 일부로 G83 명시
- **분류**: Canned Cycle (고정 사이클) — 반복적 가공을 단일 코드로 표현
- **목적**: 깊은 구멍 드릴링 시 칩 배출·냉각·드릴 보호

**FANUC 정의** (B-64604EN §10): G83 X_ Y_ Z_ R_ Q_ F_ K_

[출처: ISO 6983-1:2009 / FANUC Operator's Manual B-64604EN §10 Canned Cycles]

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)            ← 복귀 모드 선택
G83 X_ Y_ Z_ R_ Q_ F_ K_  ← G83 실행
G80                      ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 | 예시 |
|---|---|---|---|
| **X, Y** | 가공할 구멍 위치 (XY 평면) | 절대값(G90) 또는 증분(G91) | `X50.0 Y30.0` |
| **Z** | **최종 깊이** (가공 끝점) | 음수(아래 방향), mm | `Z-30.0` |
| **R** | **복귀점** (R-point, 안전 시작점) | 보통 공작물 표면 위 2~5mm, 양수 | `R3.0` |
| **Q** | **펙 깊이** (1회 후퇴 사이 굴착 깊이) | **양수**, μm 단위 (소수점 없음 주의) | `Q5000` (= 5mm) |
| **F** | **이송속도** | mm/min | `F120` |
| **K** | (선택) 같은 위치 반복 횟수 | 정수, 기본 1 | `K2` (2회 반복) |

> ⚠️ **Q 파라미터 단위 함정** (FANUC 통례): `Q5000` = 5.000 mm. 소수점 없이 μm 단위로 표기. 다른 좌표값(X/Y/Z/R)은 소수점 mm.

### 2.2 G98 vs G99 (복귀 모드)

| 모드 | 동작 | 사용 시기 |
|---|---|---|
| **G98** | 매 구멍 후 **초기점**(initial level)으로 복귀 | 다음 구멍 사이에 장애물 있을 때 |
| **G99** | 매 구멍 후 **R점**(R-point)으로만 복귀 | 평탄한 공작물 (이동시간 단축) |

### 2.3 절대좌표 vs 증분좌표

| 모드 | X·Y·Z 해석 |
|---|---|
| **G90** | 절대 좌표 (작업 원점 기준) — 본 위키 표준 |
| **G91** | 증분 좌표 (직전 위치 기준) |

[출처: FANUC B-64604EN §10.5 / Smid 2008 Ch.20]

## 3. 동작 시퀀스 ★★★

G83의 1 사이클 동작 (한 구멍 가공) — 7 단계:

```
1. 빠른 이송 (G00) → 시작점 위 (X, Y)
2. 빠른 이송 → R점 (R)
3. 절삭 이송 (F) → R점에서 Q 깊이만큼 굴착
4. 빠른 후퇴 → R점 (칩 배출, 냉각수 진입)
5. 빠른 이송 → 직전 깊이 - 약간(0.2mm 안전마진) 위치
6. 절삭 이송 → 다시 Q 깊이만큼 굴착 (누적 깊이)
7. Z 깊이에 도달할 때까지 4~6 반복 → 도달 후 G98/G99 모드대로 복귀
```

> **핵심**: 매 펙(peck) 후 **완전 후퇴** (R점까지) — 칩이 빠져나갈 시간 + 냉각수가 구멍 내부에 들어갈 시간 확보. 이것이 G73(고속펙, 부분 후퇴)과의 결정적 차이.

## 4. 사용 예시 — 실제 코드 ★★★

### 4.1 기본 예시

```g-code
%
O0001 (G83 PECK DRILL EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T1                            ← 공구 교환
G43 H1 Z100.0                    ← 공구 길이 보정
M03 S2000                         ← 주축 회전 (정방향)
G00 X50.0 Y30.0                  ← 첫 구멍 위치
G99 G83 Z-25.0 R3.0 Q5000 F120   ← G83 사이클 시작
X80.0 Y30.0                       ← 두 번째 구멍 (사이클 유지)
X110.0 Y30.0                      ← 세 번째 구멍
G80                               ← 사이클 취소
M05                               ← 주축 정지
M30                               ← 프로그램 종료
%
```

해석:
- 안전 블록: G90(절대), G54(원점1), G17(XY평면), G21(mm), G40·G49(보정취소), G80(사이클취소)
- G83: Z-25mm까지 5mm씩(Q5000) 펙. 복귀점 R+3mm. 이송 120 mm/min.
- 3개 구멍을 G83 사이클 모드로 연속 가공 → G80으로 명시 취소

### 4.2 K 파라미터 (반복) 사용

```g-code
G99 G83 X50.0 Y30.0 Z-25.0 R3.0 Q5000 F120 K3
```

동일 위치(X50, Y30)에서 G83을 3회 반복. 깊은 구멍 가공의 두 단계 펙 등에 활용.

## 5. G73 / G81 / G83 비교 ★★★

| 코드 | 명칭 | 후퇴 방식 | 적용 |
|---|---|---|---|
| **G81** | 단순 드릴 | 후퇴 없음 (연속 굴착) | 얕은 구멍 (L/D < 3) |
| **G82** | 드웰 드릴 | 바닥 정지 (드웰) | 카운터보어·정밀 깊이 |
| **G73** | 고속 펙 드릴 | **부분 후퇴** (d만큼만) | 중간 깊이 (3 < L/D < 5), 사이클 시간 단축 |
| **G83** | 펙 드릴 | **완전 후퇴** (R점까지) | 깊은 구멍 (L/D > 5), 칩 배출 우선 |
| **G84** | 탭핑 | 정역 회전 | 탭 가공 |

### G73 vs G83 결정 트리

```
구멍 깊이 / 직경 비율 (L/D) ?
├─ < 3   → G81 (펙 불필요)
├─ 3~5   → G73 (고속 펙) — 사이클 시간 우선
└─ > 5   → G83 (펙 드릴) — 칩 배출·냉각 우선
```

[출처: Sandvik Coromant 드릴링 가이드 / Smid 2008 Ch.20]

## 6. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **Q에 소수점 포함** (`Q5.0`) | FANUC 일부 모델에서 alarm | 정수(μm) 표기: `Q5000` |
| **R 음수 설정** | 공구 충돌 가능 | R은 공작물 표면 **위쪽** 양수 |
| **G80 누락** | 다음 블록의 X/Y 이동이 의도치 않게 드릴 사이클 실행 | 사이클 종료 후 항상 `G80` 명시 |
| **Z·R 모두 음수 (G99 모드)** | 가공 후 R점이 공작물 안 → 충돌 | R은 항상 공작물 위 양수 |
| **G98/G99 명시 누락** | 모드 default 의존 (불확실) | 명시적으로 G98 또는 G99 |
| **냉각수 부족 (M08 누락)** | 깊은 구멍 가공 시 드릴 파손 | G83 진입 전 `M08` 필수 |

## 7. 컨트롤러별 변종 ★★☆

### 7.1 FANUC 표준

위 §2 문법대로. Q 단위 μm (소수점 없음).

### 7.2 Siemens (SINUMERIK 840D)

```
CYCLE83(RTP, RFP, SDIS, DP, DPR, FDEP, FDPR, DAM, DTB, DTS, FRF, VARI)
```

- 매크로 형식 호출. 파라미터 명시적
- DP = 최종 깊이, DAM = 펙 깊이, DTB = 바닥 드웰
- FANUC G83보다 표현력 ↑ but 학습 곡선 ↑

[출처: Siemens SINUMERIK 840D sl Programming Manual §2.11]

### 7.3 HAAS

FANUC와 거의 동일하지만 Q 단위가 **mm** (소수점 포함). 차이 주의:
- FANUC: `Q5000` = 5mm
- HAAS: `Q5.0` = 5mm

### 7.4 Mazak (Mazatrol)

대화형(Conversational) 모드에서 G83 직접 사용 안 함. EIA 모드에서 FANUC 호환.

## 8. 본 위키에서의 위치

### 8.1 사용 맥락

- **공구 테스트**: 새로 재연삭된 드릴의 검증 시 G83 표준 코드로 가공 (`raw/report/` 영역)
- **드릴 수명 측정**: 동일 G83 조건으로 N회 가공 후 마모 측정 ([[공구-수명-관리]])
- **표면조도·치수 검증**: G83 결과를 [[표면조도-불량]] 진단 기준 비교

### 8.2 사내 표준 G83 조건

신뢰도: **추정값** — 초경 드릴 제조사(WIDIN·YG-1·COGO) 카탈로그 권장 Vc 기준으로 계산. 사내 실측 후 덮어쓸 것.

**계산 기준 (2026-06-05 재검토):**
- S45C: Vc = 70 m/min (WIDIN·YG-1 코팅 초경 드릴 권장 60~90 m/min 중간값)
- SUS304: Vc = **30 m/min** (카탈로그 권장 20~40 m/min 보수적 적용 — 가공경화·점성칩 위험으로 하한 근처 권장)
- A6061: Vc = 150 m/min (알루미늄, 카탈로그 권장 100~200 m/min 보수적 중간값)
- fz (날당 이송): 직경별 WIDIN·YG-1 카탈로그 일반 권장값
- Q (펙 깊이): 드릴 직경의 1/3 (보수적 기준)
- RPM 계산식: N = 1000 × Vc ÷ (π × D), 50 단위 반올림
- F 계산식: F = N × fz, 10 단위 반올림

| Ø2 | A6061 | 150 | 23,850 | 0.050 | 1,190 | 0.7 | ⚠️ 추정값 — 스핀들 최대 RPM 확인 필요 |
| Ø3 | S45C | 70 | 7,450 | 0.050 | 370 | 1.0 | 추정값 |

| Ø3 | A6061 | 150 | 15,900 | 0.060 | 950 | 1.0 | ⚠️ 추정값 — 스핀들 최대 RPM 확인 필요 |
| Ø6 | S45C | 70 | 3,700 | 0.080 | 300 | 2.0 | 추정값 |
| Ø6 | SUS304 | 30 | 1,600 | 0.060 | 100 | 2.0 | 추정값 |
| Ø6 | A6061 | 150 | 7,950 | 0.100 | 800 | 2.0 | 추정값 |

> ⚠️ **A6061 소경(Ø2·Ø3) 주의**: RPM 15,000~24,000은 사내 MCT 스핀들 최대 RPM을 초과할 수 있음. 스핀들 최대 RPM 확인 후 역산: Vc = π × D × N_max / 1000.
> **SUS304**: Vc=30 m/min 적용 (권장 범위 20~40 m/min 보수적 적용). 가공경화·점성칩으로 F를 S45C 대비 약 30~50% 수준으로 낮춤 [ACA-TRENTWRIGHT2000].
> 실측 검증 후 비고란에 날짜·결과 추가하고 신뢰도를 **실측 검증**으로 갱신할 것.
