# G73 — 고속 펙 드릴 사이클 (High-Speed Peck Drilling Cycle)

> **고속 펙 드릴**: G83(펙 드릴)의 빠른 버전. 매 펙(peck) 후 R점까지 **완전 후퇴하지 않고** 아주 짧은 거리(d)만 후퇴하여 칩을 단속하면서도 사이클 시간을 크게 줄인 방식.  
> **중간 깊이(L/D 3~5)** 구멍, 또는 칩이 짧게 끊어지는 소재(주철·황동·알루미늄)에서 G83 대신 사용.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 — 고속 펙 드릴 사이클로 G73 명시
- **분류**: Canned Cycle (고정 사이클)
- **목적**: 사이클 시간 단축 + 칩 단속 (G83보다 빠르고, G81보다 칩 배출 양호)

**FANUC 정의** (B-64604EN §10): G73 X_ Y_ Z_ R_ Q_ F_ K_

[출처: ISO 6983-1:2009 / FANUC Operator's Manual B-64604EN §10 Canned Cycles]

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)               ← 복귀 모드 선택
G73 X_ Y_ Z_ R_ Q_ F_ K_   ← G73 실행
G80                         ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 | 예시 |
|---|---|---|---|
| **X, Y** | 구멍 위치 (XY 평면) | 절대값(G90) 또는 증분(G91) | `X50.0 Y30.0` |
| **Z** | **최종 깊이** (가공 끝점) | 음수(아래 방향), mm | `Z-25.0` |
| **R** | **복귀점** (R-point, 안전 시작점) | 공작물 표면 위 2~5mm, 양수 | `R3.0` |
| **Q** | **펙 깊이** (1회 절삭 깊이) | **양수**, μm 단위 (소수점 없음, FANUC) | `Q5000` (= 5mm) |
| **F** | **이송속도** | mm/min | `F120` |
| **K** | (선택) 반복 횟수 | 정수, 기본 1 | 생략 가능 |

> ⚠️ **Q 파라미터 단위 함정** (FANUC 통례): `Q5000` = 5.000 mm. 소수점 없이 μm 단위. HAAS는 `Q5.0` = 5mm (소수점 포함). [[g83-드릴사이클]] §2.1 동일 주의.

### 2.2 G73 핵심 파라미터 — 부분 후퇴량 d

> G73의 결정적 특징: 매 펙 후 R점까지 **완전 후퇴하지 않고** d(부분 후퇴)만 올라감.

- **d 값**: 컨트롤러 내부 파라미터 (FANUC에서는 파라미터 번호 5114)로 설정. 통례 **0.1~1.0 mm**
- 기본값(출하 설정)은 제조사·모델별로 다름 → 사내 장비 확인 필요
- d가 너무 작으면 칩이 끊어지지 않음. 너무 크면 G83에 가까워져 이점 감소

[출처: FANUC B-64604EN §10.4 / Smid 2008 Ch.20]

## 3. 동작 시퀀스 ★★★

G73의 1 사이클 동작 (한 구멍 가공) — 5단계 반복:

```
1. 빠른 이송 (G00) → 구멍 위치 (X, Y)
2. 빠른 이송 → R점 (R)
3. 절삭 이송 (F) → Q 깊이만큼 굴착
4. 빠른 후퇴 → d만큼만 후퇴 (칩 단속, 냉각수 진입 제한적)
   ↑ G83과 차이: R점까지 올라가지 않음 → 시간 절약
5. 절삭 이송 → 다시 Q 깊이만큼 굴착 (누적 깊이)
   Z 깊이 도달까지 4~5 반복 → 도달 후 G98/G99 모드대로 복귀
```

### G73 vs G83 동작 비교

```
G83 (완전 후퇴):          G73 (부분 후퇴):
  ─── R점 ────             ─── R점 ────
       │                       │
  ─── 1Q ───  ←후퇴R          ─── 1Q ───  ←후퇴d
  ─── 2Q ───  ←후퇴R          ─── 2Q ───  ←후퇴d
  ─── 3Q ───  ←후퇴R          ─── 3Q ───  ←후퇴d
  ──── Z ────                  ──── Z ────

후퇴 거리: 매번 R점까지     후퇴 거리: 매번 d만큼만
칩 배출: 완벽               칩 배출: 불완전 (짧은 칩 소재에 유효)
사이클 시간: 느림            사이클 시간: 빠름
```

## 4. 사용 예시 — 실제 코드 ★★★

### 4.1 기본 예시

```g-code
%
O0020 (G73 HIGH-SPEED PECK DRILL EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T1                            ← 공구 교환 (드릴 Ø8)
G43 H1 Z100.0                    ← 공구 길이 보정
M03 S1800                         ← 주축 회전
M08                               ← 쿨런트 ON
G00 X30.0 Y20.0                  ← 첫 구멍 위치
G99 G73 Z-30.0 R3.0 Q5000 F130   ← G73 (깊이 30mm, 5mm씩 펙)
X60.0 Y20.0                       ← 두 번째 구멍
X90.0 Y20.0                       ← 세 번째 구멍
G80                               ← 사이클 취소
M09                               ← 쿨런트 OFF
M05                               ← 주축 정지
M30                               ← 프로그램 종료
%
```

해석:
- Ø8 드릴, 깊이 30mm → L/D = 30/8 = 3.75 → G73 적합 범위
- 5mm씩(Q5000) 펙, 매 펙 후 d(파라미터 5114)만큼 후퇴
- G83 대비 사이클 시간 약 30~50% 단축 가능

### 4.2 G83 → G73 교체 판단 예시

```
Ø6 드릴, 깊이 24mm → L/D = 4.0 → G73 적용 검토
  - 소재: S45C (연속칩 → G73 주의, 깊이 확인)
  - 소재: 알루미늄 (단속칩 → G73 유효)
  - 소재: 주철 (단속칩 → G73 유효)
```

## 5. G73 적용 소재별 판단 ★★☆

G73은 **칩이 짧게 끊어지는 소재**에서 효과적. 연속 칩이 나오는 소재는 G83 권장.

| 소재 | 칩 특성 | G73 적합성 | 권장 |
|---|---|---|---|
| **주철** | 단속칩 (취성) | ✅ 매우 적합 | G73 |
| **황동·청동** | 단속칩 | ✅ 적합 | G73 |
| **알루미늄** (6061·7075) | 연속칩이나 고속에서 단속 | ⚠️ 조건부 | G73 (고속) 또는 G83 |
| **S45C (탄소강)** | 연속칩 | ⚠️ L/D 3~4에서만 | G73 (얕음) / G83 (깊음) |
| **SUS304** | 인성 높고 연속칩 | ❌ 부적합 | G83 권장 |
| **초경 드릴로 가공** | 소재 무관 | — | 초경 드릴 파손 방지 위해 G83 우선 검토 |

> 출처: Smid 2008 Ch.20 §20.3 / Sandvik Coromant Drilling Guide

## 6. G81 / G73 / G83 비교 ★★★

| 코드 | 명칭 | 후퇴 방식 | 적합 L/D | 사이클 시간 | 칩 배출 |
|---|---|---|---|---|---|
| **G81** | 단순 드릴 | 없음 | ≤ 3 | ⭐⭐⭐ 빠름 | ❌ |
| **G73** | 고속 펙 드릴 | **부분 후퇴 (d)** | **3~5** | ⭐⭐ 중간 | △ 짧은 칩 |
| **G83** | 펙 드릴 | 완전 후퇴 (R점) | > 5 | ⭐ 느림 | ✅ 완벽 |

## 7. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **연속칩 소재 + 깊은 구멍에 G73** | 칩 적체 → 드릴 파손 | SUS·탄소강 깊은 구멍은 G83으로 교체 |
| **Q에 소수점** (`Q5.0`) | FANUC alarm 가능 | 정수(μm): `Q5000` |
| **d값(파라미터 5114) 미확인** | 후퇴량 불확실 → 칩 배출 예측 불가 | 사내 장비 파라미터 확인 후 기록 |
| **R 음수** | 공구 충돌 | R은 공작물 위 양수 |
| **G80 누락** | 이후 이동이 드릴 사이클 실행 | 사이클 후 항상 `G80` |

## 8. 컨트롤러별 변종 ★★☆

### 8.1 FANUC 표준

위 §2 문법대로. 부분 후퇴량 d = 파라미터 5114 (기본 설정 확인 필요).

### 8.2 Siemens (SINUMERIK 840D)

```
CYCLE73(RTP, RFP, SDIS, DP, DPR, DTB, FDEP, FDPR, DAM, FRF)
```

- DAM: 각 펙 깊이 (FANUC Q에 해당)
- FDPR: 부분 후퇴량 (FANUC d에 해당, 파라미터가 아닌 직접 지정)
- Siemens는 부분 후퇴량을 파라미터로 직접 제어 가능 → FANUC보다 유연

[출처: Siemens SINUMERIK 840D sl Programming Manual §2.6]

### 8.3 HAAS

FANUC와 거의 동일. Q 단위는 mm 소수점 포함: `Q5.0` = 5mm.

### 8.4 Mazak (EIA 모드)

FANUC 호환 G73 문법 지원.

### 9.1 사용 맥락

- **알루미늄·주철 드릴 재연삭 공구 검증**: 재연삭 후 G73으로 가공 → 칩 단속 여부 확인

- **조건 비교 테스트**: 동일 구멍에서 G73 vs G83 사이클 시간·품질 비교 데이터 축적
