# G82 — 드웰 드릴 사이클 (Drilling Cycle with Dwell)

> **드웰 드릴(Dwell Drilling)**: G81(단순 드릴)에 바닥 드웰(dwell, 일시 정지)을 추가한 사이클.  
> 드릴이 최종 깊이(Z)에 도달한 뒤 지정 시간 동안 **회전만 유지하며 정지**하다가 후퇴합니다.  
> 목적: 구멍 바닥 면의 **치수 정밀도 확보**와 **버(burr) 억제** — 카운터보어·스팟 페이싱·정밀 깊이 가공에 필수.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 — 고정 사이클 그룹 내 G82 명시
- **분류**: Canned Cycle (고정 사이클)
- **목적**: 바닥 드웰로 구멍 깊이 정밀도 향상 및 바닥 면 품질 개선

**FANUC 정의** (B-64604EN §10): `G82 X_ Y_ Z_ R_ P_ F_ K_`

G81과 파라미터 집합이 거의 동일하고, **P(드웰 시간)** 하나만 추가됩니다.

[출처: ISO 6983-1:2009 / FANUC Operator's Manual B-64604EN §10 Canned Cycles]

---

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)               ← 복귀 모드 선택
G82 X_ Y_ Z_ R_ P_ F_ K_   ← G82 실행
G80                         ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 | 예시 |
|---|---|---|---|
| **X, Y** | 가공할 구멍 위치 (XY 평면) | 절대값(G90) 또는 증분(G91) | `X50.0 Y30.0` |
| **Z** | **최종 깊이** (가공 끝점) | 음수(아래 방향), mm | `Z-15.0` |
| **R** | **복귀점** (R-point, 안전 시작점) | 공작물 표면 위 2~5 mm, 양수 | `R3.0` |
| **P** | **드웰 시간** (바닥 정지 시간) | **양수, ms 단위** (정수 권장) | `P500` (= 0.5초) |
| **F** | **이송속도** | mm/min | `F150` |
| **K** | (선택) 같은 위치 반복 횟수 | 정수, 기본 1 | `K3` (3회 반복) |

> ⚠️ **P 단위 주의** (FANUC): `P500` = 500 ms = 0.5초. 소수점 없이 정수 ms 단위로 표기합니다.  
> Siemens·HAAS는 초(s) 단위를 사용하므로 컨트롤러별 확인 필수.

> ⚠️ **P 생략 시**: G82는 G81과 동일하게 동작합니다 (드웰 없음). 명시적으로 P를 지정해야 드웰 효과가 있습니다.

### 2.2 G98 vs G99 (복귀 모드)

| 모드 | 동작 | 사용 시기 |
|---|---|---|
| **G98** | 매 구멍 후 **초기점**(initial level)으로 복귀 | 클램프·장애물이 있을 때 |
| **G99** | 매 구멍 후 **R점**(R-point)으로만 복귀 | 평탄한 공작물 (이동시간 단축) |

[출처: FANUC B-64604EN §10.2 / Smid 2008 Ch.20]

## 3. 동작 시퀀스 ★★★

G82의 1 사이클 동작 (한 구멍 가공) — 5 단계:

```
1. 빠른 이송 (G00) → 시작점 위 (X, Y)
2. 빠른 이송 → R점 (R)
3. 절삭 이송 (F) → Z 깊이까지 연속 굴착  ← G81과 동일
4. ★ 드웰 (P ms 동안 회전만 유지, 이송 정지)  ← G82만의 특징
5. 빠른 후퇴 (G00) → G98이면 초기점, G99이면 R점
```

> **G81과의 차이**: 3번에서 바닥에 도달한 직후 4번 드웰 단계가 추가됩니다.  
> 드웰 중에는 주축은 계속 회전하며, 이송만 멈춥니다 — 스프링백(spring-back) 없이 구멍 바닥을 깔끔하게 마무리합니다.

## 4. 사용 예시 — 실제 코드 ★★★

### 4.1 카운터보어 예시

```g-code
%
O0082 (G82 DWELL DRILL EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T2                            ← 카운터보어 공구 교환
G43 H2 Z100.0                    ← 공구 길이 보정
M03 S1200                         ← 주축 회전
M08                               ← 냉각수 ON
G00 X30.0 Y20.0                  ← 첫 구멍 위치
G99 G82 Z-8.0 R3.0 P500 F100    ← G82: 8mm 깊이, 바닥 0.5초 드웰
X60.0 Y20.0                       ← 두 번째 구멍
X90.0 Y20.0                       ← 세 번째 구멍
G80                               ← 사이클 취소
M09                               ← 냉각수 OFF
M05                               ← 주축 정지
M30                               ← 프로그램 종료
%
```

해석:
- Z-8.0: 8 mm 깊이까지 연속 이송 (F100 mm/min)
- P500: 바닥에서 500 ms(0.5초) 드웰 → 스프링백 없이 바닥 면 정리
- 3개 구멍을 G82 모드로 연속 가공 → G80으로 명시 취소

### 4.2 스팟 페이싱 (Spot Facing) 예시

카운터보어 직경이 크고 바닥 면의 평탄도가 중요한 경우 드웰을 길게 설정합니다:

```g-code
G99 G82 X50.0 Y50.0 Z-5.0 R2.0 P1000 F80
```

- P1000 = 1초 드웰: 절삭 잔류 응력이 빠져나갈 시간 확보
- 낮은 이송(F80): 바닥 면 조도(Ra) 개선 우선

## 5. G81 / G82 / G83 비교 ★★★

| 코드 | 명칭 | 후퇴 방식 | 드웰 | 적용 |
|---|---|---|---|---|
| **G81** | 단순 드릴 | 바닥에서 즉시 후퇴 | 없음 | 얕은 구멍 (L/D < 3), 스팟 드릴 |
| **G82** | 드웰 드릴 | 바닥 드웰 후 후퇴 | **P ms** | 카운터보어, 스팟 페이싱, 정밀 깊이 |
| **G73** | 고속 펙 드릴 | 부분 후퇴 (d만큼) | 없음 | 중간 깊이 (3 < L/D < 5) |
| **G83** | 펙 드릴 | 완전 후퇴 (R점) | 없음 | 깊은 구멍 (L/D > 5), 칩 배출 우선 |

### G81 vs G82 결정 기준

```
바닥 면 품질·치수 정밀도가 중요한가?
├─ NO  → G81 (단순 드릴) — 사이클 시간 최소
└─ YES → G82 (드웰 드릴)
         └─ 드웰 시간 기준:
            - 카운터보어, 스팟페이싱: P300~P1000
            - 정밀 깊이 제어: P200~P500
            - 재질이 연질(Al 등)이면 짧게: P100~P300
```

[출처: Smid 2008 Ch.20 / FANUC B-64604EN §10]

## 6. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **P 소수점 사용** (`P0.5`) | FANUC에서 alarm 또는 무시 | 정수 ms 표기: `P500` |
| **P 생략** | G81과 동일 동작 (드웰 없음) | 드웰이 필요하면 반드시 P 명시 |
| **P 과다** (P3000 이상) | 사이클 시간 증가, 불필요한 열 발생 | 재질·목적에 맞게 P200~P1000 범위 |
| **G80 누락** | 이후 X/Y 이동이 드릴 사이클 실행 | 항상 `G80`으로 명시 취소 |
| **R 음수 설정** | 공구 충돌 가능성 | R은 공작물 표면 위 양수 |
| **냉각수 누락 (M08)** | 카운터보어 절삭면 소착 | G82 진입 전 `M08` 권장 |

## 7. 컨트롤러별 변종 ★★☆

### 7.1 FANUC 표준

위 §2 문법대로. P 단위 ms(정수).

### 7.2 Siemens (SINUMERIK 840D)

```
CYCLE82(RTP, RFP, SDIS, DP, DPR, DTB)
```

- DTB = 바닥 드웰 시간 (**초 단위**, 소수 가능: `DTB=0.5`)
- FANUC P500 = Siemens DTB=0.5

[출처: Siemens SINUMERIK 840D sl Programming Manual §2.9]

### 7.3 HAAS

FANUC과 거의 동일하지만 P 단위가 **초(s)** (소수 포함):
- FANUC: `P500` = 500 ms = 0.5초
- HAAS: `P0.5` = 0.5초

### 7.4 Mazak (EIA 모드)

FANUC 호환 문법 사용. P 단위 ms.
