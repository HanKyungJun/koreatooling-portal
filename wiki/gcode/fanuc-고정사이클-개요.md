# FANUC 고정 사이클 개요 (Canned Cycle Overview)

> **고정 사이클(Canned Cycle)**: 반복적인 구멍 가공 동작(위치 이동→진입→절삭→복귀)을 단일 G코드로 표현하는 기능.  
> FANUC에서는 G73~G89가 고정 사이클 그룹이며, **G80으로 취소**합니다.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 개요·표준 ★★★

- **표준**: ISO 6983-1:2009 — 고정 사이클 코드 체계 정의
- **FANUC 적용**: 0i 시리즈 기준 G73~G89 (컨트롤러 버전에 따라 일부 코드 미지원)
- **핵심 원칙**: 한 번 지정한 고정 사이클은 **G80 취소 전까지 유효**. 이후 X/Y 이동만으로 다음 구멍 가공

[출처: ISO 6983-1:2009 / FANUC B-64604EN §10 Canned Cycles]

---

## 2. 공통 동작 — 4단계 ★★★

모든 고정 사이클은 아래 4단계 구조를 따릅니다:

```
1단계: 빠른 이송(G00) → 구멍 XY 위치
2단계: 빠른 이송(G00) → R점 (안전 진입점)
3단계: 절삭 이송(F)   → Z 최종 깊이 (사이클별 동작 상이)
4단계: 복귀           → G98: 초기점 / G99: R점
```

---

## 3. G98 / G99 복귀 모드 ★★★

고정 사이클 실행 전 반드시 복귀 모드를 지정합니다.

| 모드 | 동작 | 사용 시기 |
|------|------|----------|
| **G98** | 매 구멍 후 **초기점(Initial Point)** 복귀 | 구멍 사이에 클램프·돌출부 있을 때 |
| **G99** | 매 구멍 후 **R점(R-Point)** 복귀 | 평탄한 공작물 (사이클 시간 단축) |

```
G98 모드:  초기점 ─┐
                    ↓  (복귀)
           R점 ────┤  ↑
           Z점 ────┘
           
G99 모드:  R점 ────┐
                    ↓  (복귀)
           Z점 ────┘
```

> **권장**: G98/G99를 항상 명시적으로 기재. 미지정 시 이전 상태 유지로 오작동 위험.

---

## 4. 공통 파라미터 ★★★

| 파라미터 | 의미 | 비고 |
|---------|------|------|
| **X, Y** | 구멍 위치 | G90(절대) / G91(증분) 모두 가능 |
| **Z** | 최종 가공 깊이 | 음수(아래 방향), mm |
| **R** | R점 (안전 진입점) | 공작물 표면 위 2~5 mm, 양수 권장 |
| **F** | 절삭 이송속도 | mm/min. G84 탭핑은 F = S × Pitch 필수 |
| **Q** | 펙 깊이 (G73·G83) / 시프트 (G76·G87) | FANUC: μm 정수 (Q5000 = 5 mm) |
| **P** | 바닥 드웰 시간 (G82·G84·G85 등) | ms 단위 |
| **K** | 반복 횟수 | 생략 시 1회 |
| **L** | 반복 횟수 (K와 동일, 컨트롤러 따라 다름) | — |

> ⚠️ **Q 단위 주의**: FANUC은 μm 정수(Q5000 = 5 mm), **HAAS는 mm 소수(Q5.0 = 5 mm)**. 컨트롤러 혼용 시 반드시 확인.

## 6. G80 — 고정 사이클 취소 ★★★

```g-code
G80   ← 고정 사이클 모달 취소
```

- G80 이후 X/Y 이동은 일반 위치 이동으로 처리됨
- **필수**: 고정 사이클 종료 후 반드시 G80 명시. 누락 시 이후 이동이 드릴 사이클로 실행되는 오작동 발생
- G00/G01/G02/G03 등 일반 이동 G코드 지정도 고정 사이클 취소 효과 있으나 — 명시적 G80 권장

## 7. 표준 프로그램 구조 ★★★

```g-code
%
O0001 (CANNED CYCLE EXAMPLE)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록 (G80 포함)
M06 T1                            ← 공구 교환
G43 H1 Z100.0                    ← 공구 길이 보정
M03 S___                          ← 주축 회전
M08                               ← 쿨런트 ON
G00 X___ Y___                    ← 첫 구멍 위치
G99 G8X Z___ R___ F___ (Q___)   ← 고정 사이클 시작
X___ Y___                         ← 추가 구멍
G80                               ← 사이클 취소 ★ 필수
M09                               ← 쿨런트 OFF
M05                               ← 주축 정지
M30                               ← 종료
%
```

> **안전 시작 블록**에 G80을 포함하는 것이 업계 표준 관행. 이전 프로그램의 고정 사이클 모달이 남아있을 경우를 대비.

## 8. L/D 비율 기준 사이클 선택 트리 ★★★

```
드릴 직경 D, 가공 깊이 L 기준:

L ÷ D = ?
│
├─ ≤ 3      → G81 (단순 드릴) — 펙 불필요
│             G82 (드웰 드릴) — 카운터보어·자리파기
│
├─ 3 ~ 5    → G73 (고속 펙) — 부분 후퇴, 철계·주철 적합
│
└─ > 5      → G83 (펙 드릴) — R점 완전 후퇴, 깊은 구멍 표준
   > 10      → G83 + Q값 축소 + 고압 쿨런트 권장
```

탭핑: **G84** (우나사) / **G74** (좌나사) — L/D 무관, F = S × Pitch 준수 필수

## 9. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|------|------|------|
| **G80 누락** | 이후 이동이 드릴 사이클로 실행 | 항상 G80 명시, 안전 시작 블록에 포함 |
| **G98/G99 미지정** | 이전 모달 상태 적용 → 예측 불가 | 항상 명시적 기재 |
| **Q 단위 착오** | 펙 깊이 1000배 오류 | FANUC μm vs HAAS mm 구분 철저 |
| **R 음수 설정** | 공구 충돌 | R은 공작물 표면 위쪽 양수 |
| **G84 F 계산 오류** | 탭 파손 | F = S(RPM) × Pitch(mm/rev) 계산 필수 |
| **M29 없는 G84** | 비동기 탭핑 → 탭 파손 | G84 전 반드시 M29 S___ |
