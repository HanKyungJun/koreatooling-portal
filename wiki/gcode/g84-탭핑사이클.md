# G84 — 탭핑 사이클 (Tapping Cycle)

> **탭핑 사이클**: 주축을 정방향으로 회전시키며 나사를 냄(탭핑)하고, 지정 깊이에서 **역회전(역방향)**으로 빠져나오는 사이클. 탭(Tap) 공구의 피치(pitch)와 이송속도(F)를 정확히 맞추는 것이 핵심.
>
> G84는 우나사(RH, Right-Hand thread) 탭핑 표준. 좌나사는 G74.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 정의·표준 ★★★

- **표준**: ISO 6983-1:2009 — 탭핑 사이클로 G84 명시
- **분류**: Canned Cycle (고정 사이클) — 주축 정역 회전 + 이송 연동 복합 동작
- **목적**: 나사 가공 (M3~M30 범위가 MCT에서 가장 일반)

**FANUC 정의** (B-64604EN §10): G84 X_ Y_ Z_ R_ P_ F_ K_

> ⚠️ **탭핑의 핵심 원칙**: F(mm/min) = **S(RPM) × Pitch(mm/rev)**  
> 이 관계를 어기면 탭이 즉시 파손됩니다.

[출처: ISO 6983-1:2009 / FANUC Operator's Manual B-64604EN §10.7]

---

## 2. 문법 — FANUC 표준 ★★★

```
G98(또는 G99)               ← 복귀 모드
M29 S___                    ← 동기 탭핑 모드 선언 (Rigid Tap, 필수)
G84 X_ Y_ Z_ R_ P_ F_ K_   ← G84 실행
G80                         ← 사이클 취소
```

### 2.1 파라미터 상세

| 파라미터 | 의미 | 부호·단위 | 예시 |
|---|---|---|---|
| **X, Y** | 탭 위치 (XY 평면) | 절대값(G90) 또는 증분(G91) | `X50.0 Y30.0` |
| **Z** | **탭 깊이** (나사 끝점) | 음수, mm | `Z-20.0` |
| **R** | **복귀점** (공작물 표면 위) | 양수, 통례 3~5mm | `R3.0` |
| **P** | (선택) **바닥 드웰** 시간 | ms 단위 정수 | `P500` (0.5초) |
| **F** | **이송속도** = **RPM × Pitch** | mm/min | `F250` |
| **K** | (선택) 반복 횟수 | 정수, 기본 1 | 생략 가능 |

### 2.2 F 계산 — 가장 중요한 파라미터 ★★★

```
F (mm/min) = S (RPM) × Pitch (mm/rev)
```

| 탭 규격 | 피치 (mm/rev) | S = 500 RPM → F | S = 800 RPM → F | S = 1000 RPM → F |
|---|---|---|---|---|
| **M3 × 0.5** | 0.5 | 250 | 400 | 500 |
| **M4 × 0.7** | 0.7 | 350 | 560 | 700 |
| **M5 × 0.8** | 0.8 | 400 | 640 | 800 |
| **M6 × 1.0** | 1.0 | 500 | 800 | 1,000 |
| **M8 × 1.25** | 1.25 | 625 | 1,000 | 1,250 |
| **M10 × 1.5** | 1.5 | 750 | 1,200 | 1,500 |
| **M12 × 1.75** | 1.75 | 875 | 1,400 | 1,750 |

> 신뢰도: **제조사 기준** (FANUC B-64604EN §10.7 공식 직접 인용)

> ⚠️ **단 1% 오차도 탭 파손 원인**. 프로그램 입력 전 반드시 검산: F = S × Pitch

### 2.3 동기 탭핑 (Rigid Tapping, M29) vs 부동 홀더 탭핑

| 방식 | 명령 | 특징 | 사용 시기 |
|---|---|---|---|
| **동기 탭핑 (Rigid Tap)** | `M29 S___` 선행 | 주축 회전과 Z 이송 **완전 동기화** — 탭 홀더 고정 | **현재 표준** (MCT 대부분 지원) |
| **부동 홀더 탭핑** | M29 없음 | 부동 홀더(float holder)가 피치 오차 흡수 | 구형 장비, 동기 탭핑 미지원 시 |

> 본 위키 ANCA CNC Tool Grinder는 공구 연삭 전용이므로 탭핑 직접 적용 없음. 사내 MCT([[anca-cnc-tool-grinder]]와 별도)에서 G84 운용.

[출처: FANUC B-64604EN §10.7 / Smid 2008 Ch.21]

## 3. 동작 시퀀스 ★★★

G84의 1 사이클 동작 (한 나사 구멍 가공) — 6단계:

```
1. 빠른 이송 (G00) → 탭 위치 (X, Y)
2. 빠른 이송 → R점 (R)
3. 주축 정회전 (M03) + 절삭 이송 (F) → R에서 Z까지 탭핑
4. [P 지정 시] 바닥에서 드웰 (P ms 동안 정지)
5. 주축 역회전 (M04) + 이송 역방향 → Z에서 R점으로 후퇴
6. G98: 초기점 / G99: R점에서 대기. 주축 정회전(M03) 복귀
```

> **핵심**: Z 최종 깊이에서 주축이 **자동 역회전** → 탭이 나사를 타고 빠져나옴.  
> 역회전 이송속도도 F와 동일하게 동기화.  
> 이 역회전 동작 때문에 탭핑은 다른 고정 사이클보다 주축 부하가 큼.

## 4. 사용 예시 — 실제 코드 ★★★

### 4.1 기본 예시 — M6×1.0 탭핑

```g-code
%
O0030 (G84 TAPPING EXAMPLE - M6x1.0)
G90 G54 G17 G21 G40 G49 G80      ← 안전 시작 블록
M06 T2                            ← 공구 교환 (M6 탭)
G43 H2 Z100.0                    ← 공구 길이 보정
M08                               ← 쿨런트 ON
G00 X40.0 Y25.0                  ← 첫 탭 위치
M29 S800                          ← 동기 탭핑 모드 (800 RPM)
G99 G84 Z-18.0 R3.0 F800         ← F = 800 × 1.0 = 800 mm/min
X80.0 Y25.0                       ← 두 번째 탭
X120.0 Y25.0                      ← 세 번째 탭
G80                               ← 사이클 취소
M09                               ← 쿨런트 OFF
M05                               ← 주축 정지
M30                               ← 프로그램 종료
%
```

검산: S=800, Pitch=1.0 → F = 800 × 1.0 = 800 ✅

### 4.2 P 파라미터 (바닥 드웰) — 고정밀 깊이 제어

```g-code
M29 S600
G99 G84 Z-15.0 R3.0 P300 F600    ← 바닥에서 0.3초 정지 후 역회전
```

맹구멍(blind hole) 탭핑에서 바닥 깊이를 정확히 맞출 때 사용.

### 4.3 M3×0.5 소경 탭핑 — 저속 권장

```g-code
M29 S500                          ← 소경 탭은 저속 (500 RPM)
G99 G84 Z-8.0 R3.0 F250          ← F = 500 × 0.5 = 250
```

> ⚠️ M3 이하 소경 탭: RPM 낮추고 절삭유 충분히. 파단 시 추출 어려움.

## 5. 탭 규격과 하부 구멍 직경 ★★★

탭핑 전 드릴(G81·G83)로 하부 구멍을 먼저 가공해야 함. 하부 구멍 직경이 작으면 탭 파손, 크면 나사산 불량.

| 탭 규격 | 피치 (mm) | 하부 구멍 직경 (mm) | 비고 |
|---|---|---|---|
| M2 × 0.4 | 0.4 | **Ø1.6** | 극소경 — 브레이킹 주의 |
| M2.5 × 0.45 | 0.45 | **Ø2.05** | |
| M3 × 0.5 | 0.5 | **Ø2.5** | |
| M4 × 0.7 | 0.7 | **Ø3.3** | |
| M5 × 0.8 | 0.8 | **Ø4.2** | |
| M6 × 1.0 | 1.0 | **Ø5.0** | 사내 가장 일반 |
| M8 × 1.25 | 1.25 | **Ø6.75** | |
| M10 × 1.5 | 1.5 | **Ø8.5** | |
| M12 × 1.75 | 1.75 | **Ø10.2** | |

> 공식: 하부 구멍 직경 ≈ 탭 공칭 직경 − 피치 (근사값, 가공 소재별 조정 필요)  
> 출처: ISO 724:1993 (미터나사 기초 치수) / Smid 2008 Ch.21 §21.2

## 6. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|---|---|---|
| **F ≠ S × Pitch** | 탭 즉시 파손 | 실행 전 반드시 검산 |
| **M29 누락** | 부동 홀더 없으면 탭 파손 | 동기 탭핑 시 M29 필수 |
| **하부 구멍 직경 오류** | 탭 파손(작을 때) / 나사산 불량(클 때) | §5 표 참조, 소재별 보정 |
| **맹구멍에서 Z 과도** | 탭 저부 충돌 파손 | Z = 탭 유효 나사 깊이 + 안전 마진 |
| **냉각수 부족** | SUS·알루미늄 응착 → 탭 파손 | M08 필수, SUS는 탭핑 전용유 권장 |
| **G80 누락** | 이후 이동이 탭핑 사이클 실행 | 항상 `G80` 명시 |
| **역탭(LH) 요구 시 G84 사용** | 나사산 역방향 오류 | 좌나사는 **G74** (역탭핑 사이클) |

## 7. 소재별 탭핑 주의사항 ★★☆

| 소재 | 주의사항 | 권장 조건 |
|---|---|---|
| **S45C** | 연성 — 나사산 형성 양호 | 표준 RPM, 수용성 쿨런트 |
| **SUS304** | 가공경화 심함 — 탭 파손 빈발 | RPM 낮춤 (300~500), 탭핑 전용유, 불연속 피딩 지양 |
| **알루미늄** | Al-탭 응착 위험 | DLC·ZrN 코팅 탭 권장, 고속 가능 (800~1,200 RPM) |
| **주철** | 건식 또는 에어 블로우 | 고속 가능 (600~1,000 RPM) |
| **초경** | 탭핑 불가 (경도 HRC 60+) | EDM 또는 레이저 나사 가공 필요 |

> 출처: Smid 2008 Ch.21 §21.3 / [[sus304]] §5.3 / [[알루미늄]] §6.4

## 9. 컨트롤러별 변종 ★★☆

### 9.1 FANUC 표준

위 §2 문법대로. M29 동기 탭핑 모드 필수.

### 9.2 Siemens (SINUMERIK 840D)

```
CYCLE84(RTP, RFP, SDIS, DP, DPR, DTB, SDAC, MPIT, PIT, POSS, SST, SST1)
```

- MPIT: 미터나사 피치 (M3 입력 시 피치 자동 계산)
- PIT: 직접 피치 지정 (mm/rev)
- Siemens는 피치를 직접 입력 → F 계산 실수 방지

[출처: Siemens SINUMERIK 840D sl Programming Manual §2.8]

### 9.3 HAAS

FANUC와 거의 동일. `M29` 대신 `M29` 또는 HAAS 전용 `G84` 내장 옵션.

### 9.4 Mazak (EIA 모드)

FANUC 호환 G84. M29 동기 탭핑 지원.
