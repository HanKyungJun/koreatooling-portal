# FANUC 매크로 변수 (Custom Macro B Variables)

> **Custom Macro B**: FANUC CNC에서 변수·연산·제어 흐름(IF/WHILE)을 사용해 범용 프로그램을 작성하는 기능.  
> 볼트 홀 원형 패턴, 반복 가공 사이클, 계측 후 보정 등에 활용합니다.
>
> ★★★ = ISO 표준·제조사 매뉴얼 직접 근거 | ★★☆ = 산업 통례 | ★☆☆ = 현장 관찰

---

## 1. 변수 종류 — 3가지 ★★★

FANUC 변수는 번호 범위에 따라 **로컬·공통·시스템** 3종으로 구분됩니다.

| 종류 | 번호 범위 | 특성 | 전원 OFF 후 |
|------|----------|------|------------|
| **로컬 변수** | #1 ~ #33 | 매크로 서브프로그램 내부 전용 | 소거 (#0) |
| **공통 변수 (휘발)** | #100 ~ #149 | 프로그램 간 공유 가능 | 소거 (#0) |
| **공통 변수 (비휘발)** | #500 ~ #531 (또는 #999) | 전원 OFF 후에도 유지 | **유지** |
| **시스템 변수** | #1000 ~ | 기계 상태·좌표·공구 보정 접근 | 컨트롤러 관리 |

> **비휘발 범위**: 컨트롤러 파라미터에 따라 #500~#999 또는 더 넓을 수 있음. 사용 전 매뉴얼 확인 필요.  
> (추정값 — 기계별 설정 확인 필수)

[출처: FANUC B-64604EN §14 Custom Macro]

## 2. 로컬 변수 (#1 ~ #33) ★★★

매크로 서브프로그램(O번호) 내부에서만 유효. 호출 시 인수로 전달됩니다.

| 변수 | G65 인수 문자 | 대응 주소 |
|------|-------------|---------|
| #1 | A | A |
| #2 | B | B |
| #3 | C | C |
| #4 | I | (없음) |
| #5 | J | (없음) |
| #6 | K | (없음) |
| #7 | D | D |
| #8 | E | E |
| #9 | F | F |
| #11 | H | H |
| #13 | M | M |
| #17 | Q | Q |
| #18 | R | R |
| #19 | S | S |
| #20 | T | T |
| #21 | U | U |
| #22 | V | V |
| #23 | W | W |
| #24 | X | X |
| #25 | Y | Y |
| #26 | Z | Z |

> #10, #12, #14~#16은 사용 불가(예약). G, L, N, O, P는 인수 불가.

[출처: FANUC B-64604EN §14.3 Argument Designation]

## 3. 공통 변수 (#100 ~ #999) ★★★

프로그램 간 데이터 공유에 사용. 전원 OFF 후 유지 여부로 두 그룹으로 나뉩니다.

### 3.1 사용 예시

```g-code
#100 = 50.0          ← X 시작 위치 저장
#101 = #100 + 10.0   ← 연산
G00 X#100 Y#101      ← 변수로 좌표 지정
```

### 3.2 용도별 권장 할당 (사내 경험값)

> 아래는 추정값 — 사내 표준 정해지면 decisions.md에 등록 권장

| 번호 | 용도 예시 |
|------|---------|
| #100~#109 | 임시 계산용 (전원 OFF 시 소거) |
| #110~#149 | 측정값·보정값 임시 저장 |
| #500~#509 | 공구 보정 오프셋 (비휘발 보존) |
| #510~#519 | 원점 좌표 보조 저장 |
| #520~#531 | 반복 가공 카운터·설정값 |

## 4. 시스템 변수 (#1000~) — 주요 항목 ★★★

시스템 변수를 통해 기계 상태, 공구 보정, 좌표값을 읽거나 씁니다.

### 4.1 공구 보정 관련

| 변수 | 내용 | R/W |
|------|------|-----|
| #2001~#2200 | 공구 길이 보정 (H01~H200) | R/W |
| #2201~#2400 | 공구 반경 보정 (D01~D200) | R/W |

```g-code
#2001 = #2001 + 0.05    ← H1 공구 길이 보정값 0.05mm 증가 (마모 보정)
```

### 4.2 현재 위치 (읽기 전용)

| 변수 | 내용 |
|------|------|
| #5001 | 마지막 블록 X 좌표 (공작물 좌표계) |
| #5002 | 마지막 블록 Y 좌표 |
| #5003 | 마지막 블록 Z 좌표 |
| #5021 | 현재 X 위치 (기계 좌표계) |
| #5022 | 현재 Y 위치 |
| #5023 | 현재 Z 위치 |

### 4.3 공작물 좌표계 오프셋

| 변수 | 내용 |
|------|------|
| #5221~#5223 | G54 X/Y/Z 오프셋 |
| #5241~#5243 | G55 X/Y/Z 오프셋 |
| #5261~#5263 | G56 X/Y/Z 오프셋 |
| #5281~#5283 | G57 X/Y/Z 오프셋 |
| #5301~#5303 | G58 X/Y/Z 오프셋 |
| #5321~#5323 | G59 X/Y/Z 오프셋 |

### 4.4 기타 자주 쓰는 시스템 변수

| 변수 | 내용 | R/W |
|------|------|-----|
| #3000 | 알람 발생 (값 = 알람 번호) | W |
| #3001 | 밀리초 타이머 (전원 ON 이후 ms) | R |
| #3002 | 시간 타이머 (h 단위) | R |
| #3003 | 단일 블록·이송 정지 제어 | R/W |
| #3004 | 이송 오버라이드·급속 제어 | R/W |
| #4001~#4120 | 모달 G코드 현재 값 | R |

## 5. 산술·논리 연산 ★★★

### 5.1 기본 연산

| 표현 | 의미 |
|------|------|
| `#i = #j + #k` | 덧셈 |
| `#i = #j - #k` | 뺄셈 |
| `#i = #j * #k` | 곱셈 |
| `#i = #j / #k` | 나눗셈 |
| `#i = SIN[#j]` | 사인 (도 단위) |
| `#i = COS[#j]` | 코사인 |
| `#i = TAN[#j]` | 탄젠트 |
| `#i = ATAN[#j]` | 아크탄젠트 |
| `#i = SQRT[#j]` | 제곱근 |
| `#i = ABS[#j]` | 절대값 |
| `#i = ROUND[#j]` | 반올림 |
| `#i = FIX[#j]` | 소수점 이하 버림 |
| `#i = FUP[#j]` | 소수점 이하 올림 |

> ⚠️ FANUC 삼각함수 인수는 **도(degree) 단위**. 라디안 아님.

### 5.2 비교 연산자

| 연산자 | 의미 |
|--------|------|
| `EQ` | = (같음) |
| `NE` | ≠ (다름) |
| `GT` | > (초과) |
| `GE` | ≥ (이상) |
| `LT` | < (미만) |
| `LE` | ≤ (이하) |

## 6. 제어 흐름 (IF / WHILE) ★★★

### 6.1 IF문

```g-code
IF [조건] GOTO N번호        ← 조건 참이면 지정 블록으로 점프
IF [조건] THEN #i = 값      ← 조건 참이면 대입 (0i 이상)
```

**예시: 카운터 기반 반복**

```g-code
#100 = 1                   ← 카운터 초기화
N10 G81 X[#100*10] Y0 Z-10 R3 F150   ← X=10, 20, 30...
#100 = #100 + 1
IF [#100 LE 5] GOTO N10    ← 5회 반복
G80
```

### 6.2 WHILE문

```g-code
WHILE [조건] DO m           ← 조건 참인 동안 반복 (m = 1, 2, 3)
  ...
END m
```

**예시: 원형 볼트 홀 패턴**

```g-code
#100 = 0                    ← 시작 각도 (도)
#101 = 50.0                 ← 반지름 (mm)
#102 = 6                    ← 구멍 수
#103 = 360 / #102           ← 각도 간격

WHILE [#100 LT 360] DO 1
  #110 = #101 * COS[#100]   ← X 위치
  #111 = #101 * SIN[#100]   ← Y 위치
  G81 X#110 Y#111 Z-12 R3 F150
  #100 = #100 + #103
END 1
G80
```

[출처: FANUC B-64604EN §14.5 Control Commands]

## 7. G65 / G66 — 매크로 호출 ★★★

### 7.1 G65 — 단순 매크로 호출

```g-code
G65 P(O번호) (인수...)
```

- 지정 O번호 서브프로그램을 1회 호출
- 인수 → 로컬 변수 #1~#26 전달
- 호출 완료 후 원래 프로그램 복귀

**예시**

```g-code
G65 P9001 X50.0 Y30.0 Z-12.0 F150   ← O9001 호출, X→#24, Y→#25, Z→#26, F→#9
```

### 7.2 G66 — 모달 매크로 호출

```g-code
G66 P(O번호) (인수...)   ← 모달 시작: 이후 이동 블록마다 자동 호출
G67                       ← 모달 취소
```

- X/Y 이동 블록마다 자동으로 매크로 실행
- 고정 사이클 대용 커스텀 사이클에 활용

## 8. #0 (Null 변수) ★★★

```g-code
#100 = #0     ← #100을 빈 값(null)으로 초기화
IF [#100 EQ #0] GOTO N100  ← 변수가 미설정 상태인지 확인
```

- `#0`은 "미정의" 또는 null을 의미하는 특수 변수
- 변수가 설정되지 않았을 때 `#0`을 반환
- 매크로 인수가 생략되었는지 확인하는 데 사용

## 9. 자주 발생하는 실수 ★★☆

| 실수 | 결과 | 대응 |
|------|------|------|
| **삼각함수 라디안 입력** | 계산 오류 | FANUC은 도(°) 단위. `SIN[90]` = 1 |
| **#500 값 무심코 덮어쓰기** | 비휘발 데이터 영구 변경 | 비휘발 변수 사용 전 용도 확인 |
| **공통·로컬 변수 혼동** | 서브프로그램에서 기대값 없음 | 로컬(#1~#33)은 G65 인수로만 전달 |
| **WHILE 무한루프** | 기계 정지 불가 | 종료 조건 반드시 검증 후 실행 |
| **시스템 변수 쓰기** | 보정값·좌표 임의 변경 위험 | 쓰기 가능 변수 목록 사전 확인 |
