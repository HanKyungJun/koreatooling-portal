# 이카운트 ERP 사용법 (재연마 업무 프로세스)

> 신뢰도: 사내 경험값. 출처: [INT-TOOLKOREA-PRODMANUAL-2026] §2 ERP 사용법 (p97~138)
> 이 페이지는 재연마 업무 흐름 상의 ERP 조작 절차만 다룹니다. 매출·거래처 관련 **금액·단가는 기록하지 않습니다** (CLAUDE.md §4 정보 분류 원칙).

---

## 1. 수주작성 — 재연마 수주 등록

1. 신규 클릭(단축키 `Ctrl+N`)으로 작성 시작
2. 다음 항목 입력:
   - 납품처(거래처 – 매출처): 예 코리아툴링(100000)
   - 수주사업장(코고툴), 수주일자(입고일), 납기일자(입고+10일)
   - 고객(성함·실제 유저 업체명·숫자) — **동일 날짜 거래처 중복 회피 목적**
   - 품목코드 (품목코드 또는 품목명으로 검색 → 품목선택 내역에 순서대로 담기)
3. R값/각도, 코팅, 수주량 작성 → 저장(`Ctrl+S`)

---

## 2. 작업계획 — 생산지시 처리 등록

1. 조회 클릭 → 품목명 확인 → 선택 클릭 → 생산지시 클릭
2. 생산지시 등록 창에서 선택한 품목이 자동 로드됨 — 지시 수량·지시일자·완료예정일 확인 후 저장

---

## 3. 공정등록 — 생산실적·작업관리 등록

- **생산실적 등록**: 계획 칸 체크 확인 후 저장
- **작업관리 등록**: 조회 → 작업 품목 더블클릭 → 계획 칸 체크 확인 후 저장
- **작업지시 공정현황**의 공정(NC, 코팅) 클릭 → 작업실적 등록에서 신규 클릭 → 양품 수량 기입 후 저장. **불량내역등록**은 연마불가 수량 기입 후 저장 (권장 순서: 불량 제품 우선 기입 → 실적 등록)

---

## 4. 출고등록 — 재연마 출하 등록

경로: `[생산]` → `[생산관리]` → `[재연마수주 출하처리]`

1. 출고 업체의 수주번호 입력 → 조회
2. 제품 확인 후 선택박스 체크 → 출하처리 버튼 클릭
3. **재연마 출하 등록** 화면에서 출하일자(출고일)·사업장(코고툴)·출하창고(안성 → 구로)·품목정보 확인 후 저장

### 4.1 거래처 유형별 분기

| 거래처 유형 | 납품처/매출처 관계 | 거래명세표 처리 |
|---|---|---|
| **코고툴 거래처** | 납품처 = 매출처 (동일) | [거래처명–코고툴]로 거래명세표 클릭 → 인쇄 |
| **코리아툴링 거래처** | 납품처(거래처) ≠ 매출처(코리아툴링) | [거래처명]으로 다음 화면 이동 |

- 거래명세서는 업체명·제품·수량·단가 순으로 확인 후 프린트.
- **코리아툴링(매출처) 업체**는 추가로 `영업–수주관리–수주등록` 진행 필요 → 재연마출하 버튼으로 등록된 납품처·품목 확인 후 선택 체크·적용하여 불러오기
- 불러온 제품의 납품처·매출처 입력 → 전체 체크(우클릭) → 구로창고 변경 클릭 → 할인율(0.75) 기입 후 버튼 클릭 → 적용된 단가·수량·출하창고(구로창고) 확인 후 저장
- 전체 체크 후 **구매발주** 클릭 → 구매발주 등록으로 이동 → 매입처: 코고툴(101434) 기입, 발주사업장 코고툴 선택 → 저장
- `구매–자재입고–발주입고처리`로 이동 → 코고툴(101434) 조회 → 발주정보 확인 후 전체(또는 개별) 선택 → 입고처리
- 사업장을 코리아툴링으로 변경 후 저장
- `영업–출하관리–수주출하처리` 진행 → 출하창고: 안성창고 → 구로창고로 변경 → 조회
- 전체 체크 → 출하처리 클릭 → 출하일자·매출일자·납품처·매출처·품목정보 확인 후 저장
- 직전 화면 조회하여 불러오기 → 거래명세표 클릭 → 거래명세서 내역(출하일·거래처·품목·수량·단가) 확인 후 프린트

## 5. 구매관리

### 5.1 구매발주 등록

경로: `[구매]` - `[구매발주]` - `[구매발주 등록]`

1. `[신규]`(`Ctrl-N`) 새로 열기 / `[조회]`(`Ctrl-Q`) 내역 확인 — 사업장·발주기간·거래처·발주담당자·메이커·품목코드로 필터링
2. `[매입처]` 입력 → `[구매발주 품목]` 흰 바탕 더블클릭 또는 `[+]`로 행 추가 → 품목코드 입력란 돋보기 클릭 → 검색창에서 품목코드·품목명·키워드·거래처로 검색 → 제품 더블클릭 → 품목선택 내역에 담고 적용
3. 리스트 확인(품목코드·수량·단가) → 저장 → 발주번호 확인

### 5.2 발주입고 등록

경로: `[구매]` - `[자재입고]` - `[발주입고처리]`

1. 납품처 또는 발주번호 입력 → 조회
2. 발주정보 목록에서 발주번호·납품처·품목 확인 → 선택 체크 → 입고처리 클릭
3. **구매입고 등록** 화면 자동 표시 — 입고품목(품목코드·입고수량·단가), 입고정보(사업장·매입처·입고일자) 확인 후 저장 → 입고번호 확인 → 지류 거래명세표 날짜 위에 기입

---

## 6. 품목등록 — 품목 코드 등록

경로: `[개발]` - `[품목관리]` - `[품목등록]`

- 품목코드·품목명·정가 입력, 대분류(재연마), 공급구분(생산), 메이커(코고_재연마) 선택 후 저장
- ⚠️ 품목코드 작성은 품목코드표 참고
- ⚠️ **드릴을 제외한 나머지 품목의 매출 할인율은 0.63**으로 한다

---

## 7. 거래처등록

경로: `[기준정보]` - `[거래처관리]` - `[거래처 등록]`

- 거래처코드·거래처명·매출담당 입력 후 저장
- 예: 코고툴 업체 — 업체명 "코고툴", 매출담당 한경준

---

## 8. 판매현황

경로: `[영업]` - `[매출관리]` - `[목표대비 달성 현황]`

- 기준년월 기준으로 작년도 비교년월을 기입 → 조회 → 생산팀 클릭하여 금액 확인
- ⚠️ 매출 금액은 CLAUDE.md §4 원칙에 따라 위키에 직접 기록하지 않음 — 조회 경로만 기록.
