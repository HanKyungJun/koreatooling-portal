# ANCA e-Sharp 사내 적용 체크리스트 — 즉시 가능 3항목 (2026-05)

> 본 페이지는 본 위키에 정착된 [[anca-esharp-index|ANCA e-Sharp 6개 자료]]의 권장값을 **사내 ANCA tool grinder + 보유 휠 5종** 환경에서 **1주 내 즉시 적용 가능한 3가지 액션**으로 변환한 운영 가이드입니다.
>
> 신뢰도: 권장 출처 = **★★★★☆** (ANCA 1차 자료). 사내 측정값 = **★** (현장 실측 양식, 한경준님 채움).
>
> **3가지 즉시 가능 항목** (투자·구매 불요, ANCA 머신 기본 기능 활용):
> 1. **휠 밸런싱 (iBalance 활성화)** — Richardson 2022 / 머신 기본 탑재
> 2. **MRR 모니터링 (Q'w + 스핀들 파워)** — Zaiser 2022 / Graf 2011 / 시뮬레이션 + 운영 점검
> 3. **칠러 ±1°C 점검** — Mulder 2024 Tip 1 / 쿨란트 시스템 점검

---

## 1. 적용 우선순위 — 의존 관계 그래프

```
[① 칠러 ±1°C 점검] ─────┐
       (환경 안정 확보)    ├──> [② iBalance 측정] ──> [③ MRR 모니터링]
                          │     (휠 진동 제거)        (운영 데이터 축적)
                          │
[④ 운영 기준값 결정] ◄────┘
       (보유 휠 5종에 적용)
```

**순서 권장 근거**:
- ①을 먼저 하지 않으면 ②·③의 측정 결과가 온도 영향을 받음 → 데이터 신뢰성 저하
- ② iBalance는 ③ MRR 측정 시 진동 노이즈 제거
- ③ MRR은 누적 데이터 축적 필요 → 가장 마지막 시작, 가장 오래 지속

## 2. 항목 ① — 칠러 ±1°C 점검 (Tip 1, Mulder 2024) ★★★

### 2.1 학술 근거

> "Chilling the coolant is important in maintaining stability and accuracy in production. Using a chiller that can maintain temperatures to **1°C** will help with consistency and quality while mitigating waste." — Kaine Mulder (ANCA, 2024)

출처: [[에너지효율-연삭-7가지팁]] §2 Tip 1

### 2.2 사내 체크리스트

| # | 작업 | 측정 도구 | 양식 |
|---|------|---------|------|
| 1 | 현재 칠러 모델·제조사 확인 | 명판·매뉴얼 | 모델: _______ / 제조사: _______ |
| 2 | 칠러 설정 온도 확인 | 컨트롤 패널 | 설정: _____ °C |
| 3 | 작업장 주변 온도 측정 (계절·시간별 3회) | 디지털 온도계 | 아침: _____ / 점심: _____ / 저녁: _____ °C |
| 4 | 칠러 출력 온도 측정 (입구·출구) | 접촉식 온도계 | 입구: _____ / 출구: _____ °C |
| 5 | 1시간 동안 출구 온도 변동 (Δ) | 5분 간격 12회 | 최저: _____ / 최고: _____ / Δ = _____ °C |
| 6 | 칠러 설정 vs 주변 온도 일치? | 비교 | ✅ ±2°C 이내 / ❌ 차이 ____°C |
| 7 | A/C 캐비닛 설정 (있는 경우) | 패널 | 현재: _____ °C / 35°C 이상? Y/N |

### 2.3 판정 기준 (Mulder 2024 권장)

| 측정값 (Δ) | 판정 | 조치 |
|----------|------|------|
| Δ ≤ 0.2°C | 🟢 정밀 가공급 | 그대로 유지 |
| 0.2 < Δ ≤ 0.5°C | 🟢 우수 | 그대로 유지 (정밀 응용 필요시 0.2°C로 강화) |
| 0.5 < Δ ≤ **1.0°C** | 🟡 **Mulder 권장 최소 충족** | 정밀 응용 필요시 칠러 업그레이드 검토 |
| Δ > 1.0°C | 🔴 부적합 | **칠러 점검·수리 또는 교체** |

### 2.4 환경 평형 설정 (Mulder 2024 핵심)

> "We should not be **fighting the coolant** but trying to **equalise the machine with its environment**."

- 작업장 온도 제어 환경 (공장 내) → **칠러 설정 = 주변 온도와 동일**
- 비제어 환경 → 주변 + 안정성 마진

**액션**: 위 §2.2 표 #3 (주변 온도)와 #2 (칠러 설정)을 비교 → 일치 안 하면 칠러 설정 변경

### 2.5 기록 위치

본 페이지 §6.1 사내 측정 결과 표에 기록.

### 3.3 보유 휠 5종 iBalance 측정 절차

**측정 시점**:
- 신규 휠 장착 시
- Dressing 직후 (휠 형상 변화 후)
- 충돌·낙하 등 휠 손상 의심 시
- **정기 측정**: 매주 1회 (운영 안정 후 월 1회로 완화 가능)

**측정 절차** (Richardson 2022 §3.1):
1. 휠 팩 머신에 장착
2. iBalance 실행 (서보 드라이브 센서 → 모터 전류 자동 감지)
3. 화면에 표시된 **불균형 방향·무게량** 확인
4. 휠 너트 끝에 권장 위치·무게로 웨이트 추가
5. iBalance 재실행 → 불균형 해소 확인 (≤ 권장 임계값)

## 4. 항목 ③ — MRR 모니터링 (Zaiser 2022 + Graf 2011) ★★★

### 4.1 학술 근거

> "Grinding wheels perform best when used in the manufacturer's recommended MRR range. **High MRR than Qmax** causes rapid wheel breakdown while grinding on **too low MRR; lower than Qmin** can lead to wheel loading and wheels becoming dull. The wheel achieves the **legendary self-sharpening state** when grinding in the optimal range." — Vadim Zaiser (ANCA, 2022)
>
> 출처: [[MRR-기반-연삭공정-분석]] §3.1

### 4.2 사내 적용 Q'w 권장값 (Walter Graf 2011)

[[연삭-테스트-방법]] §4.6에서 도출한 본 위키 사용 시나리오 직접 적용값:

| 응용 | Q'w 권장 (mm³/(mm·s)) | 사내 보유 휠 적용 |
|------|---------------------|----------------|
| **초경 엔드밀 플루팅** | **6 ~ 12** ★ | [[휠-5도-Ø125-1-2]] (D10/D4 평 End Face Gash) |
| | | [[휠-45도-Ø125-1-2]] (D12 평/D6 코너R End Face Gash) |
| | | [[휠-20도-Ø125-1-1]] (D6 볼 Gash) |
| | | [[휠-컵-Ø100-1-1]] (D6 볼 날 가공) |

> **Qmin = 6 / Qmax = 12 mm³/(mm·s)** — 사내 초경 엔드밀 가공의 안전 운영 범위.

### 4.3 Q'w 계산 (Walter Graf 2011 §3.2)

$$
Q'_w = \frac{V_w \times A_e}{60} \quad \text{[mm³/(mm·s)]}
$$

- $V_w$ = 공작물 이송속도 (mm/min)
- $A_e$ = 연삭 깊이 (mm)

#### 4.4.2 판정 기준

| Q'w 값 (mm³/(mm·s)) | 판정 | 조치 |
|--------------------|------|------|
| < 6 (Qmin 미만) | 🟡 **휠 둔화·로딩 위험** | Vw 증가 또는 Ae 증가 → Q'w 6 이상으로 |
| 6 ~ 12 (Sweet Spot) | 🟢 **자생작용 영역** | 그대로 유지 |
| 12 ~ 18 (Qmax 부근) | 🟡 주의 | 단기 허용, 휠 마모 모니터링 |
| > 18 | 🔴 **휠 급속 마모 위험** | 즉시 Vw 또는 Ae 감소 |

### 4.5 스핀들 파워 모니터링 (Zaiser 2022 §3.4)

#### 4.5.1 방법

> "Plotting **spindle power** on the machine over the **pre-calculated MRR** from simulation, the graphs should correlate, as grinding off the same amount of material requires the same amount of energy."

- 시뮬레이션 MRR + 실측 스핀들 파워 = 동일 패턴이어야 함
- 시간 경과 따라 동일 MRR에서 스핀들 파워 ↑ → **휠 마모 신호** → dressing 필요

#### 4.5.2 사내 점검 양식 (Walter Graf 2011 §3.1 8번 Load 미터와 연계)

| 일자 | 공구 | 휠 | Q'w | **스핀들 부하 (%)** | Load 차이 (vs 1주 전) | 조치 |
|------|------|-----|-----|---------------------|--------------------|------|
| __-__-__ | __ | __ | __ | _____ % | 기준값 | — |
| 일주 후 | __ | __ | __ | _____ % | + ____ % | 증가 시 → dressing |

> Walter Graf 2011 §5.1 Load 미터 단계 규칙: 20% 정상 / 60% 도달 시 미세 증가만 / 한계 도달 시 20% 감소 후 안정화.

### 4.6 CIM3D 시뮬레이션 활용 (Zaiser 2022 §2)

**사내 점검**:
- 현재 CIM3D 버전: _____ (V9 권장)
- MRR 타임라인 차트 기능 활성 여부: Y / N
- 활성 시: 신규 공구 가공 전 시뮬레이션 → MRR 타임라인 차트로 Qmax 초과 시점 사전 식별

> 본 자료의 핵심: **CIM3D는 신규 공구의 MRR을 사전 시뮬레이션**으로 검증 → 실가공 시 충돌·과부하 방지.
