## 5. 불량 증상 체크리스트

### 버닝 (Burning)
- [ ] 가공면 변색 (갈색/청색)
- [ ] 원주속도 20 m/s 미만 확인
- [ ] 드레싱 주기 초과 여부 확인
- [ ] Coolant 공급 불량 여부 확인

### 드래그 마크 (Drag Mark)
- [ ] 원주속도 부족 또는 glazing 진행으로 인한 마찰 증가 가능성 확인
- [ ] Feed 역전 구조 여부 확인
- [ ] 휠 로딩 여부 확인

### 휠 로딩 (Loading)
- [ ] 스핀들 부하 낮음에도 표면 불량
- [ ] 드레싱 후 즉시 개선 여부 확인
- [ ] Grit 변경 검토 필요

### 치수 불량
- [ ] DOC 설정값 재확인
- [ ] 휠 마모량 보정 여부 확인

> **진단 요약 원칙**
> 1. 원주속도 < 20 m/s이면 Feed 조정보다 RPM, 휠 직경, 휠 상태를 먼저 함께 검토
