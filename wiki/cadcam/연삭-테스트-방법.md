# 연삭 테스트 방법 — 6단계 워크플로우 (Walter Graf / Winterthur 2011)

> 본 페이지는 **Walter Graf** (Winterthur Technology Group CMO, 2011 당시)가 ANCA *e-Sharp News* 2011년 12월호에 게시한 *"효과적인 연삭 테스트 구성 방법(How to run a Grinding Test)"* 한국어 원문을 정리하고, 본 위키의 정착된 1차 출처([[휠RPM-정책-검증-노트]] / Norton Winter Catalog 2023 / [[tools/wheels/catalog/index|홍익다이아 카탈로그]])와의 **정합 주석**을 추가한 자료입니다.
>
> 원문: <https://machines.anca.com/e-sharp-news/december-2011/how-to-run-a-grinding-test?lang=ko-KR>
>
> 신뢰도: **★★★★☆** (Tier 1.5 — 제조사 1차, 글로벌 메이저 연삭 휠 제조사 CMO 직접 작성).
>
> 적용 범위: 크립피드 연삭, **밀링 커터·탭 플루팅 연삭**, 초경·HSS·공구강·니켈합금 등 — 본 위키의 ANCA tool grinder 응용 영역과 직접 호환.

---

## 1. 6단계 공정 순서

```
┌─ 1. 목적 (Define Objectives)
├─ 2. 준비 (Preparation)
├─ 3. 테스트 (Test Execution)
├─ 4. 평가 (Evaluation)
├─ 5. 기록 (Record)
└─ 6. 정보 공유 (Share)
```

**좋은 엔지니어링 습관**: 한 번에 변수 하나씩 변경 → 변화 관찰 → 결과 평가 → 다음 변경.

---

## 2. 단계 1 — 목적 (Define Objectives)

먼저 찾고자 하는 목표가 분명해야 합니다. 일부 목표들은 서로 상반될 수 있음 (예: 최대 단위시간당 연삭량 + 공정안정 향상 동시 달성).

### 2.1 목적 예시

| # | 목적 | 응용 시나리오 |
|---|------|------------|
| 1 | **현재 공정 문제 해결** | 버닝·표면조도·치수 안정 등 |
| 2 | **생산 공정 안정** | 휠 수명 증가, 변동성 감소 |
| 3 | **단위시간당 연삭량 증가** | 사이클타임 단축 |
| 4 | **새로운 기준 테스트** | 신규 휠·신규 본드 도입 |
| 5 | **같은 결과 반복 (재현성)** | 양산 표준화 |

---

## 3. 단계 2 — 준비 (Preparation)

현재 공정에 적용 시 아래 사항을 **정확히 파악·기록**:

### 3.1 핵심 9개 변수

| # | 변수 | 단위 / 정의 |
|---|------|------------|
| 1 | **Q'w** (Q-prime, 단위시간당 연삭량) | `Q'w = (Vw × Ae) / 60` [mm³/(mm·s)] |
| 2 | **Vs** (휠 원주속도) | m/s |
| 3 | **Vw** (이송 속도) | mm/min |
| 4 | 총 연삭 여유, Ae (연삭 깊이), 연삭 횟수 (pass 수) | mm, 회 |
| 5 | 절삭유 노즐 위치·상태 | 점검 + 사진 기록 |
| 6 | 절삭유 온도 (아침·저녁), 유량 | ℃, L/min |
| 7 | 드레싱 변수: Qs (속도비), Ad (깊이), 동시/개별 | — |
| 8 | 연삭부하 Load 미터 (황삭 최대값) | % |
| 9 | 공회전 시간 (실제 연삭 = 사이클의 20-30%만 차지) | sec |

### 3.2 ★ 핵심 인사이트 — Q'w 공식

```
              Vw [mm/min] × Ae [mm]
   Q'w   =   ─────────────────────       [mm³ / (mm · s)]
                       60
```

> 출처: Walter Graf (Winterthur 2011) — 본 자료 §준비 §1.
> 학술 근거: Malkin & Guo (2008) *Grinding Technology* (2nd ed.) Ch.5 — Q'w (단위 휠 폭당 재료 제거율) 정의. Marinescu et al. (2016) Ch.4 정합.

### 3.3 ⚠️ 공회전 시간 단축의 우선순위

> **"실제 연삭 시간은 총 사이클타임의 20-30%밖에 안 되는 경우가 종종 있습니다. 무리하게 이송 속도를 증가시키기보다 이런 불필요한 공회전 시간을 줄이는 것이 더 낫습니다."**

— 이송속도 증가 전 **연삭 전 이송·연삭 후 추가 이동거리** 점검이 첫 번째 액션.

## 4. 단계 3 — 테스트 (Test Execution)

### 4.1 연삭 입자·본드 선택 ★★★

| 응용 | 권장 입자·본드 |
|------|--------------|
| 크립피드 연삭 (이송 매우 느림) | **비트리 본드 + Al₂O₃ (알루미늄 옥사이드)** |
| 탭 나사산 연삭 | **모노 크리스탈 Al₂O₃** |
| 탭 플루팅 (일반 휠) | **세라믹 입자 + 레진 본드** |
| **초경 절삭 공구 연삭** | **NaxoForce 하이브리드 / 고성능 레진** |
| 공구강·HSS 엔드밀·밀링커터 | **CBN + 하이브리드 / 레진 / 비트리** |

> 출처: Walter Graf (Winterthur 2011) §연삭 입자와 본드 선택.

#### 본 위키 정합 주석

| 본 자료 권장 | 본 위키 매핑 |
|------------|---------|
| 초경 → NaxoForce / 고성능 레진 | [[홍익다이아-본드-체계]] Resin/Hybrid 일치. NaxoForce는 Winterthur 본드 브랜드 (현재 3M Winterthur). 홍익다이아 Resin/Hybrid가 직접 대체 가능 |
| 공구강·HSS → CBN | [[홍익다이아-그릿-체계]] B 시리즈 (B46~B126) HSS 적용 분류와 일치 |

### 4.2 입자 크기 trade-off — 정량 ★★★

> **"입자 크기를 반으로 줄이면 같은 볼륨에 8배 많은 입자, 동일 접촉면에 4배 많은 입자."**

수학적 근거: 부피 ∝ d³ (8배), 면적 ∝ d² (4배).

| 큰 입자 (D91 등) | 작은 입자 (D15 등) |
|---|---|
| ✅ 마찰 ↓ | ❌ 마찰 ↑ |
| ✅ 절삭유 유입 용이 | ❌ 절삭유 유입 어려움 |
| ❌ 표면조도 거침 | ✅ 표면조도 매끄러움 |
| ❌ 코너R 변형 큼 | ✅ 코너R 정밀 |

→ **"가능한 큰 치수 선택하되 코너반경·표면조도 요구 고려"**.

### 4.3 시작 전 체크리스트 (6항목)

작업자에게 미리 질문:

1. 연삭휠의 형상 변화가 있는지?
2. 버닝·떨림 현상 발생?
3. 공정이 안정적인지?
4. 절삭유가 균일하게 공급되는지?
5. 지그·고정구 견고? 떨림?
6. 연삭 치수가 안정적으로 유지?

### 4.4 휠 체결·검사

- **비트리 본드 휠**: 플라스틱 망치로 살짝 두드려 **맑은 소리** 확인 (크랙 검출)
- 기공이 있는 일반 휠 토크: **20 ft·lb (≈ 27 N·m) 또는 30 N·m**
- **금속 몸체 CBN/다이아몬드 휠**: 토크 렌치 불필요

> ⚠️ 한국어 원문의 "금솟몸체"는 오타 — **금속 몸체**가 정확.

### 4.5 드레싱 변수 ★★★

이전 경험·데이터 없이 새 연삭 작업 시작 시:

| 휠 종류 | 드레싱 깊이 Ad (회전당) |
|--------|---------------------|
| **일반 연삭휠** | **0.5 ~ 1 μm** |
| **CBN 휠** | **0.2 μm** (더 작게) |

- 같은 방향 회전 드레싱, **속도비 Qd = 0.8**
- 형상 드레싱 롤: **오버랩 비율 Ud = 4 ~ 6** (낮을수록 거친 드레싱)
- NaxoForce 본드: 드레싱 가능한 다이아몬드 휠 존재

> 출처: Walter Graf (Winterthur 2011) §드레싱 변수들.

#### 본 위키 정합 주석

| 본 자료 권장 | 본 위키 현황 |
|------------|-----------|
| Ad 0.5-1 μm (일반) / 0.2 μm (CBN) | [[휠-20도-Ø125-1-1]] 등 보유 휠 5종 페이지에 드레싱 변수 미수록 → **보강 가치** |
| Qd 0.8 (같은 방향) | 본 위키 사내 ANCA 운영 표준 정립 필요 |
| Ud 4-6 (형상 드레싱) | 본 위키 ANCA iGrind / ToolRoom RN 워크플로우와 연결 |

### 4.6 Q'w 권장값 매트릭스 ★★★

| 응용 | 시작 Q'w [mm³/(mm·s)] |
|------|---------------------|
| 열처리강 크립피드 연삭 | **5 ~ 10** |
| 항공기용 니켈합금강 크립피드 | **10 ~ 20** |
| 공구강 탭 플루팅 (레진 본드) | **10 ~ 20** |
| **초경 엔드밀 플루팅** | **6 ~ 12** ★ |

> ⚠️ 본 위키 사용 시나리오(**ANCA + 초경 엔드밀**)의 직접 적용값: **Q'w 6-12 mm³/(mm·s)**.

> 출처: Walter Graf (Winterthur 2011) §연삭 변수들.

> ⚠️ 위 수치는 기계·장비 견고성, 공작물 치구 상태, 연삭 재질의 경도·조직에 따라 변동.

### 4.7 ★ 사이클타임 단축 — 변경 우선순위

> 만약 사이클타임 단축이 목적이라서 연삭깊이 vs 이송속도 중 하나를 선택해야 한다면:
>
> **이송속도 증가를 택할 것** (휠이 좀 더 거칠게 공작물에 밀어붙이는 결과).

또한:
- **하향 연삭(down grinding)** 권장 → 연삭력 ↓, 휨·버닝 ↓
- 연삭 pass 수 가능한 최소

## 5. 단계 4 — 평가 (Evaluation)

### 5.1 Load 미터 단계 증가 규칙 ★★★

| 현재 Load | 증가 단계 |
|----------|---------|
| 최고부하의 20% 정도 | **+20%씩 단계적** 이송속도 증가 |
| 60% 도달 | **+10%씩** 미세 증가 |
| 한계 도달 (휠 마모 심해짐 / 버닝 시작) | **-20% 줄여 안정화** |

> 핵심: **"안정된 연삭 공정의 유지"**. 처음과 나중이 균일한 결과여야 함.

### 5.2 결과 관찰 — 휠 반응 진단

**휠 형상이 변경된 경우** — 가능한 원인:

| 증상 | 가능한 원인 | 대응 |
|------|-----------|------|
| 휠 형상 마모 / 변경 | 휠이 너무 푸석푸석함 (soft) | 더 단단한 등급 |
| | **휠 원주속도가 낮음** | **3-5 m/s씩 단계적 증가** |
| | 이송속도가 빠름 | 감소 |
| | 드레싱량 부적당 | Ad·Qd 재검토 |
| | 휠 입자 크기가 너무 큼 | 작게 |

#### 본 위키 정합 주석 — Vc 조정 단계

> 본 자료는 "3-5 m/s씩 단계적 조정"이라는 **상대적 표현**만 사용. **절대 Vc 권장 수치는 제공하지 않음**.
> [[휠RPM-정책-검증-노트]]에 따르면 초경 + Resin Bond Diamond + ANCA 환경의 실사용 대표 Vc 범위는 **17-22 m/s**(최빈 18, Norton Winter 8건) · 사내 운용 상한 25 m/s ⚠️ (2026-08-28 정정: **ANCA 한정은 18~22 m/s**, 17 m/s는 SAACKE 장비 사례 — 8건 전체가 17~22. → [[tools/wheels/index]] §정정). 본 자료의 "3-5 m/s씩 조정"은 **이 범위 내에서의 미세 조정** 가이드로 해석.

### 5.3 버닝 현상 진단

| 진단 단계 | 확인 |
|---------|------|
| 1단계 | 드레싱 후 휠이 **날카로운지** 확인. 드레싱면을 손톱으로 긁어 부드러우면 드레싱 변수 변경 필요. CBN/다이아몬드는 **화이트 스틱** 사용 |
| 2단계 | 절삭유 상태 확인 (온도·농도·유량) |
| 3단계 | **휠 원주속도가 너무 높은가?** → **3-5 m/s씩 단계적 감소** |

### 5.4 휠 수명 ↑ 위한 미세 조정

- 드레싱 깊이 감소 (예: 크립피드 연삭의 연속드레싱 — 회전당 0.8 μm → 0.6 μm)
- 휠이 부스러지거나 버닝이 나는 한도까지 단계적 테스트

## 6. 단계 5 — 기록 (Record)

테스트 후 챠트·도표로 만들고 **각 부품별 연삭 변수 리스트** 업데이트:

| # | 변수 | 기호 | 단위 |
|---|------|------|------|
| 1 | 휠 원주속도 | Vc | m/s |
| 2 | 연삭 깊이 (드레서) | Ad | μm |
| 3 | 이송속도 | Vw | mm/min |
| 4 | 단위 시간당 연삭량 | Q'w | mm³/(mm·s) |
| 5 | 평균 연삭 칩 두께 | Hm | μm |
| 6 | 연삭 거칠기 계수 | Fa | 20~30 |
| 7 | 드레싱 비율 / 드레싱 량 | Qd / Aa | — |
| 8 | 연삭 부하 Load | % | % |
| 9 | 사이클 타임 | Tc | sec |

---

## 7. 단계 6 — 정보 공유 (Share)

테스트 결과를 **데이터베이스로 만들어 동료들과 공유**, 지속 업데이트.

> "이 방법을 기본으로 계속 테스트를 진행하다 보면 휠의 성능을 극대화하면서 연삭 공정의 안정과 경제적 절감을 이룰 수 있습니다." — Walter Graf

## 8. 핵심 공식·기호 정리

### 8.1 공식

| 약어 | 정의 | 단위 |
|------|------|------|
| **Q'w** | (Vw × Ae) / 60 | mm³ / (mm·s) |
| Hm | 평균 연삭 칩 두께 | μm |
| Vd | 형상 드레싱 롤 이송속도 (공식 = f(Vc, r, Ud)) | mm/min |
| **Qd** | 휠과 드레서 롤의 속도비 (Vd/Vc 또는 Vr/Vs) | — |
| **Qs** | 휠과 공작물의 속도비 (Vs/Vw) | — |
| Fa | 연삭 거칠기 계수 (20~30) | — |

### 8.2 기호

| 기호 | 정의 | 단위 |
|------|------|------|
| Ad | 드레서의 pass당 또는 회전당 절삭 깊이 | μm |
| Ae | pass 절삭 깊이 | mm |
| Ds | 연삭 휠 외경 | mm |
| Ns | 연삭 휠 회전수 | RPM |
| Tc | 사이클 타임 | sec |
| Ud | 형상 드레싱 롤 오버랩 비율 | 4~8 |
| Vc | 휠 원주속도 | m/s |
| Vr | 드레싱 롤 원주속도 | m/s |
| Vw | 공작물 이송속도 | mm/min |

> 출처: Walter Graf (Winterthur 2011) §공식 및 사용기호.
