# 공구 도면 · 3D 생성기 (`scripts/tool_gen.py`)

> 요약: 사양 한 줄을 넣으면 A4 공구 도면(DXF · PDF · PNG)과 SolidCraft 3D(.sc · STEP)를 만든다. 실측 — 도면 6 ~ 10 s, 3D 계산(v1.2) 평 0.5 s · 코너 R · 볼 18 ~ 21 s(v1.1 은 43 ~ 87 s), SolidCraft 호출 1번(11-12 손작업 약 19분/종). 부피는 계산값과 −0.017 % 이내. **모양 확인용** — 날 끝 형상 · 홈 끝맺음이 없고, 공구 형상 기준은 ANCA ToolRoom.

## 1. 쓰는 법

Claude 에게 「공구 만들어 줘 EM 4날 D6 d6 L50 Lc9 R0.5 넥5.7×18 헬릭스35」처럼 말한다. Claude 가 아래 순서로 진행한다.

1. 도면: `python scripts/tool_gen.py "<사양>" --tpl "raw/도면 작업/양식/도면양식_A4가로_공구용_v1.dxf" --out outputs/02_도면_3D_CAM/공구생성기 --sc-root <같은 폴더 Windows 경로>` (PC VM 에서 실행, ezdxf · matplotlib 필요)
2. 3D: 만들어진 `<이름>_3d_recipe.json` 의 `stages`(v1.2 는 1개)를 SolidCraft `batch`(commands · expect 그대로)로 한 번 → `screenshot`. 교차가 실패하면 `fallback_stages`(옛 방식, 단계마다 저장)
3. 점검: FreeCAD 에서 STEP 읽기 — 솔리드 2개 · isValid · 부피 · 최적 경계상자

| 사양 항목 | 쓰는 법 | 비고 |
|---|---|---|
| 종류 | `EM` | 엔드밀만(2026-11-12) |
| 날 수 | `4날` · `4F` | 2 ~ 4날 |
| 날경 · 생크경 | `D6` · `d6` | 생크는 항상 d |
| 전장 · 날장 | `L50` · `Lc9` | mm |
| 끝 모양 | 없음 = 평 · `R0.5` = 코너 R · `볼` (R = D/2) | |
| 넥 | `넥5.7×18` | 넥 지름 × 유효장(날 끝 → 넥 끝) |
| 나선각 | `헬릭스35` · `헬릭스35좌` | 기본 오른나선 |
| 선택 | `코어60` (심압 %D) · `테이퍼13` (편측 °) · `C0.3` (생크 끝 모따기) · `넥단직각` · `번호XXX` | 없으면 아래 기본값. v1.2 이전 모양 = `테이퍼15 넥단직각` |
| 홈 단면 (v1.5) | `경사6` (경사각 °, −10 ~ 25) · `홈각55` (홈 = 피치의 %, 30 ~ 85) · `단면원호` (v1.4 까지 원 1개 방식) | 평 끝날만 경사 단면. 코너R · 볼은 원호 단면 자동(§3-D) |

- 성립하지 않는 사양은 파일을 만들지 않고 「불가능」과 이유만 낸다(예: 코너 R ≥ D/2, 넥 ≥ D, 날장 ≥ 전장, 홈끼리 겹침, A4 에 들어가는 ISO 5455 축척 없음). `--check` 는 검사 · 부피 계산만.
- 같은 이름 폴더가 있으면 `_v2` · `_v3` 으로 판을 올린다(덮어쓰지 않음). `--drawing-only <폴더>` · `--recipe-only <폴더>` 는 그 폴더의 도면 · 레시피만 다시 쓴다.

## 2. 만드는 것

| 파일 | 내용 |
|---|---|
| `<이름>.dxf` · `.pdf` · `.png` | 공구용 A4 양식 사본(원본 `raw/` 는 읽기만). 정면도 · 끝면도 · 상세 A(코너 R · 볼) · 치수 · 사양표 · 주기 7줄 |
| `<이름>_3d_recipe.json` | SolidCraft batch 1회분(날부 + 생크 + 저장 + STEP) · 기대 부피 · 예비 `fallback_stages`(홈마다 빼기) |
| `<이름>_사양.json` | 해석한 사양 · 계산값(리드 · 비틀림 · 홈 단면 · 부피) · 축척 시도 기록 |
| `<이름>.sc` · `.step` · `_3D.png` | 3D(솔리드 2개: FluteBody · ShankBody). `_작업/` 에 단계 저장본 |

### 2-1. 도면 규칙

- 축척: ISO 5455 권장값(50 · 20 · 10 · 5 · 2 · 1:1 · 1:2 · 1:5) 중 **그리기 전에** 정면도 · 끝면도 · 상세도 차지 영역을 계산해 표제란 · 개정란 · 사양표 · 주기 · 틀과 겹치지 않는 가장 큰 값 [STD-ISO5455]. 그린 뒤 실제 범위가 틀 안인지 다시 확인.
- 정면도 = 날 끝 왼쪽, 끝면도 = 왼쪽(3각법, 축 높이 맞춤). 끝면도는 날 끝 형상을 생략했으므로 **날부 단면과 같은 모양**(3D 와 같은 홈 원).
- 치수는 ezdxf 로 직접 넣는다(축척 보정 `dimlfac`). 날장 · 유효장 · 전장 · D · 넥 · d h6 · 모따기 · 테이퍼 · 코너/볼 R.
- d 공차 h6 = 0 / −IT6 (ISO 286-2): ≤ 3 → 0.006 · ≤ 6 → 0.008 · ≤ 10 → 0.009 · ≤ 18 → 0.011 · ≤ 30 → 0.013 · ≤ 50 → 0.016 mm [STD-ISO286]. 지시 없는 공차 ISO 2768-m [STD-ISO2768].
- PNG · PDF 는 흰 바탕 · 검정 선. 한글은 맑은 고딕이 없는 PC VM 에서 Noto Sans CJK 로 대신(DXF 글꼴 설정은 양식 그대로 KOR).

### 2-2. 3D · 기본값 (모양 확인용 — 추정값)

| 항목 | 값 | 근거 | 신뢰도 |
|---|---|---|---|
| 홈 단면 | 원 1개(반지름 rf), 중심 거리 a = 심압/2 + rf | 11-12 샘플 방식 | 추정값 |
| 홈 단면 (v1.5, 평 끝날 기본) | 경사면 직선(경사각 6°) + 곡선(바닥 = 심압 원 접함, 원호 4개 근사) · 홈각 = 피치의 55 % · 경사면 바깥 끝 = 심압 → 외경의 15 % 지점 | 학습목록 §1 ③ · [ACA-REN2018-FLUTE] 단면 구성 | 추정값 |
| 2날 | 심압 60 %D · rf 0.35D | SMP-01 | 추정값 |
| 3날 | 심압 62 %D · rf 0.27D | 2 · 4날 중간 | 추정값 |
| 4날 | 심압 65 %D · rf 1.3/6 D | SMP-02 | 추정값 |
| 리드 | π × D ÷ tan β | 기하 | — |
| 비틀림 | 360° × (Lc + 2) ÷ 리드 (z −1 ~ Lc+1 쓸기) · 양수 = 오른나선 | [[cadcam/CAD-3D-프로그램-역할-정의]] §3-1 | 실측 검증 |
| 테이퍼(넥 → 생크, D ≠ d) | 편측 13° (v1.2 까지 15°) | 고객 STEP 4KCR 040 010 250 실물 1건 | 실측 1건 |
| 넥 → 날부 단 | 45° 모따기, 반경 (D − 넥경)/2 · `넥단직각` 으로 끔 | 같은 STEP(반경 0.08) | 실측 1건 |
| 생크 끝 모따기 | d ≥ 8 → C0.5 · d ≥ 4 → C0.3 · 그 밖 C0.2 | SMP-01 · 02 | 추정값 |

부피 계산: 날부 = ∫ [π r(z)² − 날 수 × 겹침넓이(r(z), a, rf)] dz (코너 R · 볼 구간은 Simpson 적분, 나선 비틀림은 단면 넓이를 바꾸지 않음) + 생크 원뿔대 합. 겹침넓이 식은 shapely 다각형과 1 × 10⁻⁷ mm² 안에서 같음(실측 검증).

## 3-C. 보강 v1.4 (2026-11-12, 한경준님 「진행」)

근거: [[cadcam/도면-3D-외부자료-학습목록]] §1 ② · ⑥ · ⑧.

1. **ISO 13399 기호 병기** — 사양표 값 뒤 괄호: NOF · DC · DMM · OAL · APMX(날장) · DN × LU · RE · FHA [VEN-DORMERPRAMET-ISO13399]. `_사양.json` 에 `iso13399` 항목. 도면 생크 표기는 계속 d. 날장 → APMX · 넥 없을 때 LU = 날장은 대응 추정.
2. **생크 d 공차를 치수에 직접** — `d Ø6 h6` 치수 옆에 위 · 아래 편차(0.000 / −0.008)를 쌓아 표기(ezdxf `set_tolerance`) [VEN-EZDXF-DIM].
3. **날경 공차 옵션** — 사양에 `D6e8` 처럼 붙일 때만 D 치수 · 사양표 · 주기에 편차 표기. 지원 등급 h6 · e8, 3 초과 ~ 50 mm(JIS B 0401 = ISO 286 발췌표로 대조 [VEN-MIKI-JISB0401]). 3 mm 이하 · 그 밖 등급은 「불가능 — 표 미대조(확인 필요)」로 멈춘다.
4. 주기 2 = 공차 · 주기 8 끝 = 「사양표 괄호 = ISO 13399 기호」.

## 3-D. 보강 v1.5 — 날 단면 「경사면 직선 + 곡선」 (2026-11-12 ~ 13 KST, 한경준님 「다음 진행」)

1. **평 끝날 기본 단면 변경** — 날 끝(외경) → 경사면 직선(경사각 γ, 기본 6°) → 곡선(심압 원에 닿는 바닥) → 다음 날 랜드. 곡선은 극좌표 코사인 곡선을 원호 4개(3점 원호)로 근사해 SolidCraft 스케치에 그대로 넣는다. 끝면도도 같은 모양.
2. **부피 계산** — 단면이 원이 아니므로 shapely 다각형 ∩ 원판 넓이 적분으로 바꿈(코너 R · 볼 구간 Simpson 그대로).
3. **코너 R · 볼은 원호 단면으로 자동 전환** — 아래 실측대로 경사 단면은 코너 R · 볼 회전체와의 교차(intersect)가 끝나지 않는다. 사양에 `경사N` 을 써도 코너 R · 볼이면 원호 단면으로 만들고, 주기 4 끝에 「코너R·볼 원호 고정」, `_사양.json` 의 `section.fallback` 에 이유를 남긴다.

## 4. 한계 · 주의

1. ⚠️ 주의: 도면 · 3D 는 **모양 확인 · 설명용**이다. 경사각 · 여유각 · 갭 · 끝날 · 홈 끝맺음이 없고 홈 단면은 원 1개로 단순화했다(추정값). (v1.5 부터 평 끝날은 경사면 직선 + 곡선 단면 — 여전히 모양 확인용 추정값, 여유각 · 2차 여유 · 갭 · 끝날 없음. 코너 R · 볼은 원 1개 그대로, §3-D) 연삭 프로그램 · 공구 설계의 근거로 쓰지 않는다 — 원본은 ANCA ToolRoom.
2. 사양표의 소재 · 코팅은 「확인 필요」로 나온다 — 대외로 낼 때는 채우고 검토 · 승인 칸 서명.
3. 3D 는 솔리드 2개(날부 · 생크)로 남긴다 — 합치기는 SolidCraft headless 에서 시간 초과(역할 정의 §4-7, v1.2 에서 다시 시험 안 함).
4. 축척(실측 7종, `plan_layout`): D · d ≤ 10 · L ≤ 100 은 2:1, D12 L75 · D16 L100 · D20 L150 · D6 L120 은 1:1. 축척이 ISO 5455 단계(5 → 2 → 1)로만 바뀌어 1:1 도면은 작다. 소경(D1 d4 L50 → 2:1)은 정면도 날부가 작게 나온다 — 날부 확대 상세는 아직 없음(끝면도만 20:1).
5. 드릴 · 리머 · 테이퍼 엔드밀 · 5날 이상은 아직 없음.
