# 재연마 작업준비 절차 (선별 · 레이저마킹 · 밑작업)

> 신뢰도: 사내 경험값. 출처: [INT-TOOLKOREA-PRODMANUAL-2026] §1 작업준비 (p10~34)
> CNC 가공 단계는 [[cadcam/anca-재연마-작업절차-SOP]] 참고.

---

## 1. 선별

### 1.1 형태별 분류

입고된 엔드밀을 형태별로 분류하는 것이 선별의 첫 단계.

### 1.2 재연마 의뢰서 작성 항목

의뢰업체(실사용업체) / 업체의뢰일 / 입고일 / 작성자 / 수주번호 / Ø(직경) OO × R값 / HSS·초경 구분 / 외주업체 또는 코팅 / 발송일 / 날수

### 1.3 재연마 수주 작성 → 작업지시

수주 작성 후 작업지시는 **날수/크기 → 형상/코팅 → 날짜/수주번호** 순서로 작성한다.

### 1.4 업체 주문과 입고 물품이 다를 때 (대응 절차)

업체 주문과 입고된 엔드밀의 수량·형태가 다르거나, 작업지시 사항이 없거나 모호해서 작업을 진행할 수 없는 경우:

1. 입고된 엔드밀의 개수·형태를 파악해 의뢰내용과 다른 부분 확인
2. 거래관리시스템에서 거래처 전화번호 확인 후 전화
3. 거래처 통화 시 정중한 응대 — "안녕하세요, 코리아툴링 OOO입니다. 재연마 담당자분과 통화 가능한가요?"
4. 재연마 담당자에게 의뢰내용과 실제 내용물의 차이를 설명하고 조치 방법 결정

### 1.5 재연마 기준코드표

품목코드 체계는 [[공구-코어-직경]], [[엔드밀-드릴-규격-이해]] 및 사내 품목코드표 참고(원본: 매뉴얼 p16, 이미지 기반이라 텍스트 미추출 — 원본 슬라이드 직접 참조 필요).

## 2. 레이저마킹

### 2.1 마킹 순서 (6단계)

1. 레이저 마킹기 전원 켜기
2. 프로그램(Ezcad2) 켜기
3. 업체명 입력
4. 초점 맞추기
5. 마킹 부위 미리보기
6. 마킹

### 2.2 상세 절차

| 단계 | 조작 |
|------|------|
| 전원 켜기 | [레이저 튜브] 전원과 [레이저 파워본체] 전원을 켠 뒤 컴퓨터 부팅 |
| 프로그램 실행 | **Ezcad2** 프로그램 실행 |
| 파일 열기 | [파일열기] 클릭 |
| 파일 실행 | [재연마 마킹] 파일 실행 |
| 업체명 입력 | 왼쪽 [Text] 항목 더블클릭 → "코.(업체명)" 입력, 마킹 전 "선택마킹" 체크 |
| 초점 맞추기 | 샹크별 마킹 기준표에 따라 레이저튜브 높이를 해당 위치에 맞게 조정 |
| 마킹 부위 확인·마킹 | 마킹할 엔드밀을 올려놓고 **[F1]** = 미리보기(마킹될 부위 확인) → **[F2]** = 마킹 실행 |

### 2.3 주의사항

- 마킹 시 강한 빛 발생 — **안구손상 주의(보안경 착용)**
- 장갑이나 천으로 마킹 부위 이물질 제거, 장갑 착용 후 사용
- 엔드밀에 "코.(의뢰업체명)" 입력. **코고툴 업체는 "(의뢰업체명)"만** 입력
- 엔드밀 구경별 초점을 맞춰서 마킹
- 기존 마킹과 겹치지 않게 할 것
- 마킹 시 신체 부위가 마킹 부위에 닿지 않도록 주의
- **창성 TOOL 의뢰 물품**은 마킹 후 의뢰서 복사본 또는 재연마 수주 등록 후 인쇄하여 창성 TOOL로 송부

## 3. 밑작업 (C40 절단·콜렛교체·휠교환)

### 3.1 C40 작동법 (7단계)

① C40 전원 ON → ② 스핀들 가동 → ③ Mist collector 가동 → ④ 가공할 엔드밀 구경에 맞는 콜렛 교체 → ⑤ 가공 부위 확인 → ⑥ 절단 → ⑦ 절단 부위 확인

### 3.2 콜렛 교체

가공할 엔드밀 구경에 맞춰 콜렛을 교체(절차는 [[cadcam/anca-재연마-작업절차-SOP]] §1.6 콜렛 교체와 동일한 원리 — 파이 표기부와 고정나사 일직선 정렬).

### 3.3 형태별 절단 방법

| 형태 | 절단 위치 |
|------|----------|
| 평엔드밀 | 파손 부위에서 절단 |
| 볼엔드밀 | 파손 부위에서 1~2mm 정도 윗부분 절단 (볼 형태로 가공되며 파손 부위 제거됨) |
| 코너R엔드밀 | 평엔드밀과 같거나, 평엔드밀보다 파손 부위에서 조금 윗부분을 절단 |

### 3.4 휠 교환·각도 수정

1. 보호판 고정 너트 → 스핀들 고정너트를 T렌치로 고정 → 휠 고정너트 풀어 휠과 스핀들 분리
2. 베드·척 고정나사를 렌치로 풀어준 뒤 각도 수정 — **베드 각도와 척 각도는 반드시 동일**해야 함

### 3.5 밑작업 주의사항

- 보호장비 착용(보안경, 앞치마, 팔토시, 마스크) 후 작업
- Wheel 가동 중 신체 부위 접촉 금지
- AUTO LINK 집진기를 가동하고 작업
- CNC에서 가공할 수 있을 만큼 **충분한 옆날 길이 확보**
- 절단 시 적정 Feedrate로 작업
- 연마석 가공 시 엔드밀을 너무 가까이 잡지 말고, 놓치지 않도록 잘 잡을 것
- 절단휠과 엔드밀은 서서히 어프로치
- 볼에서 코너R로 변경 시 **GASH 부분 끝부분까지 절삭**
