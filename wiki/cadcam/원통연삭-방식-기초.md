# 원통연삭(Cylindrical Grinding) 방식 기초

> 작성 배경: [[tools/wheels/원통연마-휠-12도-스펙]] (휠 D, 초소형 Neck 검토) 논의 중 "Neck 부위"와 "12° 경사 부위"의 역할을 잘못 이해하고 있었음이 확인되어, **원통연삭의 표준 분류부터 재정리**합니다.
>
> ⚠️ 신뢰도 안내: 트래버스/플런지/폼 연삭의 **정의 자체**는 연삭공학 표준 교재([ACA-KLOCKE2009], [ACA-MARINESCU2016], [ACA-MALKINGUO2008], [ACA-ROWE2014] — 본 위키 [[휠RPM-정책-검증-노트]] 등에서 이미 1차 출처로 등재된 핸드북)에 일반적으로 수록된 통용 개념입니다. 다만 이번 조사에서는 각 교재의 **정확한 장·페이지 번호까지는 확인하지 못했습니다** (확인 필요). 아래 산업 자료([IND-*] ID)는 정의를 교차 확인하는 보조 참고이며 단독 인용 대상이 아닙니다 (CLAUDE.md 출처 우선순위 5순위).

---

## 1. 원통연삭이란

원통연삭(Cylindrical Grinding)은 회전하는 공작물의 원통형 외면(또는 내면)을 회전하는 연삭 휠로 가공하는 방식입니다. 공작물은 센터 또는 척으로 지지되어 회전하고, 휠은 별도로 고속 회전하며 접촉합니다 [ACA-MARINESCU2016].

원통연삭은 **휠과 공작물의 상대 이송 방식**에 따라 아래 3가지로 분류됩니다.

| 방식 | 이송 방식 | 휠 폭 조건 |
|------|----------|-----------|
| 트래버스 연삭 (Traverse Grinding) | 공작물(또는 테이블)이 휠 축 방향으로 왕복 이송 | 휠 폭 < 가공 길이 |
| 플런지 연삭 (Plunge Grinding) | 휠이 공작물 반경 방향으로만 절입, 축 방향 이송 없음 | 휠 폭 ≥ 가공 길이 |
| 폼(성형) 연삭 (Form/Profile Grinding) | 플런지 연삭의 하위 방식 — 휠 형상 자체가 공작물 형상의 음각(陰刻) | 휠 폭 ≥ 가공 길이, 휠이 프로파일 형상 보유 |

---

## 2. 트래버스 연삭 (Traverse Grinding)

- 좁은 폭의 휠이 **길이 방향으로 왕복 이송**하면서 긴 원통 공작물을 연삭.
- 표면 거칠기 Rmax 0.1 μm 이하까지 확보 가능 — 정밀 축·롤러류에 적합 [IND-MISUMI-GRINDING].
- 사내 사례: 없음 (본 위키 ANCA 공구연삭은 대부분 짧은 구간 성형이라 트래버스보다 플런지/폼 방식에 가까움).

```
   ⟲ 휠(폭 좁음)          ⟵ 왕복 이송 ⟶
  ┌──────┐
  │██████│  ─────────────────────────
  └──────┘        공작물 (길게 회전) ⟳
```

---

## 3. 플런지 연삭 (Plunge Grinding, = Infeed Grinding)

- 공작물은 제자리에서 회전만 하고, 휠은 **반경 방향으로만 절입** — 축 방향 이송 없음.
- 휠 폭이 가공 구간 전체를 덮으므로, **짧은 구간·소형물 연삭**에 적합 [IND-TOOLINGU-CYLGRIND].
- 휠이 평면(1A1)이면 단순 외경 절삭, 휠에 형상이 새겨져 있으면 **폼 연삭**이 됨.

```
        ⟵ 절입(반경 방향)만
   ⟲ 휠(폭 = 가공 구간)
  ┌──────────┐
  │██████████│  ═══════  공작물 (제자리 회전) ⟳
  └──────────┘
```

---

## 4. 폼(성형) 연삭 (Form / Profile Grinding)

> **"Plunge grinding is normally applied using a formed grinding wheel to impart the shape of the grind wheel on the workpiece."** [IND-TOOLINGU-CYLGRIND] 웹 검색 결과 요약, 교차 확인: 플런지 연삭에 프로파일 휠을 적용하면 곧 폼 연삭이 됨.

- 플런지 연삭의 하위 방식. **휠 단면 형상 = 공작물에 새겨질 형상의 음각(거울상)**.
- 휠이 축 방향으로 한 번 절입(plunge)하면, 휠 표면의 여러 단면 형상이 **동시에** 공작물에 전사됨.
- 공구 연삭(엔드밀 Neck 릴리프, 코너 R, Gash 등)의 상당수가 이 방식.

## 5. ANCA 원통 연마 휠(Neck + 12° 경사) — 어느 방식인가

[[tools/wheels/원통연마-휠-12도-스펙]]에서 검토 중인 "Neck + 12° 경사" 휠은 위 분류상 **폼(성형) 플런지 연삭용 프로파일 휠**입니다.

### 5.1 이전 오해 (2026-07-01 정정 전)

- 12° 경사면 위의 서로 다른 지점이 서로 다른 공구 직경(D1~D6)을 담당하는 **가변 접촉면**이라고 가정.
- Δr = (D_max - D_min)/2, L = Δr / tan(12°) 공식으로 "직경 범위별 필요 경사부 길이" 표를 산출.

### 5.2 정정된 이해 (한경준님 확인, 2026-07-01)

> "Neck이 1순위로 가공하기 위해 닿는 부위이고, 12도 길이는 뒷부분의 여유롭게 들어가는 부분"

- **Neck (원통부)** = 휠 프로파일에서 **정밀 성형면(1차 접촉·가공 대상)**. 공구의 실제 기능 치수(Neck 직경)를 정밀하게 성형하는 구간.
- **12° 경사부** = Neck 뒤쪽에서 휠 몸통(또는 공구 몸통)까지 여유 있게 연결되는 **릴리프/전환 구간**. 정밀도 요구가 낮고 "generous(여유롭게)"하게 설계됨 — 공구 몸통이나 휠 바디가 서로 간섭하지 않도록 하는 클리어런스 역할.
- 즉 **12° 구간의 길이는 "어디까지 갈아낼 것인가(직경 범위)"가 아니라, "몸통 간섭을 피하기에 충분한 여유를 확보했는가"로 결정되는 값**입니다.
- 이 구조는 공구 제조업계에서 통용되는 **Neck relief / shank relief** 설계와 일치합니다: "A smaller-diameter grinding wheel is used to carefully reduce the diameter behind the flutes, creating the neck relief. The shape of the neck relief must be carefully designed to provide sufficient clearance without compromising tool strength." [IND-BAUCOR-NECKREL]; "Shank relief... allows clearance between the shank and the sides of workpieces" [IND-MASTERCUT-ENDMILL].

### 5.3 실무 영향 — [[tools/wheels/원통연마-휠-12도-스펙]] §2 "휠 D" 재검토 필요

- 기존 §2 "휠 D" 절의 **B(경사부 두께)+C(Neck 두께) 합산 = T(전체 두께)** 프레임은 유지 가능하나, **"12° 구간이 직경 범위를 커버한다"는 전제로 계산했던 이전 D6~D1 표(Δr/tan12°)는 이 페이지 기준으로 재해석이 필요**합니다.
- **C(Neck 두께)**: 실제로 가공되는 최종 Neck 직경/길이에 맞춰 정밀 결정 — 기존 트레이드오프(1mm vs 3mm) 논의는 여전히 유효 (성형면 자체의 정밀 치수 문제이므로).
- **B(경사부 길이/두께)**: "직경 범위를 커버하는 값"이 아니라 **"공구 몸통 최대 직경(D6 등)이 휠 바디에 간섭하지 않는 최소 여유"**로 재정의 필요. 일반적으로 최댓값(가장 굵은 몸통) 하나만 만족하면 그보다 얇은 몸통은 자동으로 여유가 남음.
- ⚠️ 이 재정의는 아직 한경준님 확인·홍익다이아 기술 의견 확인 전 단계입니다 — "확인 필요"로 유지.
