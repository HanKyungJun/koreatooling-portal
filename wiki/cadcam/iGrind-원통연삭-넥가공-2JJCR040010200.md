# iGrind 원통연삭(Cylindrical Grinding)으로 넥 Ø3.85 가공 — 2JJCR 040 010 200 (~~Ø3.7~~ → 10-19 확정)

> AI 제시 수치는 참고값입니다. 아래 조건은 **CIM3D 시뮬레이션까지만 확인**했고 실가공 검증 전입니다. 시험 → 측정 → 검증 후 양산에 적용합니다.

## 1. 개요

- **대상 공구**: 2JJCR 040 010 200 (초경 엔드밀, 머리 Ø4 / 날장 4 / L2 20 / L 50 / 생크 Ø6 h6 / 넥 테이퍼 15°) — 카탈로그 치수 `제조사 기준`
- **목표 형상**: 머리 Ø4(0 ~ 4 mm)는 그대로 두고, 그 뒤에 **넥 Ø3.85** (~~Ø3.7~~ → ✅ 2026-10-19 한경준님 확정, decisions 2026-10-19 (6) · 사내 기본 = D − 0.15)을 내서 생크 쪽 15° 테이퍼와 연결
  - 넥 지름 Ø3.7은 카탈로그에 없는 값이라 작도용 가정입니다 `추정값 — 확인 필요`
  - 🔴 **2026-10-19 Cowork 주의 (위키 반영 시 추가)**: Ø3.7 은 Cowork 가 같은 날 그린 도면(`outputs/2JJCR_040_010_200_도면.png`)에서 **넥 지름이 카탈로그에 없어 그림을 그리려고 임의로 넣은 값**이다(도면에 「작도용 Ø3.7 가정 · 확인 필요」 표기). 실측·고객 요구·사내 기준에서 나온 값이 아니다. 반면 기존 프로그램은 **넥 Ø3.85**(아래 §4)였다 → **Ø3.85 → Ø3.7 변경은 요구 넥 지름을 확인한 뒤에** 진행한다
- **사용 오퍼레이션**: iGrind Step Tools → Cylindrical Grinding (Step Section)
- **기준 프로그램**: `P:\toolroom\user\tools\AFCY\AFCY_D3.8_S6.tom` (현재 작업 파일)
- **구조 참고 파일**: `AFCY_2krb040120s06.tom` (2016-10-28 KST 저장 로컬 사본, 구조 확인용으로만 사용, 조건 근거 아님)

## 2. 설정 방법 (작업 순서)

1. Cylindrical Grinding 오퍼레이션 → **Section 1** 편집
2. **Basic 탭 → Dimensions**
   - Final diameter: **3.850 mm** (~~3.700~~)
   - X Start: **−4.100 mm** (날장 4 mm 뒤로 0.1 mm 여유)
   - Step length: **15.620 mm** (~~15.340~~) (화면에 X end 칸은 없음 → Step length로 끝 위치를 지정)
3. **Advanced 탭**
   - **Allow Wheel Overhang: 체크 해제** ← 핵심 (5장 참고)
   - Grind whole length: 해제 유지
   - Washout: Angle **15.00°**, Length **0.280 mm** (~~0.560~~)
4. Section 2 이후 섹션이 있으면 삭제합니다. 남겨둔다면 X Start 체인 링크를 먼저 끊고 정리합니다.
5. iGrind **2D 탭**에서 넥 범위(X −4.1 ~ −19.72 (~~−19.44~~), washout 포함 −20.0)를 확인합니다.
6. **CIM3D**로 시뮬레이션합니다. Operation Colour Mapping으로 볼 때 0 ~ −4.1 구간에 원통연삭 색이 없어야 합니다.
7. 1개 시험 연삭 → 측정 (넥 지름, 진원도, Ra μm, 머리 쪽 턱 치핑, 머리 Ø4 손상 여부)

### 계산 (검산용) — Ø3.85 (2026-10-19 확정)

- 반경 차 Δr = (4.0 − 3.85) ÷ 2 = **0.075 mm** (기존 프로그램과 같음)
- Washout 길이 = 0.075 ÷ tan 15° = 0.075 ÷ 0.2679 = **0.28 mm**
- 넥 끝(washout 제외) X end = −20.0 + 0.28 = **−19.72 mm**
- Step length = (−4.1) − (−19.72) = **15.62 mm**
- 예상 정삭 1패스 시간 = (15.62 + 0.28) ÷ 2.00 ≈ **7.95분** `추정값` (총 길이가 같아 Ø3.7 안과 같음)

#### (보존) Ø3.7 안 계산

- 반경 차 Δr = (4.0 − 3.7) ÷ 2 = **0.15 mm**
- Washout 길이 = Δr ÷ tan 15° = 0.15 ÷ 0.2679 = **0.56 mm**
- 넥 끝(washout 제외) X end = −20.0 + 0.56 = **−19.44 mm**
- Step length = X Start − X end = (−4.1) − (−19.44) = **15.34 mm**
  - 매뉴얼상 step length에는 washout 길이가 포함되지 않음 `제조사 기준`
- 예상 정삭 1패스 시간 = (15.34 + 0.56) mm ÷ 2.00 mm/min ≈ **7.95분** `추정값`

## 3. 파라미터 설명 (iGrind Grinding Manual §30)

| 파라미터 | 의미 | 신뢰도 |
|---|---|---|
| X Start | EOT(End of Tool, 공구 끝단)에서 스텝 시작점까지의 거리. 보통 0 또는 음수 | 제조사 기준 |
| X Start 체인 아이콘 | 기본값으로 이전 섹션의 X end와 연결됨. 연결된 채로 바꾸면 이전 섹션도 같이 밀림. 아이콘 클릭 → Parameter Link Editor에서 해제 | 제조사 기준 |
| Step length | 스텝 길이(washout 제외), 공구 축 방향 | 제조사 기준 |
| Step length = 0 | 다음 섹션의 X Start(링크)가 이 섹션의 끝이 되는 구조로 보임 (기존 파일에서 확인: −4.1→−6.6→−9.1, 마지막 섹션 길이 0) | 추정값 — 확인 필요 |
| EOT extension | 스텝의 EOT 쪽으로 연장해서 연삭 | 제조사 기준 |
| Shank X distance | 양수면 생크 쪽 정삭 길이가 줄어듦 | 제조사 기준 |
| Finish stock | 정삭은 1패스 traverse로 고정, 패스 수 증가 불가 | 제조사 기준 |
| Grind whole length | 켜면 이 스텝의 생크 쪽 끝부터 EOT까지 전부 연삭 | 제조사 기준 |
| Start OD (Blank / Define) | Define으로 바꾸면 황삭 시작 지름을 따로 지정해 이미 깎인 구간의 공삭을 방지 | 제조사 기준 |
| Washout angle / length | 스텝 끝의 경사 이행부. 길이 0이면 washout 없음. plunge 연삭에서는 washout을 연삭하지 않음 | 제조사 기준 |
| Grind Direction (상위 오퍼레이션 Basic) | EOT→생크 또는 생크→EOT | 제조사 기준 |
| Allow Wheel Overhang | 2014년판 매뉴얼에 설명 없음. 휠이 스텝 경계를 넘어가도록 허용하는 설정으로 보임 | 추정값 — 확인 필요 |
| 오퍼레이션 비활성화 | 메인 화면의 체크 표시로 끔. 단 Global infeed는 계속 적용됨 | 제조사 기준 (User Manual §3.4.4) |

## 5. 주의사항

- ⚠️ **머리(Ø4)가 넥보다 굵은 형상에서는 Allow Wheel Overhang을 꺼야 합니다.** 켜져 있으면 휠의 EOT 쪽 부분이 X Start를 넘어 날장을 깎습니다 (CIM3D 확인).
- ✅ (10-19 Ø3.85 확정으로 반경 0.075 mm = 기존과 같음 → 아래 고절입 우려는 Ø3.7 안 기준, 보존)
- ⚠️ **초경 고절입**: 반경 절입이 0.15 mm로 기존(0.075 mm)의 2배이고, 정삭 1패스로 제거합니다.
  - 권장: Roughing을 켜서 패스를 나누거나, Ø3.85 → Ø3.7 두 단계로 시험
- 넥 끝을 washout 없이 X −20에서 끊으면 반경 0.15 mm 턱이 생깁니다 → 15° / 0.56 mm washout으로 기존 테이퍼와 연결합니다.
  - washout이 생크 쪽 끝에 생기는지는 시뮬레이션으로 확인 필요
- CIM3D 블랭크가 단순 Ø4 원통이면 테이퍼 연결부를 검증할 수 없습니다 → 블랭크 에디터에 실제 형상(Ø4 → 15° → Ø6)을 넣고 확인합니다.
- X Start는 EOT 기준이므로 EOT digitizing이 정확해야 합니다.

### 이송·휠 속도 참고 (조건 결정 전)

- **Vc 범위**: Norton Winter 2023 카탈로그의 레진 다이아몬드 휠 초경 연삭 사례는 Vc 17~35 m/s (주로 18~22 m/s) `제조사 기준`
  - ⚠️ 위키 기존 기록([VEN-NORTON-WINTER-2023] · [[comparisons/휠-원주속도-제조사자료-비교-2026-10]])은 **초경 + 레진 다이아 17~22 m/s, 35~40 m/s 는 HSS + 레진 CBN 사례**로 나눈다 — 원문 p.25~26 확인 필요. 확인 전에는 초경에 30 m/s 초과 값을 쓰지 않는다(사내 상한 25 m/s)
  - 원통(OD) 연삭 전용 조건표는 카탈로그에 없음
- 현재 3000 rpm의 Vc는 휠 지름에 따라 다름 — 계산식 Vc = π × D × N ÷ 60000:

| 휠 D (mm) | 3000 rpm일 때 Vc (m/s) | Vc 18 m/s용 N (rpm) | Vc 22 m/s용 N (rpm) |
|---|---|---|---|
| 100 | 15.7 | 3438 | 4202 |
| 125 | 19.6 | 2750 | 3361 |
| 150 | 23.6 | 2292 | 2801 |

- **현재 조건 분석** `추정값`
  - 회전당 이송 fa = 2.0 ÷ 25 = 0.08 mm/rev
  - 공작물 원주속도 vw = π × 3.7 × 25 ÷ 1000 = 0.29 m/min (Ø3.85: π × 3.85 × 25 ÷ 1000 = **0.30 m/min**)
  - 제거율 Q = π × 3.85 × 0.15 × 2.0 = 3.6 mm³/min (Ø3.85: π × 3.925 × 0.075 × 2.0 = **1.85 mm³/min**)
- **시험 계획 (추정값, 검증 필요)**
  - 패스 분할 후 이송을 2.0 → 3.0 → 4.0 mm/min 순서로 올림
  - 단계마다 지름, 진원도, Ra, 치핑, 스핀들 부하를 측정하고 이상 시 직전 값으로 복귀
