# 공구 도면 · 3D 작업 — 외부 자료 · 학습 목록 (2026-11-12 조사)

> 요약: 공구 생성기([[cadcam/공구-도면-3D-생성기]])와 도면 작업에 쓸 밖의 자료를 표준 9건(새 8 · 기존 1) · 제조사 · 도구 문서 8건 · 논문 7건으로 모았다(새 출처 ID 23개, 검수 2026-11-12). 가장 효과가 큰 것은 ① 회사가 이미 쓰는 ANCA 의 **ToolDraft**(ToolRoom · CIM3D 공구 → 2D 도면 · PDF · DXF) 사용 가능 여부, ② 치수 이름을 **ISO 13399 기호**(DC · DMM · DN · OAL · LU · RE …)에 맞추기, ③ 날 단면을 「경사각 · 심압 · 홈각」 목표로 만드는 논문 방법이다. 표준 원문은 대부분 미보유 — 수치는 견본 · 2차 출처 범위만 인용.

## 1. 생성기 · 도면에 바로 쓸 것

| 순위 | 항목 | 밖의 근거 | 지금 생성기 | 할 일 | 크기 |
|---|---|---|---|---|---|
| 1 | ANCA ToolDraft — ToolRoom(2016 이후) · CIM3D(8.1 이후) 공구를 바로 2D 도면. GD&T · ISO 기호, 헬릭스 · 훅 · 여유각 치수, 단면 · 상세도, PDF · DXF | [VEN-ANCA-TOOLDRAFT] | 원호 1개 단순 형상으로 계산해 그림 | **사내 라이선스 확인 필요**(「Send to ToolDraft」 는 CIM3D V9 비교표에서 Advanced 쪽에만 있음 [VEN-ANCA-CIM3D-V9]). 있으면 실제 공구 도면은 ToolDraft, 생성기는 견적 · 설명용으로 역할 나눔 | 확인 1건 |
| 2 | ISO 13399 기호 — DC · DMM · DN · OAL · LU · APMX · RE · FHA · NOF | [VEN-DORMERPRAMET-ISO13399] · [VEN-SIEMENS-GTC2015] | D · d · L · Lc · 넥 · R · 헬릭스(사내 표기) | 사양표 · `_사양.json` 에 ISO 기호를 **병기**(생크는 계속 d 표기 — DMM 은 괄호). 거래처 · CAM 카탈로그와 이름이 맞음 | 작음 |
| 3 | 날 단면을 경사각 · 심압 반지름 · 홈각 3개 목표로 결정 — 단면에서 휠 = 타원, 소재 = 원(간섭 · 과삭 · 미삭 조건) | [ACA-FANG2020-WHEEL](오픈 액세스) · [ACA-WANG2014-THESIS] · [ACA-REN2018-FLUTE] · [ACA-KIMJH2005-KSPE] | 원호 1개(추정값) | 단면을 「경사면 직선 + 원호 + 뒤꿈치」로 바꾸고 경사각 · 심압을 입력으로 받기. 1차는 휠 계산 없이 기하로만 | 중간 |
| 4 | ISO/TS 13399-303 — 솔리드 엔드밀 **단순화 3D 모델** 만드는 법(특징 ↔ 속성) | [STD-ISO13399-303] | 단순화 모델과 같은 범주(날 끝 생략) | 원문 구매 여부 판단(확인 필요). 모델 이름 · 좌표계 · 절삭 구역 표시 규칙 맞추기 | 원문 필요 |
| 5 | 3D → 2D 자동 투상(실제 3D 단면으로 단면 A-A) | [VEN-FREECAD-TECHDRAW] | 끝면도는 계산 단면 | FreeCAD TechDraw `writeDXFPage` 로 STEP 에서 투상 · 단면 → 생성기 DXF 와 겹쳐 확인용 | 중간 |
| 6 | 치수 공차 표기 — ezdxf `set_tolerance()` · `set_limits()` | [VEN-EZDXF-DIM] | d 는 「h6」 글자, 공차 값은 주기 | 생크 d 를 `Ø6 h6 (0/−0.008)` 공차 치수로 직접 표기 | 작음 |
| 7 | 표제란 필수 칸 — 소유자 · 식별번호(16자) · 발행일 · 시트 번호 | [STD-ISO7200] | 코리아툴링 · 도면번호 · 작성일 · 시트 다 있음 | 도면번호가 16자를 넘는 경우(예: `EM4F-D6R0.5-d6-L50-N5.7x18` 26자) — 짧은 번호 규칙 검토 | 작음 |
| 8 | 날경 공차 등급 — 제품 사양 표기 사례 DC **e8** · 생크 **h6** | [VEN-HOFFMANN-203440](제조사 1곳 · 1제품) | D 공차 표기 없음 | D 공차는 제품마다 다름 → 사양에 `De8` 처럼 넣을 때만 표기(기본 없음). 근거 더 모으기 | 작음 |

- 신뢰도: 위 내용은 **제조사 기준**(1 · 2 · 8) · **표준 견본 · 2차 출처**(4 · 7) · **학술**(3)이며, 사내 적용은 모두 시험 전.
- 2026-11-12 생성기 v1.3 의 기하공차 0.005 는 사내 2016 도면 관례(사내 경험값)다. 표기 형식 근거는 ISO 1101:2017 · KS A ISO 1101 [STD-ISO1101] — 공구용 수치 표준은 이번 조사에서 못 찾음(ISO 2768-2:1989 흔들림 일반공차 H 0.1 mm — 2차 출처 [VEN-CAMCUT-RUNOUT] — 는 공구에 너무 큼).

## 2. ⚠️ 기존 위키와 다른 점 (병기)

- sources [STD-ISO1641] 은 「ISO 1641:2003 — 엔드밀 치수」로 적혀 있으나, 현행 **ISO 1641-1:2016 은 적용범위에서 초경(solid hard metal) 엔드밀을 뺀다**(견본 확인) [STD-ISO1641-1]. 초경 엔드밀 치수는 **DIN 6527**(K · L 계열) [STD-DIN6527] 쪽이 맞다. 기존 ID 는 지우지 않고 두 줄을 병기했다 — 위키에서 「ISO 1641 = 초경 엔드밀 치수」로 인용한 곳이 있으면 고쳐야 함(확인 필요).

## 5. 다음 단계 추천

**추천: 1순위 ToolDraft 사용 가능 여부부터 확인** — 실제 연삭 형상(ToolRoom 원본)으로 도면을 바로 뽑을 수 있으면 생성기의 단면 개선(3번)보다 정확하고 빠르다. 확인 방법: ANCA PC 의 CIM3D 메뉴에 「Send to ToolDraft」 가 있는지 · ToolDraft 설치 여부(한경준님). 없으면 2번(ISO 13399 기호 병기) → 3번(단면 개선) 순서.
