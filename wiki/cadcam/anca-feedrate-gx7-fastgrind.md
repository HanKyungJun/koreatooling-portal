# ANCA GX7 / FastGrind 연삭 피드 조건

> **신뢰도: 사내 경험값** — `raw/manuals/CNCFeedrate.xlsx` (2017-02 기준 사내 누적 데이터)  
> 단위: 모든 피드레이트 **mm/min**, 사이클 타임 **HH:MM:SS**  
> ⚠️ 이 값은 2017년 시점 기준. 현재 장비 상태·휠 마모 정도에 따라 결과가 달라질 수 있습니다. 신규 조건 적용 전 테스트 필수.

---

## 1. 개요

이 페이지는 ANCA 연삭기에서 **GX7 프로그램**과 **FastGrind 프로그램**을 사용할 때의 직경·형상별 연삭 피드레이트 사내 경험값을 정리한 참조 자료입니다.

| 항목 | GX7 | FastGrind |
|------|-----|-----------|
| 특징 | 범용 연삭 (표준 품질) | 고속 연삭 (사이클 타임 단축 우선) |
| 용도 | 신품·정밀 재연마 | 량산 재연마·빠른 처리 |
| 비고 | 소직경(D2~D4)은 사이클 타임이 짧음 | 대직경(D16~D20)에서 GX7 대비 유리 |

**공구 코드 체계**

| 코드 | 의미 | 예시 |
|------|------|------|
| `{날수}BA{직경×10}` | Ball 엔드밀 | `2BA060` = 2날 Ball Ø6mm |
| `{날수}CO{직경×10}` | Corner Radius 엔드밀 | `4CO100` = 4날 CR Ø10mm |
| `{날수}FL{직경×10}` | Flat 엔드밀 | `3FL080` = 3날 Flat Ø8mm |

**피드 구분**

| 항목 | 설명 |
|------|------|
| **Impact** | 휠이 공구에 최초 접촉할 때의 감속 피드 (충격 완화) |
| **Gashing / start / end** | 갭(홈) 연삭 중 피드 |
| **Walk** | 워크 모션(축방향 이송) 피드 |
| **Bottom** | 갭 바닥 연삭 피드 |
| **OD primary / secondary** | 외경 1·2차 연삭 피드 |
| **Endface primary / secondary** | 단면 1·2차 연삭 피드 |

## 5. 운용 주의사항

⚠️ **2017년 기준 사내 경험값이므로 현재 조건과 반드시 비교 확인 후 적용**

- 이 피드 데이터는 특정 휠·소재·장비 상태 기준. 휠 마모·드레싱 상태·소재 경도 변화 시 재확인 필요.
- `Impact` 값을 임의로 올리면 날 끝 치핑 위험. 낮추면 사이클 타임 증가.
- 대직경(D16, D20) Ball은 사이클 타임이 1일 이상 → 나이트 시프트 운용 또는 자동화 환경에서 실행.
- R2.0 Corner Radius의 일부 조건(예: 2CO120 GX7 R2.0 → 11:38)은 동일 직경 R0.5 대비 4배 이상 사이클 타임 증가.
- 표에 값 없는 항목(예: 4CO200, 2CO050 FastGrind)은 사내 미사용 또는 미기록.
