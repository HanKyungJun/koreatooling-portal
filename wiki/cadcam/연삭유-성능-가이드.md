## 1. 연삭유 선택의 중요성 — 자주 간과되는 핵심 변수

연삭 공정 개선을 위해서는 모든 측면을 평가해야 합니다:
- 적합한 공작기계 선택
- 연삭 휠 선택
- 공구 홀더
- 공구 경로
- **그리고 절삭유**

> ⚠️ 불행히도 많은 사람들이 절삭유를 **"필요한 악(unnecessary evil)"**으로 봅니다. 적합한 절삭유 선택이 다음에 상당한 개선을 가져올 수 있다는 점을 인식하지 못합니다:
> - **사이클 타임**
> - **표면 품질·마감**
> - **2차 작업** (예: 공구 코팅)

### 1.1 본 위키 정합 — [[연삭-테스트-방법]] (Walter Graf 2011) §3.1 준비 단계와의 연계

Walter Graf 2011 §3.1 준비 단계 체크리스트 중:

위 두 항목은 **연삭유 자체의 종류·등급**과는 다른 문제. 본 자료는 Walter Graf의 운영 점검(상태) 외에 **연삭유 자체 선택의 기술적 근거**를 보강.

## 2. Base Oil 4 카테고리 ★★★

산업용 금속가공 유체의 **Base Oil은 4가지 카테고리**로 분류됩니다:

| Group | 구성 | 성능 |
|-------|------|------|
| **Group I** | 미네랄 오일 (저정제) | 가장 낮음 |
| **Group II** | 미네랄 오일 (수소화 처리) | 보통 |
| **Group III** | 미네랄 오일 (Severely Hydrotreated) | 우수 |
| **Group IV** | **순수 합성 (PAO)** | 최고 |

> ★ 핵심: Base Oil 카테고리는 연삭유 성능의 가장 중요한 결정 인자.

### 2.1 Group III — 보다 나은 성능을 위한 선택

> "To achieve better performance, consider products made with **Group III base oils**."

- **Severely hydrotreated** — 불순물 제거 + 점도 지수 개선 + 안정성 향상
- 미네랄 오일 유래 — **합성유 아님** (synthetic이 아님)

⚠️ **마케팅 주의**: 일부 제조사가 **"synthetized" (합성화)** 용어를 사용해 최종 사용자에게 혼란을 줄 수 있음. **Synthetic이 아닙니다.**

#### Group III 내의 GTL (Gas-to-Liquid) Base Oils

- Group III에 포함되나 **자매 제품보다 더 나은 특성**
- Group IV (PAO) 아래의 등급
- **천연가스 → 오일로 변환** 유래
- 많은 경우 **GTL 기반 연삭유로 전환 시 측정 가능한 성능 이점**

### 2.2 Group IV — 최고 성능: PAO (Pure Synthetic) ★★★

> "If you really want to ramp your performance, look to **Group IV, Pure Synthetic base stock products**."

| 항목 | 내용 |
|------|------|
| 구성 | **Polyalphaolefins (PAO)** |
| 점도 지수 | 높음 (Viscosity Index — 온도 변화 대비 점도 변화의 척도) |
| 제조 방식 | 원유 추출이 아닌, **작고 균일한 분자로 제조** |
| 결과 | 매우 **예측 가능한 특성** + 일관된 최종 결과 |
| 성능 | **최고 성능, 공정 안정성, 수명** |
| 가격 | **최상위** (top tier) |
| 가치 | 이점·결과가 가격 상승을 훨씬 능가 |

> ★ **"Grinding oils produced with PAO's will offer you the highest performance, process stability, longevity."**

## 3. 공기 방출 특성 (Air Release Properties)

핵심 속성 하나: **포말(foam) 발생 / 공기 방출 특성**.

- **공기는 냉각·윤활에 부적합한 매체**
- 낮은 등급 base oil → 포말·공기 갇힘 ↑
- 결과:
  - 윤활 불량
  - 냉각 불량
  - **표면 결함**
  - **여과 불량**

→ 운영에 적합한 **공기 방출 특성**을 가진 연삭유 선택.

---

## 4. Additive 패키지 (첨가제) — Base Oil 못지않게 중요

Base Oil 선택만으로는 충분하지 않음. **첨가제의 품질·양**도 핵심.

### 4.1 "Good, Better, Best" 분석

```
좋은 품질 Base Oil + 최고 품질 Additive 패키지
   = 그저 그런 제품 (도드라진 제품 아님)

최고 품질 Base Oil + 최고 품질 Additive 패키지 (최신 기술)
   = 혁신적 유체 기술 (innovative fluid technology)
```

> ★ 핵심: **Base Oil과 Additive 모두 최고 등급**이어야 진정한 우수 연삭유.

### 4.2 산업 선두 제조사 + 첨가제 생산자 협력

- 산업 선두 포뮬레이터의 R&D 전문성
- 최고 첨가제 생산자와의 협력
- → **기대를 충족·초과하는 연삭유**

### 5.3 시대성

- 2022년 자료 — Base Oil 분류 체계(Group I~IV)는 산업 표준으로 시대 무관
- PAO 기반 연삭유의 우수성은 학술적으로 확립된 사실
- 단, 최신 형성물·합성 기술 발전 시 본 자료 미반영 가능
