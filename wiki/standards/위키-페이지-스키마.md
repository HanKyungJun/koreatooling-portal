# 위키 페이지 유형 및 스키마

> CLAUDE.md §6 (6-1 ~ 6-10) 에서 원문 그대로 옮김(2026-11-10). 절 번호는 그대로 둔다 — 다른 문서의 「CLAUDE.md §6-5」 같은 인용은 이 파일의 같은 번호를 뜻한다.

### 6-1. 공통 프론트매터

모든 위키 페이지는 YAML 프론트매터를 포함합니다:

```yaml
---
type: machine | material | tool | wheel | gcode | cadcam | troubleshoot | project | comparison | script | report
tags: [관련 태그들]
sources:
  - "[ID-1]"
  - "[ID-2]"
updated: YYYY-MM-DD
---
```

`sources`는 `wiki/_handoff/sources.md`의 ID 형식을 사용합니다.

### 6-2. 장비 페이지 (`wiki/machines/`)

### 6-3. 소재 페이지 (`wiki/materials/`)

파일명: `{소재명}.md` (예: `sus304.md`, `알루미늄.md`)

신뢰도 등급을 3단계로 표시합니다:
- `★★★` — 학술·ISO 표준 1차 출처 직접 인용
- `★★☆` — 복수 산업 카탈로그 또는 핸드북 간접 확인
- `★☆☆` — 단일 출처 또는 경험적 추정

```markdown
---
type: material
category: "스테인리스강"
iso_group: "M"
hardness_range: "HRB 70-90"
tags: [SUS, 스테인리스, 난삭재]
sources:
  - "[STD-ISO15510]"
  - "[ACA-DAVIM2014-SS]"
updated: YYYY-MM-DD
---

# SUS304 (AISI 304 / 1.4301 / X5CrNi18-10)

## 1. 규격·명칭 (★★★)
## 2. 화학 조성 (★★★)
## 3. 기계적 물성 (★★★)
## 4. 가공 특성 (★★☆)
## 5. 추천 가공 조건 (★★☆)
## 6. 코팅 선택 (★★★)
## 7. 절삭유 (★★☆)
## 8. 사내 데이터 [대외비: 단가 제외]
## 9. 트러블슈팅
## 10. 관련 페이지
## 11. 참고 문헌
```

### 6-10. ERP·업무 프로세스 (`wiki/erp/`) (2026-07-27 신규)

파일명: `{시스템명}-사용법.md` (예: `이카운트-ERP-사용법.md`)

가공·연삭 조건이 아닌 사내 업무 시스템(ERP 등) 사용법을 다루는 페이지 카테고리. §4 정보 분류 원칙에 따라 **타 직원 실명·개인 평가 데이터는 기록하지 않음**(구조·절차만 기록).

```yaml
---
type: erp
system: "시스템명"
tags: [ERP, 업무프로세스]
sources:
  - "[ID-1]"
updated: YYYY-MM-DD
---
```
