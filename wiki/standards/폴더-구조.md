# cnc-wiki 폴더 구조

> CLAUDE.md §1 에서 원문 그대로 옮김(2026-11-10). CLAUDE.md 에는 요약만 남김.

```
cnc-wiki/
├── CLAUDE.md                  ← 규약서 (Claude · Cowork 자동 로드)
├── AGENTS.md                  ← Codex 협업 규약 (별도)
├── SECURITY_NOTES.md          ← 보안 주의사항
├── .env.example               ← 환경변수 템플릿
├── .gitignore
│
├── raw/                       ← 원본 소스 (읽기 전용, LLM 수정 금지)
│   ├── Catalog/               ← 공구·휠 카탈로그 PDF (JJ, COGO, 홍익다이아, 이화다이아)
│   ├── tool/                  ← ANCA .tom 파일 (공구 프로그램 원본, 165개)
│   ├── wheel/                 ← ANCA .wpk 파일 (휠팩 원본, 33개)
│   ├── manuals/               ← 장비 매뉴얼
│   ├── articles/              ← 기사·블로그·포럼 글
│   ├── notes/                 ← 현장 메모·가공 일지·작업자 작성 xlsx
│   ├── codes/                 ← G-code 파일·매크로·스크립트
│   └── assets/                ← 이미지·도면 스크린샷
│
├── wiki/
│   ├── index.md               ← 전체 페이지 카탈로그 (항상 최신 유지)
│   ├── log.md                 ← 위키 변경 이력 (시간순, 추가 전용)
│   ├── overview.md            ← 위키 현황 요약
│   ├── _handoff/              ← 환경 간 컨텍스트 공유 (아래 §0 참조)
│   │   ├── README.md
│   │   ├── context.md
│   │   ├── decisions.md
│   │   ├── worklog.md
│   │   ├── tasks.md
│   │   ├── memory.md
│   │   ├── sources.md
│   │   ├── holidays.md        ← 휴무일·휴가 단일 소스 (§13 참조)
│   │   └── chat-project-instructions.md
│   ├── machines/              ← 장비 (ANCA, VOLLMER, Rollomatic 등)
│   ├── materials/             ← 소재 (초경, S45C, SUS304, 알루미늄, 공구코팅)
│   ├── tools/                 ← 공구·연삭 조건·코어 직경·수명·표면조도
│   │   └── wheels/            ← 연삭 휠 (보유 5종 + 카탈로그 7페이지)
│   ├── cadcam/                ← CAD/CAM·ANCA e-Sharp 시리즈·연삭 테스트 방법
│   ├── gcode/                 ← G-code 레퍼런스 (G83 등)
│   ├── comparisons/           ← 비교 분석 (3사 비교, KPI, 휠 비교)
│   ├── reports/               ← xlsx 보고서·체크리스트 (ANCA 마스터, 코어 권장 등)
│   ├── scripts/               ← 자동화 스크립트 문서 (17개 카탈로그)
│   ├── projects/              ← 프로젝트별 기록 (공구사양 실험 이력 등)
│   ├── troubleshoot/          ← 장애·트러블슈팅
│   ├── erp/                   ← ERP(이카운트) 사용법·업무 프로세스 (2026-07-27 신규 — §6-10 참조)
│   ├── standards/             ← 사내 기준·규칙 (보고서 작성 규칙, 정가표 읽는 법, 경도 환산, 끼워맞춤 공차 등)
│   ├── templates/             ← 보고서·기록 양식 (양식 A · B · C, 사진목록 양식 등)
│   ├── measurements/          ← 측정 기록·표준공수 DB
│   ├── repairs/               ← 설비 수리 이력 (assets/ 사진)
│   ├── compliance/            ← 법정 점검 (작업환경측정 등)
│   ├── _private/              ← 대외비 (단가·연락처 — CLAUDE.md §4)
│   └── _backup/               ← 옛 화면 백업 (portal-ui-20260615)
│   ※ reports/ 아래: 01_연삭조건 ~ 09_업무일정 · daily/ · claude-활용일지/ — 회의록은 09_업무일정/회의록/ (2026-10-28 정리)
│
├── outputs/                   ← 스크립트 실행 결과 (임시, .gitignore 대상 가능)
├── _to_delete/                ← 지울 후보 보관함 (.gitignore) — Claude 는 지우지 않고 여기로 옮기기만, 비우기는 한경준님 (정리_20261028/이동목록.csv)
├── scripts/                   ← 자동화 Python 스크립트 (parse_anca.py 등)
└── dist/                      ← 정적 웹 화면 (빌드 산출물)
```
