# Claude 요청 문장 모음 — 이렇게 말하면 이게 돈다

> 스킬 이름은 외우지 않아도 된다. 아래 문장과 **비슷한 말**이면 Claude 가 알아서 맞는 스킬을 부른다.
> 안 불린 것 같으면 뒤에 「스킬로 해 줘」만 붙인다.

| 하고 싶은 일 | 이렇게 말하면 된다 | Claude 가 하는 일 |
|---|---|---|
| 세션 시작 · 이어가기 | 「세션 시작」 · 「어디까지 했어」 | 핸드오프 읽고 현황 요약 (cnc-handoff) |
| 세션 끝내기 | 「마무리해줘」 | worklog 블록 + 커밋 명령 (cnc-handoff) |
| 무엇이든 검토 | 「erp_gui.py 검수해 줘」 · 「방금 만든 거 검수해 줘」 — **대상을 같이 말한다** | 대상 보고 역할 고름 → 검토표 적용. **프로그램이면 코드 리뷰까지 자동** (review-role → code-review) |
| 위키 품질 점검 | 「위키 검수」 · 「lint 돌려줘」 | 프론트매터 · 출처 · 고아 페이지 · 빨간 링크 (wiki-lint) |
| 일일보고서 확인 | 「일일보고서 확인」 · 「보고서 생성됐어?」 | 누락 날짜 · 원인 (daily-report-check) |
| 자동화가 안 돌 때 | 「스케줄러 진단」 · 「왜 보고서가 안 만들어졌어?」 | 로그 · 원본 일지 · 휴무일 대조 (scheduler-diagnose) |
| 연삭 계산 | 「D125 Vc 20 m/s RPM은?」 · 「Q'w 계산」 | 계산식과 중간 과정 표시 (grinding-calc) |
| 시험 결과 남기기 | 「테스트 결과 기록」 · 「측정값 남겨줘」 | 테스트 기록 표준 형식 (test-record) |
| 출처 등재 | 「출처 추가」 | sources.md ID 등재 (source-add) |
| 새 위키 페이지 | 「○○ 페이지 만들어줘」 | 스키마 맞춰 생성 + index 등재 (wiki-new-page) |
| 프로그램 오류 | 오류 메시지 붙여넣고 「왜 안 돼?」 | 재현 → 원인 → 수정 (engineering:debug) |
