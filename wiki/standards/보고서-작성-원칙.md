# 보고서 작성 원칙 (대통령비서실 매뉴얼 기반)

> **출처**: 대통령비서실 보고서 품질향상 연구팀 (2005). *보고서 작성 매뉴얼* [SYS-BLUEHOUSE2005]
> 원본: `raw/manuals/청와대_보고서작성매뉴얼_대통령비서실_2005.pdf` (75p)
> **신뢰도: 1차 출처 직접 인용** (정부 간행물) — 사내 적용 기준은 §7 참조.
> 이 페이지는 사내 문서(일일보고·회의록·발표자료·핸드오프 블록) 작성 표준의 참조 문헌 요약입니다.

---

## 1. 내용 작성 3대 원칙

### ① 수요자(보고받는 사람) 관점에서 작성

- 전문용어·어려운 한자·불필요한 외래어 지양. 필요 시 괄호 주석 또는 참고자료 첨부
- 작성자의 이해관계·선입견 배제 — 과거 사례·타부서 의견까지 포괄 검토 후 작성
- 수요자가 필요로 하는 **시점**에 보고 (적시성)

### ② 보고서 자체로 완결성 확보

- 다른 자료 없이 그 보고서만으로 이해 가능해야 함
- 읽고 나서 **추가 질문이 발생하지 않도록** 명확히 서술
- **1보고서 1주제** — 여러 주제 혼합 금지
- 분량은 적을수록 좋음. 5매 초과 시 목차 + 하이퍼링크

### ③ 표준화된 양식으로 간결·명료하게

- 6하 원칙 기준. 미사여구·애매한 표현·과장 지양
- 시작 문단에 가장 중요한 내용 배치 (특히 상황·정보보고서는 **결론 먼저**)
- 단순 사실 나열이 아니라 **의사결정이 필요한 쟁점**을 적시

## 2. 표준 구조 — 제목·개요·본론·말미

| 구간 | 역할 |
|------|------|
| **제목** | 제목만으로 성격·전체 내용 파악 가능하게. 가급적 1줄 |
| **개요** | 전체 요약 또는 작성 배경·목적·경위 |
| **본론** | 현실태·문제점 → 과거 사례·대안 분석 → 전망. **중요도 높은 것부터** |
| **말미** | 결론·대안 제시, 건의, 향후 조치. 필요 시 참고자료 첨부 |

## 3. 문장 표현 요령

- 개조식 기본이되 '한편·다만·특히' 등 접속어로 문맥 연결 (주어·목적어 과도 생략 주의 — 필요 시 서술식 병용)
- 능동형 표현, 단순한 문단 구조. 형용사·부사보다 **명사·동사** 중심
- **1문단 1초점**. 동일 단어·문구의 2중, 3중 반복 억제
- 결론·주장은 과장 없이 — 객관성·신뢰성 유지

## 4. 형식 기준 (매뉴얼 원문 — A4 서면 기준)

| 항목 | 매뉴얼 기준 [SYS-BLUEHOUSE2005] |
|------|------|
| 용지 | A4, 여백 위/아래 15mm·좌/우 20mm |
| 글꼴 | 본문 휴먼명조, 제목·중간목차 헤드라인M, 참고내용 중고딕 |
| 크기 | 문서 제목 22pt / 본문 15pt / 참고내용 13pt / 표 안 13~14pt |
| 줄간격 | 130% 기준 |
| 항목 부호 | Ⅰ. → 1. → 1) → ① → ⅰ) (사무관리규정의 가. 나. 체계 대신 제안) |
| 날짜 표기 | 2004. 8. 15. (년·월·일 생략, 온점) / 시각 15:20 (24시간제) |
| 숫자 | 아라비아 숫자, 서기 연호('서기' 생략) |

> ⚠️ 위 크기 기준은 **A4 서면 보고서** 기준입니다. 사내 PPT·Word 산출물은 스크린 가독성을 위해 별도 기준(제목 36~44pt 굵은 고딕, 본문 18~24pt — 2026-07-07 한경준님 확정)을 우선 적용합니다. 두 기준 모두 삭제하지 않고 병기합니다.

## 5. 보고서 4유형과 용도

| 유형 | 용도 | 핵심 |
|------|------|------|
| **정책 보고서** | 정책 기획·조정·참고 | 배경→현황·문제점→대안 분석→추진계획→건의 |
| **상황·정보 보고서** | 사실관계(fact) 전달 | **결론 먼저**, 정보의 조직화, 짧은 문장 |
| **회의 보고서** | 회의자료 / 회의결과 | 자료는 논의·결정 필요사항 중심, 결과는 반드시 기록 |
| **행사 보고서** | 행사 개요·진행 | 시간 순 시나리오, 참석자·역할 명확화 |

## 6. 체크리스트 (매뉴얼 5종 요약)

### 6.1 정책 보고서

- [ ] 보고 목적(의제화 이유)이 명확한가 / 추진 배경·경과가 정리되었나
- [ ] 문제의 현황·실태·원인이 제시되었나 / 국내외 유사 사례가 있나
- [ ] 대안과 주요 쟁점이 정리되었나 / 기대 효과가 제시되었나
- [ ] 추진 일정·필요 자원·성과관리 방법이 포함되었나
- [ ] 결정권자에게 건의·제안할 사항이 포함되었나

### 6.2 상황·정보 보고서

- [ ] **결론을 먼저** 서술했나 (수요자는 요지를 빨리 알고 싶어함)
- [ ] 입수 정보를 논리적으로 체계화했나 (불필요한 반복 제거)
- [ ] 제목이 전체 내용을 함축하나 / 구성이 압축·간결한가
- [ ] 짧은 문장인가 (2줄 내외) / 미사여구·전문용어 회피했나
- [ ] 자기 부서 시각만으로 평가하지 않았나 / 유관부서 의견을 왜곡 없이 반영했나

### 6.3 회의자료 / 회의결과

- [ ] (자료) 논의·결정이 필요한 사항 중심으로 구성했나, 처리 방향을 포함했나
- [ ] (자료) 한정된 시간에 논의 가능한 분량인가
- [ ] (결과) 중요한 회의결과를 반드시 정리·보고했나 — 논의 결과 중심, 중요도에 따라 상세/간략 조절
- [ ] (결과) 결정사항·담당·기한이 기록되었나
