## 0. 왜 이 문서가 필요한가

정가표는 **한 시트에 수십 개 블록이 가로·세로로 흩어져 있는 매트릭스**입니다. 블록을 잘못 고르면 값이 **2배 넘게** 틀어지는데, 겉보기에는 그럴듯해서 눈으로는 안 잡힙니다.

실제로 2026-09 개정에서 **세 파일 모두 이 지점에서 틀렸고**(정정 113건), Cowork도 블록을 두 번 잘못 짚었습니다. `HSS 라핑 밑날` 531건은 **블록을 못 찾아 한 달 가까이 미검증**으로 남아 있었습니다 — 원인은 아래 §4의 주석 한 줄을 못 본 것이었습니다.

## 1. 품목명·품목코드 구조

### 품목명 — 슬래시 6필드

```
2날 / 라핑평 / 12.5mm / HSS / 밑날 / 일반 코팅
날수   형상     직경    재질   가공부   코팅
```

| 필드 | 값 |
|---|---|
| 날수 | `2날` `3날` `4날` `5날` `6날` |
| 형상 | `평` `볼` `코너` `라핑평` `라핑볼` `라핑코너` `라핑` `날붙이초경` 등 |
| 직경 | `12.5mm` `30MM` — 대소문자 혼용, 소수 있음 |
| 재질 | `초경` `HSS` |
| 가공부 | `밑날` `밑옆날` `골수리` `밑골수리` `옆날` |
| 코팅 | `비코팅` `일반 코팅` `일반코팅` `고경도 코팅` `고경도코팅` — **공백 혼용** |

⚠️ **코팅 표기의 공백은 통일돼 있지 않습니다.** 비교 전에 공백을 제거하세요.
⚠️ **6필드를 안 지키는 품목이 있습니다.** `원통연삭/3MM`, `절단/6mm이하` 는 형상·재질 개념이 없는 **정상 품목**입니다. 반면 `2날코너/21MM/…`(구분자 누락)는 **오류**입니다 — 이런 건 파싱이 안 돼 **대조 대상에서 아예 빠지므로 값 오류보다 먼저 잡아야 합니다.**

### 품목코드

```
[K|P] {날수} {형상 2자} {직경×10, 3자리} …
   K2      CO       210            → 2날 / 코너 / 21.0mm
    2      RF       105            → 2날 / 라핑평 / 10.5mm
```

**품목명과 교차검증할 수 있습니다.** 2026-08-31 개정에서 이 검사로 직경 오기 5건을 찾았습니다.

⚠️ **직경 자리가 3자리(0.1mm 단위)라 소수 둘째 자리를 담지 못합니다.** `5.45mm`·`5.86mm` 는 코드와 품목명이 원리상 어긋납니다 — **오류가 아니라 코드 체계의 한계**입니다.

## 2. ★ 블록은 4개 축으로 갈린다

| 축 | 값 |
|---|---|
| **재질** | 초경 / HSS |
| **형상 계열** | 평(FLAT·라핑평) / 코너·볼(BALL·코너R·라핑볼·라핑코너) |
| **가공부** | 밑날 / 밑옆날·밑골수리 / 골수리(외경연삭) |
| **코팅** | 비코팅 / 일반코팅 / 고경도코팅 |
| **날수** | 2날 / **3날 이상(=4날 행)** |

> 🔴 **「밑날」과 「밑옆날」은 값이 2배 넘게 차이납니다.** 제목만 보고 아무 블록이나 쓰면 크게 틀립니다.

### 가공부 → 블록 대응

| 품목명 가공부 | 봐야 할 블록 |
|---|---|
| **밑날** | 「… 밑날」 블록 |
| **밑옆날** | 「… 밑옆날」 블록 |
| **골수리** | **= 외경연삭**. 형상 무관 공통 → 「{초경\|HSS} 라핑 E/M 외경연삭」·「… 외경연삭 코팅」 |
| **밑골수리** | **= 밑옆날 / 밑외경**. 초경은 「라핑 {평\|코너/볼}_E/M_밑골수리」, HSS는 「라핑 평 밑골수리 코팅」·「HSS 라핑 BALL, 코너R E/M 밑골수리 비코팅」 |

> 📌 **2026-09-01 개명**: 초경 라핑 블록 제목이 **「밑옆날」 → 「밑골수리」** 로 바뀌었습니다. 옛 문서에 「밑옆날」로 적힌 라핑 블록은 이제 「밑골수리」입니다.

## 3. 날수 규칙 — 3날 이상은 전부 4날

정가표에는 **2날과 4날 행만** 있습니다.

> **2날 → 2날 행 / 3·4·5·6날 → 전부 4날 행** [사내 확인, 한경준님 2026-09-01]

일부 블록은 열 이름이 아예 `2날` / `3,4,6날` 로 적혀 있습니다. 정가표 주석 *"*4날: 2날 X 1.25"* 와 정합합니다.

---

## 4. ★★ 주석이 규칙이다 — 블록 옆 메모를 반드시 읽을 것

블록 제목 오른쪽 작은 글씨가 **그 블록의 계산 규칙**입니다. 이걸 놓쳐서 531건이 한 달간 미검증으로 남았습니다.

| 위치 | 주석 | 의미 |
|---|---|---|
| **HSS 라핑 E/M 외경연삭** | ***"밑날가격 = 옆날가격"*** | 🔴 **HSS 라핑은 밑날 전용 블록이 없는 것이 정상.** 외경연삭 블록을 그대로 쓴다 |
| **초경 라핑 E/M 외경연삭** | ***"밑날 가격: 초경밑날 X 1.1"*** | 🔴 **초경은 규칙이 다르다.** 초경 기준으로 HSS를 찾으면 영원히 안 나온다 |
| 여러 블록 | *"Long: X 1.5 / Ex-Long: X 2"* | 길이 계열 계수 (직경 아님) |
| 여러 블록 | *"지정치수: X 1.5"* | |
| 코너R/BALL 밑날 | *"4날: 2날 X 1.25"* | |
| TAPER | *"제작: 2배"*, *"밑날가격 = HSS밑날(소치수)"* | |
| 외경연삭 | *"밑날+옆날 동시작업: 단수가격 X 1"* | |

> 🔴 **×1.1 은 「라핑」 품목 전용입니다.** 「초경 라핑 E/M 외경연삭」의 *"밑날 가격: 초경밑날 X 1.1"* 주석은 **품목명에 `라핑`이 붙은 품목**(`라핑볼`·`라핑코너`·`라핑평`)에만 적용됩니다.
> 품목명이 `볼`·`코너`·`평`(비라핑)인 초경 밑날 품목은 **「초경 BALL E/M, 코너R E/M 밑날」·「초경 FLAT E/M 밑날」 블록 값을 그대로** 씁니다 — ×1.1 하지 않습니다.
>
> 2026-09-02 검수에서 비라핑 `볼`·`코너` 밑날 **비코팅 3날이상** 73건(코고 37 · 코툴 36)이 정확히 ×1.1 된 값으로 들어가 있었고, 전부 정정했습니다.
> 판별법: 대상 값이 정가표 값의 **정확히 1.1배**이고 품목명에 `라핑`이 없으면 이 오류입니다.

## 5. 직경 구간은 **전부 「이하」** — 경계값은 그 구간에 포함

`Ø10` → **「10이하」** · `Ø10.5` → **「12이하」**

한 칸 위로 미는 실수가 가장 흔합니다(2026-08-31 개정에서 26건, 2026-09-02에서 59건).

### 🔴 「미만」·「이상」 혼용 주의

2026-09-01 개정 직후 라핑 평 블록 구간이 `… 25이하 / **30미만** / **31이상**` 이었습니다. 이러면 **Ø30이 어느 칸에도 안 들어갑니다**(30<30 거짓, 30≥31 거짓). 6건이 여기서 샜습니다.

> ★ **일반화: 구간 라벨에 「미만」과 「이상」을 섞으면 경계값이 새는 칸이 생긴다. 「이하」로 통일하는 편이 안전하다.**

현재는 `30이하 / 31이상` 으로 정정돼 있습니다.

## 6. 블록의 물리적 배치

- **직경이 세로**인 블록과 **가로**인 블록이 섞여 있습니다. 자동 판독 시 둘 다 처리해야 합니다
- **2단 헤더**가 흔합니다: 제목 → (비코팅/코팅) → (2날/3,4,6날) → 데이터
- 세로형은 보통 **직경 열 = 제목 열**, 데이터가 오른쪽으로 이어집니다
- **한 행에 여러 블록이 나란히** 놓여 있습니다 → 헤더를 행 단위로 훑으면 옆 블록 숫자와 섞입니다. **반드시 연속 열 구간으로 잘라서** 인식하세요 (실제로 이 버그로 오판한 적 있음)
- 고경도 블록은 일반 블록보다 **구간이 짧은 경우가 있습니다**(예: 평 밑골수리 고경도는 25이하까지)
