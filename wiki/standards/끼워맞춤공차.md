# 끼워맞춤 공차 (ISO 구멍 기준 끼워맞춤)

> **출처**: `raw/manuals/끼워맞춤공차.xls` — ISO IT 공차 기반 (SAE J 417 / ISO 286 기준)  
> **신뢰도: 표준 기준** — ISO 286-1 국제 표준 환산표  
> ⚠️ 단위: μm (마이크로미터). 공차는 허용 치수 편차 범위.

---

## 1. 끼워맞춤 종류

| 종류 | 의미 | 대표 조합 |
|------|------|-----------|
| **틈새 끼워맞춤 (Clearance fit)** | 구멍이 항상 축보다 큼 | H7/f6, H8/e8 |
| **중간 끼워맞춤 (Transition fit)** | 틈새 또는 죔새 가능 | H7/k6, H7/n6 |
| **압입 끼워맞춤 (Interference fit)** | 축이 항상 구멍보다 큼 | H7/p6, H7/s6 |

## 3. 상용 끼워맞춤 — 구멍 기준 H7 조합

| 축 등급 | 끼워맞춤 종류 | 용도 예시 |
|---------|------------|---------|
| H7/c9 | 틈새 (큰 틈) | 온도 팽창 있는 고온 부품 |
| H7/d8, H7/e8 | 틈새 (중간) | 베어링 외륜 미끄럼, 부시 |
| H7/f6, H7/f7 | 틈새 (소) | 슬라이딩 베어링, 부시 (일반) |
| H7/g6 | 틈새 (최소) | 정밀 슬라이딩, 기어 부시 |
| **H7/h6** | 틈새~0 | 교환 가능한 정밀 부품, 위치 결정 |
| **H7/k6** | 중간 | 기어·풀리 압입, 탈착 가능 |
| **H7/n6** | 중간 (죔새 쪽) | 기어 압입 (보통 압) |
| **H7/p6** | 압입 (경) | 부시 고정, 키없는 기어 |
| H7/r6, H7/s6 | 압입 (강) | 영구 결합 부품 |
| H7/u7 | 압입 (최강) | 탈착 불가 결합 |
