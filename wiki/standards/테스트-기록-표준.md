# 테스트 · 불량 기록 표준

> CLAUDE.md §9 (9-1 ~ 9-4) 에서 원문 그대로 옮김(2026-11-10). 절 번호는 그대로 둔다 — 「CLAUDE.md §9」 인용(36곳) · test-record 스킬은 이 파일의 같은 번호를 뜻한다.

### 9-1. 테스트 데이터 기록 항목

사내 가공·연삭 테스트 결과 기록 시 아래 항목을 포함합니다:

| 항목 | 예시 |
|------|------|
| 장비명 | ANCA MX7 |
| 휠 사양 | 11V9 Ø125 Resin Diamond D46 |
| RPM / Vc | 3,050 rpm / 20 m/s |
| Feed / Q'w | Q'w 8 mm³/(mm·s) |
| DOC / Ae | 0.3 mm |
| 쿨런트 | 수용성 에멀전 5%, 20 bar |
| 피삭재·공구 | D6 4날 초경 엔드밀 WC-Co |
| 측정 장비 | Mitutoyo SJ-210 |
| 결과 | Ra 0.4 μm, 수명 45개/드레싱 |

### 9-2. 설비 상태 기록

결과에 영향을 줄 수 있는 설비 상태를 함께 기록합니다:
- 스핀들 런아웃·열변형 여부
- 휠 밸런스 (iBalance 측정값)
- 드레싱 상태 (마지막 드레싱 시점·횟수)
- 필터 오염 상태
- 쿨런트 농도·pH
- 장비 예열 여부

### 9-3. 불량 기록 항목

불량 발생 시 아래 항목을 함께 기록합니다:
- 증상 (표면 거칠기 악화·날 끝 치핑·연삭 화상·버 발생·코어 편심·런아웃 증가)
- 발생 위치 (가공 부위·공구 형상)
- 추정 원인
- 대응 방법
- 재발 여부

### 9-4. 버전 관리 기록 형식

조건 수정 시 기존 값을 삭제하지 않고 변경 이력을 남깁니다:

```markdown
| 날짜 | 변경 내용 | 사유 | 양산 적용 |
|------|----------|------|----------|
| 2026-03 | Vc 25→20 m/s | 휠 파손 후 안전 마진 확보 | ✅ 적용 중 |
| 2026-05 | DOC 0.3→0.5 mm | 가공 시간 단축 테스트 | 🔄 검증 중 |
```
