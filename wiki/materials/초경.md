# 초경합금 (Cemented Carbide / Hardmetal)

> 초경(超硬)은 탄화텅스텐(WC) 분말을 코발트(Co) 등 결합금속으로 소결한 분말야금 복합소재입니다. 본 위키의 절삭·연삭 작업 대부분이 초경 공구 소재를 대상으로 합니다.
>
> 본 페이지는 **재료 자체의 물성·등급**에 집중합니다. 연삭 측면 학술 근거는 [[연삭-이론-근거]], 실측 조건은 [[연삭-조건-목록]] 및 형상별 페이지를 참조하세요.
>
> ★★★ = 학술 논문·국제 표준 직접 근거 | ★★☆ = 간접 지지 + 산업 통례 | ★☆☆ = 추론 또는 사내 경험치

## 1. 정의·역사 ★★★

초경합금은 1923년 독일 OSRAM/Krupp에서 Karl Schröter가 탄화텅스텐(WC) 분말을 코발트(Co) 바인더로 소결하는 공정을 특허화하면서 상업적 생산이 시작된 분말야금 복합소재입니다 [Upadhyaya 1998, Ch.1].

영문 표기는 **cemented carbide** (미국 표준), **hardmetal** (유럽·국제 표준 — ISO 사용 용어), 일본·한국 통상 표현은 **초경합금(超硬合金)** 입니다.

오늘날 세계 시장 규모는 약 200억 USD(2023년 기준)이며, 절삭공구·금형·광산공구·마모부품 등에 사용됩니다.

## 2. 화학 조성 ★★★

전형적 절삭공구용 초경합금의 구성:

| 성분 | 함량 (wt%) | 역할 |
|---|---|---|
| **WC** (탄화텅스텐) | 70~97% | 경질상, 경도·내마모성 담당 |
| **Co** (코발트) | 3~25% | 결합금속(binder), 인성·취성 균형 담당 |
| TiC, TaC, NbC 등 | 0~30% | 부수 탄화물, 내고온성·내크레이터 마모성 향상 |
| Cr₃C₂, VC | 미량 | 입자성장 억제제(grain growth inhibitor) — Ultra-fine 등급 필수 |

> **Co 함량과 특성의 trade-off**:
> Co ↑ → 인성 ↑, 경도 ↓ → 거친 가공·충격 부하용
> Co ↓ → 경도 ↑, 인성 ↓ → 정삭·내마모용

[출처: Upadhyaya 1998 / Brookes 1992]

## 3. ISO 절삭재 분류 ★★★

ISO 513:2012는 경질절삭재료를 **피삭재별로** 분류합니다.

| ISO 그룹 | 색상 코드 | 주 적용 피삭재 | 주요 특성 |
|---|---|---|---|
| **P** | 파랑 | 강(steel) 일반 | 내크레이터 마모성, TiC/TaC 함유 多 |
| **M** | 노랑 | 스테인리스·내열합금 | 인성·내마모성 균형 |
| **K** | 빨강 | 주철·비철·비금속 | 내마모성 중심, WC-Co 위주 |
| **N** | 초록 | 비철금속 (Al, Cu 등) | 미세입자, 고속절삭성 |
| **S** | 갈색 | 초내열합금·Ti 합금 | 고온 강도, 산화 저항성 |
| **H** | 회색 | 경화강 (HRC > 45) | 내마모성·고경도 |

각 그룹 내에서 **숫자**로 등급 세분화 (예: K10 < K20 < K40 — 숫자 클수록 인성↑·경도↓).

> [출처: ISO 513:2012 — 본 분류는 절삭공구 카탈로그(JJ, COGO 포함) 전반의 표준 언어]

## 4. 주요 물성 ★★★

| 물성 | 범위 | 비고 |
|---|---|---|
| 경도 (HRA) | 86~94 | Co 함량 ↓ 시 ↑ |
| 경도 (HV, GPa) | 10~22 | WC-6Co 기준 약 16 GPa |
| 항절강도 TRS (MPa) | 1,500~4,500 | Co 함량 ↑ 시 ↑ |
| 영률 E (GPa) | 450~650 | 강철(210)의 2~3배 |
| 밀도 ρ (g/cm³) | 13.0~15.2 | WC 비율 ↑ 시 ↑, 강철(7.85) 대비 약 2배 |
| 열전도성 k (W/m·K) | 60~120 | WC가 Co보다 우수 |
| 열팽창계수 α (×10⁻⁶/K) | 5.0~7.5 | 강철(11~13)보다 낮음 — 열변형 적음 |
| 최대 안정 사용 온도 (℃) | 800~1,000 | Co 결합금속 한계 (그 이상은 산화·연화) |

[출처: Upadhyaya 1998 / Brookes 1992 / Roebuck NPL 보고서들 / ISO 4499]

> ⚠️ 본 표는 일반 범위. 정확한 값은 제조사 카탈로그(JJ, COGO 등) 또는 [[sources|VEN-*]] 참조.

## 5. 미세 구조 — WC 입자 크기 분류 ★★★

ISO 4499-2에 따른 분류:

| 명칭 | WC 입자 크기 (μm) | 특징 | 주 용도 |
|---|---|---|---|
| **나노 (Nano)** | < 0.2 | 최고 경도, 인성도 양호 | 정밀 마이크로 공구, PCB 드릴 |
| **울트라 파인 (Ultra-fine)** | 0.2~0.5 | 고경도·중인성 | 정밀 엔드밀, 마이크로 가공 |
| **서브미크론 (Sub-micron)** | 0.5~0.8 | 균형형 | **일반 절삭공구 다수** ← 재연마 대상 주류 |
| **파인 (Fine)** | 0.8~1.3 | 인성 우수 | 일반 절삭, 금형 |
| **미디엄 (Medium)** | 1.3~2.5 | 인성 중심 | 거친 가공, 충격 부하 |
| **코스 (Coarse)** | 2.5~6.0 | 최고 인성 | 광산·암반 천공 (절삭공구 비주류) |

> 재연마 대상은 대부분 **Sub-micron ~ Ultra-fine** 영역입니다. 입자 크기가 작을수록 연삭 시 self-dressing 임계조건이 까다로워지므로 [[연삭-이론-근거]] §4의 #325/#400 그릿 선택 논의와 직결됩니다.

[출처: ISO 4499-2:2020 / Roebuck (NPL)]

## 8. 재연마 시 고려사항 ★★★

본 위키의 핵심 적용 영역입니다. [[연삭-이론-근거]]의 8개 섹션 전체가 초경 재연마에 직접 적용됩니다.

### 8.1 등급별 연삭 특성

| 등급 특성 | 연삭 시 영향 | 대응 |
|---|---|---|
| **고-Co 등급** (12% 이상) | 결합금속이 더 잘 흐름 → glazing 경향 강함 → 본드 표면 빠르게 막힘 | 드레싱 주기 단축, Feed 적극 상향 |
| **저-Co 등급** (5% 이하) | 경도 높음 → 연삭 부하 큼 → SGE 증가 ([[연삭-이론-근거]] §2) | 거친 연삭은 단계적 DOC, 휠 마모 모니터 |
| **Ultra-fine 입자** (< 0.5 μm) | 표면조도 우수, 절삭 안정적. 단, 미세분진 비산 주의 | 쿨런트 압력 충분히, 환기 |
| **코팅 공구** | 재연마 시 코팅 제거 → 기재(초경) 노출 → 재코팅 의뢰 필요 | 코팅 두께만큼 추가 절입 고려 |

### 8.2 연삭 휠 선택 (간단 가이드)

- **다이아몬드 레진 본드 (Resin Bond Diamond)** — 본 위키 표준. [[연삭-이론-근거]] §4 Self-Dressing 메커니즘 참조.
- **다이아몬드 비트리파이드 본드 (Vitrified Diamond)** — 고생산성·장수명, 그러나 본드·드레서 비용 ↑
- **CBN** — 초경에는 **부적합** (CBN은 강철 계열 연삭용; 다이아몬드와 WC의 친화성으로 인해 초경은 다이아몬드 휠 사용이 표준)

[출처: [[연삭-이론-근거]] §4 / ANCA 공식 기술문서 / Eagle Superabrasives 자료]
