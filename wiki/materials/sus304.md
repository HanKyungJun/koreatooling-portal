# SUS 304 / AISI 304 / 1.4301 — 오스테나이트계 스테인리스강

> 본 페이지는 가장 일반적인 **오스테나이트계 스테인리스강 304**(SUS304 = AISI 304 = X5CrNi18-10 = EN 1.4301)를 다룹니다. 사내 가공·공구 적용 표준 **난삭재 baseline**.
>
> 동일 소재의 다중 표준 명칭:
> - **SUS 304** — JIS (일본·한국 통상)
> - **AISI 304 / SAE 304** — 미국
> - **X5CrNi18-10** — ISO 15510 / EN 10088 표기
> - **1.4301** — EN 강번호 (Werkstoffnummer)
> - **S30400** — UNS (Unified Numbering System)
>
> 신뢰도 등급: **★★★** = ISO·EN·ASTM·JIS 직접 + 교과서 / **★★☆** = 산업 통례 + 1차 출처 / **★☆☆** = 추론

## 2. 화학 조성 ★★★

JIS G 4304:2012 / EN 10088-2:2014 기준:

| 성분 | 함량 (wt%) | 역할 |
|---|---|---|
| **C** (탄소) | ≤ **0.07** | 입계 Cr 카바이드 석출 억제 (낮을수록 좋음) |
| Si | ≤ 1.00 | 탈산제 |
| Mn | ≤ 2.00 | γ상 안정화 |
| P | ≤ 0.045 | 불순물 |
| S | ≤ 0.030 | 불순물 (단, 절삭성 향상) |
| **Cr** (크롬) | **17.5~19.5** | 내식성 핵심 (≥ 12% 부동태 형성) |
| **Ni** (니켈) | **8.0~10.5** | γ상(오스테나이트) 안정화 |
| N (질소) | ≤ 0.10 | γ상 안정화 보조 |
| Fe | 잔여 | 매트릭스 |

> ⚠️ **"18-8 스테인리스"**: 18% Cr + 8% Ni의 약칭이 SUS 304. 가장 일반적인 스테인리스 등급.
> 출처: EN 10088-2:2014 Table 4 / JIS G 4304:2012 Table 2 / ISO 15510:2014.

### 2.1 Cr·Ni·C의 역할

- **Cr ≥ 12%** → 표면 Cr₂O₃ 부동태막 형성 → 내식성
- **Ni 첨가** → 상온에서 γ상(FCC, 비자성) 안정화 → 인성·연성 우수
- **C 0.07% 이하** → Cr₂₃C₆ 입계 석출 억제 (예열·용접 시 입계부식 방지). 더 엄격은 304L (0.030%)

> 출처: Davis (1994). *ASM Specialty Handbook: Stainless Steels*. §2 Metallurgy of Stainless Steels.

## 3. 기계적 물성 ★★★

### 3.1 어닐링 표준 상태 (Annealed, Solution-treated)

| 항목 | 값 | 비고 |
|---|---|---|
| 인장강도 UTS (MPa) | **약 505~750** | 가공경화 시 1,000+ MPa |
| 항복강도 σy 0.2% (MPa) | **약 215~310** | UTS 대비 매우 낮음 (가공경화 여지) |
| 연신율 (%) | **40~60** | 매우 큼 (점성 칩 원인) |
| 경도 HB | **약 201** (max 217) | 어닐링 표준 |
| 경도 HV | 약 210 | — |
| 경도 HRB | 88~92 | — |
| 충격강도 (Charpy V, J) | 100+ (상온) | 매우 우수 |

> 출처: EN 10088-2:2014 Table 3 / JIS G 4304:2012 Table 5 / ASTM A276 §10.

### 3.2 가공경화 후 ⚠️ ★★★

SUS 304는 **가공경화(work hardening)가 극심**한 소재. 절삭·압연·드릴링 표면이 즉시 경화됨:

| 상태 | 경도 (HV) | 인장강도 (MPa) |
|---|---|---|
| 어닐링 (Solution Annealed) | 200 | 600 |
| 1/4 hard | 250~290 | 860+ |
| 1/2 hard | 310~370 | 1,030+ |
| Full hard | 400+ | 1,275+ |
| **절삭 영향부 (sub-surface)** | **표면 250~350** | 표면 800~1,000+ |

> ⚠️ **가공 중 일어나는 변태**: γ → α' (변태 마르텐사이트, 자성) 일부 발생. 절삭열이 부족하거나 변형이 클 때 발생 → 표면이 자성을 띠고 더 단단해짐.
> 출처: Lo, K.H., Shek, C.H., & Lai, J.K.L. (2009). Recent developments in stainless steels. *Materials Science and Engineering: R: Reports*, 65(4-6), 39-104. doi:10.1016/j.mser.2009.03.001 §3.

### 3.3 기타 물성

| 물성 | 값 | 비교 (vs S45C) |
|---|---|---|
| 밀도 (g/cm³) | 8.0 | 약간 무거움 (S45C 7.84) |
| 영률 E (GPa) | 193~200 | 유사 |
| **열전도성 k** (W/m·K) | **약 16.2** | **S45C(50) 대비 1/3 — 가공열 분산 매우 나쁨** |
| 비열 c (J/kg·K) | 500 | 유사 |
| 열팽창계수 α (10⁻⁶/K) | 17.3 | 강(11)보다 1.5배 — 열변형 ↑ |
| 융점 (℃) | 1,400~1,455 | 유사 |
| 전기전도도 | 낮음 (γ상) | 일반 강 < SUS < Al |
| **자성** | **비자성** (γ상) | 가공경화 시 부분 자성 |

> ⚠️ **열전도성 1/3** + **연성 4배** = "**가공열은 도구로 빠지고, 칩은 안 끊어진다**" 의 본질. 모든 SUS304 가공 문제의 출발점.

> 출처: ASM Handbook Vol 1 — Stainless Steels Section / SSINA Stainless Steels Data.

## 4. 미세 구조 ★★★

### 4.1 어닐링 상태

- **상**: γ(FCC) 단일상 — 비자성, 연성·인성 우수
- **결정립**: 등축 ASTM grain size 6~9 (평균 30~70 μm)
- 미세 석출: 미량 δ-페라이트 잔존 가능 (1% 미만, 용접·고온에서 증가)

### 4.2 가공 영향부 (Machining-affected zone)

절삭·소성 가공 시 표면 30~150 μm 범위에서:

1. **변형 유기 마르텐사이트** α' (변태 BCC, 강자성)
2. **전위 밀도 증가** (가공경화 본질)
3. **표면 잔류 응력** (인장)

> 출처: Lo et al. (2009) §3.2 — Strain-induced martensite / Trent & Wright (2000) Ch.6 §6.5.

### 4.3 절삭에 미치는 영향

- 어닐링 상태(연성 ↑) + 가공경화(인접 표면 경화 ↑) → **공구가 동시에 연한 매트릭스와 경한 표면을 절삭** → BUE + 인선 마모 동시 발생
- 낮은 열전도 → 칩-공구 계면 온도 800~1,100°C 도달 → **인선 흐름 + 코팅 박리**
- 비자성 + 칩 분단 불량 → **공작물 주변 점착 칩** 처리 부담

## 5. 가공 특성 (Machinability) ★★★

### 5.1 절삭성 지수

| 기준 소재 | 절삭성 (%) | 비고 |
|---|---|---|
| **AISI 1212 (Free-machining steel)** | 100 (기준) | 표준 기준 |
| **AISI 1045 / S45C** | 57 | C45 |
| **AISI 303** (Free-cut SS, S 첨가) | 78 | SS 중 가장 양호 |
| **AISI 316** (Mo 첨가) | 36 | 304보다 더 어려움 |
| **AISI 304 / SUS 304** | **~45** | **SUS 표준 baseline** |
| **AISI 321** (Ti 안정화) | ~36 | 항공·고온 |
| (참조) Al 6061-T6 | 300 | Al 비교 |
| (참조) Ti-6Al-4V | ~22 | 더 어려움 |

> 출처: Boothroyd & Knight (2006) Table 6.1 + SSINA *Designer Handbook: Machining of Stainless Steels*. SUS 304는 "**중간 난삭**" 범주.

### 5.2 칩 형성 패턴 ★★★

| 절삭속도 영역 | 칩 종류 | 표면 품질 | 메커니즘 |
|---|---|---|---|
| 저속 (V < 50 m/min) | 강한 BUE + 점성 단속칩 | 매우 거침 | **회피** (가공경화 + BUE) |
| 중속 (50~120 m/min) | 연속칩 + 부분 BUE | 보통 | 가장 안정적 황삭 영역 |
| 고속 (120~200 m/min) | 연속칩 (BUE 감소) | 양호 | **정삭 영역** |
| 초고속 (> 200 m/min) | 세그먼트 칩 + 인선 마모 가속 | 양호 | 공구 수명 트레이드오프 |

> 핵심: 알루미늄과 달리 **"무조건 고속"이 답이 아님**. Vc 너무 높이면 인선 온도 + 마모 가속. 120~180 m/min이 sweet spot.

### 5.3 SUS304 가공의 3대 문제 ★★★

1. **가공경화 (Work hardening)** — 인선이 dwelling·rubbing하면 표면 경화 → 다음 절입 시 hardened layer 통과 → 인선 마모 가속
2. **점성 칩** — 칩 분단 불량 → 절삭부 주변 점착 → 표면 손상
3. **낮은 열전도** — 절삭열 80% 이상이 공구로 → 인선 온도 800~1,100°C → 코팅 박리

> 출처: Davim, J.P. (Ed.) (2014). *Machining of Stainless Steels and Super Alloys*. Wiley. Ch.3.

### 5.4 가공경화 회피 핵심 규칙 ★★★

> "**인선이 표면에 머무르거나(dwelling) 비비지(rubbing) 말 것**"

- **이송(fz) 충분히** — 너무 작은 fz는 표면을 비빔 → 가공경화 가속. 최소 fz > nose radius × 0.3 권장
- **절입(ap) 충분히** — 매우 얕은 절입(0.1 mm 이하)은 표면 비비기 → 가공경화 → 다음 패스에서 인선 마모 ↑
- **연속 절삭** — 단속절삭은 매 진입마다 가공경화층 통과 → 가능하면 단속 회피
- **인선 라운딩 작게** — 정삭은 sharp insert (인선 라운딩 < 15 μm) 권장
- **인선 예리하게 유지** — 마모된 인선 = 비비기 = 가공경화 → 마모 한계 보수적 (VB < 0.2 mm)

> 출처:
> - Davim 2014 *Machining of Stainless Steels* Ch.3 §3.2
> - [SAMSHION — 304 CNC Machining Critical Parameters](https://samshionrapid.com/304-stainless-steel-cnc-machining-parameters-finish/)

### 6.2 추천 코팅 ★★★

| 우선 | 코팅 | 적용 영역 | 비고 |
|---|---|---|---|
| 1순위 | **PVD AlTiN / TiAlN** | 고속·정삭 (Vc 120~180) | 내열 1,100°C, 산화 안정 |
| 1순위 | **CVD TiCN + Al₂O₃** | 황삭 (Vc 80~150) | 두꺼운 다층 (TiN + Al₂O₃ + TiCN) |
| 2순위 | TiCN | 중속 | 인선 인성 ↑ |
| 2순위 | **AlCrN** | 황삭·중속 | 내산화 + 인성 균형 |
| 3순위 | TiN | 저속·소량 | 범용, 성능 한계 |
| 회피 | **PCD (Diamond)** | — | ⚠️ **Fe 확산 → 흑연화 → 인선 파손** (강·SS 절대 금기) |

| **고압 합성유 (HPC, 70 bar+)** | **권장** | 인선 온도 ↓ + 칩 배출 + 가공경화 ↓ |
| Emulsion (8~10%) | 표준 | 일반 절삭유 |
| **MQL** | 정밀 가공 | 마이크로 미스트, 박판·표면 |
| 건식 (Dry) | 권장 안 함 | 가공경화·인선 온도 극심 |
| Cl 함유 | **회피** | 응력부식 균열 위험 |

> ⚠️ **고압 쿨런트(HPC)는 SUS 가공의 핵심**. 70 bar 이상 분사로 인선 냉각 + 칩 절단 + 가공경화 억제 동시 달성.
> 출처: Davim 2014 Ch.4 §4.3 / [SAMSHION — 304 Machining Parameters](https://samshionrapid.com/304-stainless-steel-cnc-machining-parameters-finish/).

## 7. 본 위키에서의 위치 — 난삭재 baseline

### 7.1 사용 맥락

- **사내 M그룹 피삭재 표준**: 스테인리스·내열합금 가공의 대표 비교 기준
- **가공경화 메커니즘 학습**: SUS의 work hardening은 직관적이고 빠르게 관찰 → Ti 합금·니켈 베이스 가공 응용 기반

- **공구 수명 사례 비교**: SUS는 V·f·코팅에 매우 민감 — 공구 수명 데이터 변동성을 빠르게 보여줌
