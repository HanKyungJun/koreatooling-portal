# 알루미늄 합금 (Aluminum Alloys) — 피삭재 페이지

> 본 페이지는 **알루미늄 합금 클래스**를 포괄하며, 가공 빈도가 높은 **6061·7075·5052** 3종을 중점 다룹니다. CNC 가공·재연마 현장의 표준 비철(N그룹) 피삭재.

## 2. 화학 조성 ★★★

### 2.1 주요 3종 합금

| 성분 (wt%) | **6061** | **7075** | **5052** |
|---|---|---|---|
| Si | 0.40~0.80 | ≤ 0.40 | ≤ 0.25 |
| Fe | ≤ 0.70 | ≤ 0.50 | ≤ 0.40 |
| Cu | 0.15~0.40 | **1.20~2.00** | ≤ 0.10 |
| Mn | ≤ 0.15 | ≤ 0.30 | ≤ 0.10 |
| **Mg** | **0.80~1.20** | **2.10~2.90** | **2.20~2.80** |
| Cr | 0.04~0.35 | 0.18~0.28 | 0.15~0.35 |
| **Zn** | ≤ 0.25 | **5.10~6.10** | ≤ 0.10 |
| Ti | ≤ 0.15 | ≤ 0.20 | — |
| Al | 잔여 | 잔여 | 잔여 |

> 출처: ISO 209-1:2007 Table A.1, A.2, A.3 / EN 573-3:2019.

### 2.2 합금 분류상 차이

- **6xxx (Mg+Si)** — Mg₂Si 석출상이 시효경화 — 범용 (강도·내식·용접·가공성 모두 균형)
- **7xxx (Zn+Mg+Cu)** — MgZn₂ 석출 — **고강도** (강도 ↑↑, 가공성 ↓, 응력부식 가능)
- **5xxx (Mg)** — Mg 고용 강화 — **내식성 우수** (해양·차체), 가공경화 (열처리 강화 불가)

> 출처: Polmear et al. (2017). *Light Alloys* (5th ed.). Ch.5 §5.2 (시효경화) / Ch.6 §6.1 (5xxx) / Ch.7 (6xxx) / Ch.8 (7xxx).

## 4. 미세 구조 ★★★

### 4.1 6061-T6 (Al-Mg-Si)

- **매트릭스**: α-Al (FCC) + 잔여 Si, Fe, Cu 미세 분산
- **강화 상**: β" (Mg₂Si pre-precipitate) → β' → β (Mg₂Si) 순차 시효
- **결정립**: 50~150 μm 평균

### 4.2 7075-T6 (Al-Zn-Mg-Cu)

- **매트릭스**: α-Al + 미세 분산
- **강화 상**: GP zone → η' (MgZn₂ semi-coherent) → η (MgZn₂) → S (Al₂CuMg)
- **결정립**: 일반적으로 더 미세 (재결정 억제 Cr·Mn)

### 4.3 5052-H32 (Al-Mg)

- **매트릭스**: α-Al + Mg 고용
- **강화 기구**: **고용 강화 + 가공경화** (전위 밀도 증가) — 석출경화 없음
- 결정립: 가공 방향성 (H32 = stabilized 1/4-hard)

> 출처: Polmear et al. 2017. *Light Alloys* Ch.5~8 / ASM Handbook Vol 4: Heat Treating.

### 4.4 절삭에 미치는 영향

| 합금 | 미세조직 특이성 | 가공 영향 |
|---|---|---|
| 6061-T6 | Mg₂Si 미세 석출 | **균질 → 가공성 최상** |
| 7075-T6 | η' 미세 석출 + 분산 강화 | 강도 ↑ → 절삭력 ↑ + 점성 칩 |
| 5052-H32 | 가공경화 매트릭스 | **칩 분단 불량** (연성 ↑) + 점성 |
| 2024-T3 | Al₂CuMg + Cu 함유 | Cu 입자 ↔ 공구 응착·BUE |

## 5. 가공 특성 (Machinability) ★★★

### 5.1 절삭성 지수 (Machinability Index)

| 기준 소재 | 절삭성 (%) | 비고 |
|---|---|---|
| **AISI 1212 (Free-machining steel)** | 100 (기준) | 표준 기준 |
| **6061-T6** | **~300** | 매우 양호 (강철 5~6배) |
| **2011-T3** (Free-cut Al) | **~400** | Al 합금 중 최고 (Pb·Bi 첨가) |
| **7075-T6** | ~200 | 6061 대비 낮음 (강도 ↑) |
| **5052-H32** | ~180 | 점성 칩 |
| **1100-O** | ~150 | 너무 연함 — BUE 빈발 |
| **2024-T3** | ~200 | Cu 함유 응착 위험 |
| (참조) S45C | 57 | C45 기준 |

> 출처: Boothroyd & Knight (2006) Table 6.1 + Aluminum Association *Machining Aluminum Reference*. 절삭성 300은 "**1212 강철 1단위 칩 부피당, 6061 가공 시 3단위 가능**" 의미.

### 5.2 칩 형성·BUE 메커니즘

알루미늄 가공의 **핵심 문제는 BUE와 응착**. 융점 낮고 Al-Al 친화로 공구에 잘 달라붙음.

| 절삭속도 영역 | 칩 종류 | 표면 품질 | BUE |
|---|---|---|---|
| 저속 (V < 50 m/min) | 연속칩 + 강한 BUE | 매우 거침 | **심함** — 회피 |
| 중속 (50~200 m/min) | 연속칩 + 부분 BUE | 보통 | 존재 |
| 고속 (200~600 m/min) | 연속칩 (BUE 감소) | 양호 | 약함 |
| **HSM (> 600 m/min, 6061-T6 PCD)** | 연속칩 (BUE 소멸) | **우수** | **없음** |

> ⚠️ **알루미늄 = "고속이 답"**. 6061 PCD 가공 시 Vc 1,000~3,000 m/min 일반. C45와 정반대 (C45는 V 150~400).
> 출처: Trent & Wright 2000 Ch.10 §10.3 (Non-ferrous machining) / Sandvik Coromant CoroKey N group.

### 5.3 절삭력·열·표면

| 항목 | 알루미늄 (vs C45) | 영향 |
|---|---|---|
| 비절삭저항 (kc, N/mm²) | **~600** (vs C45 ~2,000) | 절삭력 1/3 — 머신 부하 낮음 |
| 열전도성 | **3배+ 높음** | 가공열 → 칩으로 빠르게 빠짐 |
| 융점 | 절반 수준 | 마찰열 시 응착·galling |
| 칩 연성 | 매우 높음 | 칩 분단 어려움 → 작업 안전·청소 부담 |
| 표면 변형 | 매트릭스 연하여 인선 압흔 흔적 | 정삭 인선 라운딩 < 10 μm 권장 |

### 6.2 코팅 — Al에서 "회피해야 하는 코팅"이 핵심 ★★★

| 우선 | 코팅 / 표면 | 적용 | 메커니즘 |
|---|---|---|---|
| 1순위 | **PCD (Polycrystalline Diamond)** | 고생산·HSM | C-C 결합, Al과 무반응 |
| 2순위 | **DLC (Diamond-Like Carbon)** | 범용·정삭 | 저마찰·비응착 |
| 3순위 | **ZrN (지르코늄 나이트라이드)** | 범용·황삭 | Al 친화 없음 |
| 3순위 | **무코팅 polished (Mirror finish)** | 범용 | 가장 단순, 표면 광택 → 응착 ↓ |
| 회피 | **TiAlN / AlTiN** | — | ⚠️ **Al 함유 → Al 워크피스와 친화 → galling**. (강에서는 1순위지만 Al에서는 회피) |
| 회피 | **TiN (일반)** | — | Al에 약함 — DLC가 우월 |

> ⚠️ **TiAlN 회피 근거**: 코팅 자체에 Al이 포함되어 Al 워크피스의 응착(welding/galling)을 유발. 단기 가공·고속에서는 일부 허용되나, 본격적 Al 양산은 PCD·DLC·polished가 표준.

## 7. 본 위키에서의 위치 — 비철 가공 표준

### 7.1 사용 맥락

- **사내 N그룹 피삭재 표준**: 비철(알루미늄·구리·플라스틱) 가공 시 알루미늄이 대표
- **고속 가공(HSM) 사례 학습**: HSM 절삭속도 영역(1,000+ m/min)을 알루미늄으로 학습 → 합금강 HSM 응용 기반
- **공구 응착·BUE 메커니즘 학습**: Al의 BUE는 직관적이고 빠르게 관찰 가능 → 다른 소재 BUE 진단 기준
- **쿨런트 알칼리성·코팅 회피 학습**: 강에서는 TiAlN이 1순위이지만 Al에서는 회피 — 코팅 선택 trade-off 학습 사례
