## 1. 정의 — 코어 직경 (Core Diameter) ★★★

| 기호 | 의미 |
|---|---|
| **d_c** (코어 직경) | 플루트(홈)가 만나지 않는 공구 중앙의 견고한 원기둥 직경. ISO 3002-1 §3.2.4. |
| **D** (외경) | 공구가 가공하는 외측 직경. |
| **dc/D** (코어 비율) | 코어 직경의 외경 대비 비율 — 강성·칩 배출 트레이드오프의 핵심 지표. |
| **d_web/D** (웹 두께비) | 드릴 전용 표기. ISO 3002-1·DIN 1898 정의. d_web ≈ d_c |

[출처: ISO 3002-1:1982 *Basic quantities in cutting and grinding* §3.2.4 / Engin & Altintas 2001]

## 2. 강성 vs 칩 배출 트레이드오프 ★★★

### 2.1 코어 ↑ → 강성 ↑ (4승 비례)

공구 굽힘강성 (cantilever beam 모델):

```
I ∝ d_c⁴       ← 원기둥 단면 2차 모멘트
δ ∝ F·L³/(E·I) ← 처짐
```

→ **코어 직경 10% 증가 → 강성 약 46% 증가** (1.1⁴ ≈ 1.46). 채터·휨 감소.

### 2.2 코어 ↑ → 칩 배출 ↓

칩 배출 단면적:

```
A_chip = π/4 × (D² - d_c²)
```

→ 코어가 클수록 칩이 빠져나갈 공간 감소 → 알루미늄·플라스틱처럼 칩이 많은 소재 가공 시 불리.

### 2.3 trade-off 요약

| 우선 | dc/D 권장 | 적용 |
|---|---|---|
| **강성 우선** | 0.60~0.65 | 고경도재(HRC 45+), 고이송, 채터 우려 |
| **균형** | 0.50~0.60 | 일반 강·SUS·주철 (산업 표준) |
| **칩 배출 우선** | 0.45~0.50 | 알루미늄, 플라스틱, 복합재 |

[출처: Engin & Altintas (2001) *Int. J. Machine Tools Manuf.* 41(15) / Smith (2008) Ch.5]

## 7. 피삭재별 보정 계수 ★★☆

기본 dc/D 권장값에 곱해서 피삭재 특성 반영:

| 피삭재 | 보정 계수 | 근거 |
|---|---|---|
| 일반 강 (S45C 등) | **×1.00** | 기준 (산업 표준) |
| 스테인리스 (SUS304/316) | **×1.05~1.10** | 가공 경화 → 절삭력 ↑ → 강성 ↑ 필요 |
| 티타늄·인코넬 (Ti·Ni base) | **×1.10~1.15** | 절삭력 + 진동 ↑ → 강성 극대 |
| 알루미늄 (A6061/7075 등) | **×0.85~0.95** | 칩 배출 ↑ → 코어 ↓ 유리 |
| 주철 (FC, FCD) | ×1.00 | 일반 강과 유사 (단속적 칩) |

> ⚠️ 본 보정 계수는 카탈로그 권장값 + Smith (2008) Ch.5 + Boothroyd & Knight (2006) Ch.7 종합. 향후 사내 절삭 테스트 누적되면 **자체 보정 계수로 갱신**.

## 8. 의사결정 4단계 워크플로우 (xlsx 시트 0 표준)

신규 공구 코어 결정 시 다음 4단계:

```
① 형상 확인
   ↓
② §3 권장 dc/D 조회 (해당 형상의 권장값)
   ↓
③ §4 직경별 표준 코어 dc 계산 (D × dc/D)
   ↓
④ §5 카탈로그 교차 검증 (해당 직경의 카탈로그 값과 비교)
   ↓
⑤ §6 유사 사내 케이스 참조 (ANCA 마스터 비슷한 케이스 찾기)
```

피삭재가 강/주철 외(SUS·Ti·Al)면 §7 보정 적용.

## 9. Re Grind 공정 시 코어 처리 ★★★

ANCA 마스터의 Re/Re Grind 폴더에서 `final_core_diam`이 미입력된 9건은 **작업 누락이 아닌 정상 관행** (decisions.md 2026-05-14 #2):

- 사내 Re Grind 공정은 "**OD 가공 없이 BALL 부분만 재가공**"하는 볼노즈 엔드밀 전용 재연마
- OD가 변하지 않으므로 d_c 도 변하지 않음 → 재입력 불필요
- Malkin & Guo (2008) *Grinding Technology* Ch.9 "재연마 사이클에서 코어는 거의 변화 없음" 학술 근거
