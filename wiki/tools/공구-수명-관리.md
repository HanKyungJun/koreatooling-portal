# 공구 수명 관리

> 본 페이지는 초경 절삭공구의 **수명 자체**에 집중합니다.
> - 표면 품질 불량은 [[표면조도-불량]] 참조
> - 케이스별 연삭 조건 기록은 [[연삭-조건-기록]] 참조
> - 본 페이지는 ISO 8688 마모 분류, 수명 측정·예측, 재연삭 사이클 이론에 특화
>
> ★★★ = 학술 논문·국제 표준 직접 근거 | ★★☆ = 간접 지지 + 산업 통례 | ★☆☆ = 현장 추론

## 1. 공구 수명 — 정의 ★★★

**공구 수명 (Tool Life, T)**: 공구가 규정된 마모 기준(예: VB = 0.3 mm) 또는 파손에 도달할 때까지의 실효 사용 시간 또는 가공 수량.

ISO 표준 기반 정의:
- **ISO 3685:1993** — 단일 인선 선삭공구 수명 테스트
- **ISO 8688-1:1989** — 페이스 밀링 공구 수명 테스트
- **ISO 8688-2:1989** — 엔드 밀링 공구 수명 테스트

### 1.1 수명 표현 단위

| 단위 | 의미 | 사용 상황 |
|---|---|---|
| **분 (min)** | 실 절삭 시간 | 실험·연구실 표준 |
| **개수 (pcs)** | 동일 가공 수행 수 | 현장 빈출 — 본 위키 표준 |
| **거리 (m, mm)** | 절삭 경로 길이 | 자동화 라인 |
| **부피 (mm³)** | 제거 재료 부피 | 절삭조건 비교 |

> 본 위키 표준: **가공 수량(pcs) 기반** + 보조로 절삭 시간 병기.

## 2. 마모 유형 Taxonomy (ISO 3685 기준) ★★★

절삭공구 마모는 **위치·메커니즘**에 따라 분류:

### 2.1 위치별 마모 유형

| 유형 | 위치 | 측정 기호 | 주 메커니즘 |
|---|---|---|---|
| **플랭크 마모 (Flank Wear)** | 여유면 (clearance face) | VB | 마찰성 마모, 표준 마모 |
| **크레이터 마모 (Crater Wear)** | 경사면 (rake face) | KT (깊이) | 확산·산화 (고온) |
| **노치 마모 (Notch Wear)** | DOC 경계 | VN | 가공 경화층, 산화 |
| **인선 라운딩 (Edge Rounding)** | 인선 자체 | r_β 증가 | 미세 파괴 누적 |
| **치핑 (Chipping)** | 인선·코너 | 결손 깊이 | 충격 부하, 진동 |
| **파괴 (Fracture)** | 전체 | 파손 길이 | 과대 부하, 인성 한계 초과 |

### 2.2 메커니즘별 마모

| 메커니즘 | 지배 온도 | 특징 | 학술 근거 |
|---|---|---|---|
| **연마성 마모 (Abrasive)** | 저~중온 | 피삭재 경질 입자에 의한 미세 절단 | Archard 법칙 |
| **접착성 마모 (Adhesive)** | 중온 | BUE (Built-Up Edge) 형성·탈락 | Trent & Wright 2000 |
| **확산성 마모 (Diffusion)** | 고온 (>800℃) | 공구 원소가 칩으로 확산 | Komanduri 2001 |
| **산화성 마모 (Oxidation)** | 고온 | 노치 마모와 결합 | Trent & Wright 2000 |
| **화학성 마모 (Chemical)** | 가변 | 코팅-피삭재 화학 반응 | 코팅 종류별 상이 |

> 초경 공구의 일반 동작 영역에서는 **연마성 마모 + 접착성 마모**가 지배적. 고속·난삭재에서는 확산·산화 마모 증가 [출처: Trent & Wright 2000, Ch.4].

### 2.3 ISO 8688 기준 — 플랭크 마모 측정

- **VB (평균 플랭크 마모폭)** — 전체 절삭 인선의 마모 평균
- **VB max (최대 플랭크 마모폭)** — 가장 마모가 진행된 지점
- **VC (코너 마모)** — 코너부 마모

ISO 8688-2 권장 수명 기준 (엔드밀):
- VB = 0.3 mm (정삭) 또는 VB = 0.4 mm (거친 가공)
- VB max = 0.6 mm (안전 한계)

## 3. Taylor 공구 수명 방정식 ★★★

1907년 Frederick W. Taylor가 제시한 절삭속도-수명 경험식 [출처: Taylor, F.W. (1907). *On the art of cutting metals*. ASME]:

```
V × T^n = C
```

| 기호 | 의미 |
|---|---|
| V | 절삭속도 (m/min) |
| T | 공구 수명 (min) |
| n | 지수 (재료·공구 조합에 따라 0.1~0.7) |
| C | 상수 (V=1 m/min에서의 수명) |

### 3.1 확장 Taylor 식 (현대 표준)

Taylor 원식은 절삭속도만 고려. 현대 식은 feed·DOC 포함:

```
V × T^n × f^a × d^b = C
```

| 기호 | 의미 | 일반 지수 |
|---|---|---|
| f | 이송 (feed per tooth) | a ≈ 0.5~0.8 |
| d | 절입 (depth of cut) | b ≈ 0.1~0.4 |

> 절삭속도 V가 수명에 가장 큰 영향. 다음이 feed, 그 다음이 DOC.

### 3.2 본 위키 적용 — 연삭과 절삭의 차이

본 위키의 주 작업은 **재연삭** (그라인딩)이며 위 Taylor 식은 **절삭** 공구 수명 식. 연삭 휠 수명은 별도 모델 (Wheel Life, drainage of wheel) — [[연삭-이론-근거]] §4 self-dressing 사이클 참조.

**연삭으로 재가공된 공구의 다음 절삭 사이클 수명**에 Taylor 식 적용 가능. 단, n·C 값은 본 사내 등급·피삭재 조합에서 실측 필요.

## 4. 재연삭 사이클 이론 ★★☆

### 4.1 재연삭 가능 횟수 추정

| 변수 | 의미 | 일반 값 (초경 엔드밀) |
|---|---|---|
| L_total | 공구 전체 인선 길이 | 직경·형상 의존 |
| L_grind | 1회 재연삭 시 제거 길이 (인선 후퇴) | 0.05~0.3 mm |
| L_safe | 사용 가능 인선 최소 길이 | 직경의 약 30% |
| **N_regrind** | **가능 재연삭 횟수** | **(L_total - L_safe) / L_grind** |

> 예시: D8 엔드밀, L_total=8 mm 인선, L_grind=0.15 mm, L_safe=2.4 mm
> → N_regrind = (8 - 2.4) / 0.15 ≈ **37회**
> 실제는 코너 파손·코팅 손실·치수 한계로 더 적음 (보통 5~15회).

### 4.2 재연삭 효율 (회사 경제성 관점)

```
재연삭 효율 = (재연삭 후 평균 수명) / (신품 평균 수명)
```

| 효율 | 의미 | 조치 |
|---|---|---|
| > 0.9 | 신품 대비 90%+ | 우수, 표준 절차 유지 |
| 0.7~0.9 | 일반적 범위 | 정상 |
| < 0.7 | 효율 저하 | 재연삭 절차 점검 (휠·조건·재코팅) |

> 효율 < 0.5 시 폐기가 경제적일 가능성. 카탈로그 ([VEN-JJ], [VEN-COGO]) 기준 신품 단가 대비 재연삭 비용·수명 trade-off 분석 필요.

## 5. 재연삭 판단 기준 (실무) ★★☆

### 5.1 정성 기준 (육안)

| 상태 | 기준 | 조치 |
|---|---|---|
| 정상 | 인선 광택 유지, 마모 미미 | 계속 사용 |
| 주의 | 가공 음 변화, 표면조도 저하 시작 | 모니터링 강화 |
| 재연삭 필요 | 인선 마모 육안 확인, Ra 목표값 초과 | 재연삭 의뢰 |
| 폐기 | 파손·결손, 재연삭 여유 미달 (L_safe 이하) | 폐기 처리 |

### 5.2 정량 기준 (측정 기반, 권장)

| 측정 항목 | 한계값 (참고) | 측정 방법 |
|---|---|---|
| VB (플랭크 마모폭) | 0.3 mm (정삭) / 0.4 mm (거친 가공) | 광학 현미경 또는 비전 시스템 |
| 인선 라운딩 r_β | 초기 r_β의 3배 | SEM 또는 광학 |
| 가공면 Ra | 목표값 + 30% | 거칠기계 ([[표면조도-불량]] §1) |
| 절삭 부하 (스핀들 부하) | 초기 부하 + 30% | NC 컨트롤러 모니터 |

> 정량 기준 도입 시 일관성 ↑. ISO 8688 권장 VB 기준 적용이 출발점.

### 6.2 재연삭 수명 — 사내 평균 데이터

### 6.3 재연삭 한계 — 회사 표준

> [확인: 2026-06-05 한경준] **최대 재연삭 횟수 기준 미확립.** 폐기 판단 기준은 **날장(인선) 잔여 길이** — 날장이 충분히 남아있으면 재연삭 가능, 소진되면 폐기. 구체적 mm 기준은 형상·직경별로 다르며 현재 수치화 안 됨. 신뢰도: 사내 경험값.
>
> **핵심 원칙 (2026-06-05 확정)**: 최대 횟수가 아닌 **날장 잔여량**이 재연삭 가능 여부의 실질 기준.
>
> 향후 기준 수립 시 아래 표를 채워 폐기 기준으로 활용 권장:
> - 볼·코너R Ø2~Ø4: 공구 짧아 인선 잔여 소모 빠름 → 상대적으로 적은 횟수 예상
> - 공통 폐기 트리거 후보: "날장 소진", "수명 효율 < 60%", "코너 파손 발생", "직경 공차 이탈"
