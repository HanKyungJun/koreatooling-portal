# 홍익다이아 본드 체계 (Bond Types)

홍익다이아 카탈로그 표지(p.1)에는 **5종**의 본드가 명시되어 있습니다. 카탈로그 본문(p.2~15)에서 각 형식별로 권장 본드가 박스 형태로 표기되어 있으며, 본 페이지는 이를 정리한 자료입니다.

> 📄 출처: 홍익다이아 catalogue 영문.pdf p.1 (Cover) — Resin · Vitrified · Metal · Electrodeposition · Hybrid 5종 명시.

---

## 1. 본드별 카탈로그 적용 현황

| 본드 | 영문 표기 | 카탈로그 형식 | 카탈로그 페이지 |
|------|---------|------------|--------------|
| 레진 | RESIN | 11V9, 12V9, 1A1, 3A1, 14A1, 1V1, 3V1, 14V1 (Resin or Hybrid 선택), 11V5, 4B1 (Finishing), 12A2 | p.2~13, p.15 |
| 하이브리드 | HYBRID | 11V9, 12V9, 1A1, 3A1, 14A1, 1V1, 3V1, 14V1 (Resin or Hybrid 선택) | p.2~11 |
| 비트리파이드 | VITRIFIED | 6A2 | p.14 |
| 메탈 | METAL | 4B1 (Roughing process) | p.13 |
| 전착 | ELECTRODEPOSITION | (표지에만 명시, 본문 형식 없음) | p.1 |

## 2. 본드 특성 (일반 산업 기준)

> ⚠️ 아래 특성은 **연삭공학 일반 지식**(FEPA / DIN 8589) 기준이며, 홍익다이아 카탈로그에는 본드별 상세 특성이 기재되지 않았습니다. 실제 발주 시 공급사 기술 자료 별도 확인이 필요합니다.

### 레진(Resin / B) 본드

| 항목 | 내용 |
|------|------|
| 결합재 | 페놀계 열경화성 수지(주로 페놀-포름알데히드) |
| 강도 | 중간 — 유연성 있음 |
| 자생작용(self-dressing) | 양호 — 마모된 입자가 적절히 탈락하며 새 입자 노출 |
| 표면 거칠기 | 우수 (Ra 낮음) — 마감용에 적합 |
| 권장 원주속도(Vc) | **18 ~ 25 m/s** (레진 본드 상한) — 본 위키 보유 휠과 동일 |
| 단점 | 열에 약함, 고하중·고온에서 결합재 열화 |
| 주 용도 | Endmill Flute / Gash, End Tooth, OD Finishing |

> 출처: 본 위키 [[index|휠 카탈로그]] 공통 스펙 (보유 휠 = HID Resin 본드 / Vc 25 m/s 상한).
> 학술 참조: Marinescu, I. D. et al. (2007). *Handbook of Machining with Grinding Wheels*. CRC Press. Ch. 3 — Resin Bond Wheels.

### 하이브리드(Hybrid) 본드

| 항목 | 내용 |
|------|------|
| 결합재 | Resin + Metal 또는 Resin + Vitrified의 복합 |
| 특성 | Resin의 자생작용 + Metal/Vitrified의 형상유지력 |
| 권장 원주속도 | Resin보다 높음 (제조사별 차이) |
| 카탈로그 표기 | "Bond Type: RESIN or HYBRID" (선택 가능) — p.2~11 |

> 출처: 홍익다이아 카탈로그 p.2~11 (8종 형식에서 Resin 또는 Hybrid 선택 가능 명시).
> 학술 참조: Webster, J. & Tricard, M. (2004). "Innovations in Abrasive Products for Precision Grinding". *CIRP Annals*, 53(2), 597-617.

### 비트리파이드(Vitrified / V) 본드

| 항목 | 내용 |
|------|------|
| 결합재 | 세라믹 (유리화 결합재 — 약 1200°C에서 소결) |
| 강도 | 강함 — 형상유지 우수 |
| 권장 원주속도 | 30~45 m/s (CBN: 60 m/s 이상도 가능) |
| 단점 | 충격에 약함, 드레싱 까다로움 |
| 카탈로그 적용 | **6A2 (p.14)** — Endmill Flute/Gash |
| 주 용도 | 고정밀 마감, 고온 안정성 필요한 공정 |

> 출처: 홍익다이아 카탈로그 p.14 (6A2, Vitrified 단독 표기).
> 학술 참조: Jackson, M. J. & Davim, J. P. (2011). *Machining with Abrasives*. Springer. Ch. 2 — Vitrified Bond Wheels.

### 메탈(Metal / M) 본드

| 항목 | 내용 |
|------|------|
| 결합재 | 청동·구리·니켈·코발트계 금속 |
| 강도 | 매우 강함 — 마모율 낮음 |
| 자생작용 | 낮음 — 정기적 드레싱 필수 |
| 카탈로그 적용 | **4B1 Roughing (p.13)** — Endmill Cylindrical Grinding |
| 주 용도 | 황삭, 절단, 유리·세라믹 가공 |

> 출처: 홍익다이아 카탈로그 p.13 ("4B1 ... ROUGHING PROCESS: Bond Type RESIN or METAL").

### 전착(Electrodeposition / Plated) 본드

| 항목 | 내용 |
|------|------|
| 결합재 | 니켈 전착(단층) — 입자가 표면에 박혀 노출 |
| 입자 노출 | 최대 (입자 직경의 50~70%까지 돌출) |
| 수명 | 짧음 — 단층이므로 마모 시 재생 불가 |
| 카탈로그 적용 | **본문 형식 없음** (표지만 명시) |
| 주 용도 | 형상 정밀도 필요한 프로파일 가공, 의료기기 |

> 출처: 홍익다이아 카탈로그 p.1 (Cover에만 명시).
> 학술 참조: Krar, S. F. & Ratterman, E. (2003). *Superabrasives: Grinding and Machining with CBN and Diamond*. McGraw-Hill.

## 3. 본드별 권장 원주속도 (학술 참조)

> ⚠️ 카탈로그에 본드별 Vc 상한 표기가 없으므로 아래는 **연삭공학 일반 기준**입니다.

| 본드 | 권장 Vc (m/s) | 비고 |
|------|--------------|------|
| Resin | 18 ~ 25 | 본 위키 보유 휠 적용 기준 |
| Vitrified (Diamond) | 25 ~ 45 | 일반적으로 30 m/s 전후 |
| Vitrified (CBN) | 60 ~ 120 | 고속 CBN 가공 |
| Metal (Bronze) | 20 ~ 35 | |
| Electrodeposition | 25 ~ 80 | 입자·기재에 따름 |

> 출처:
> - Marinescu, I. D., Hitchiner, M., Uhlmann, E., Rowe, W. B., & Inasaki, I. (2007). *Handbook of Machining with Grinding Wheels*. CRC Press. Table 3.2 — Bond System Operating Speed Ranges.
> - 본 위키 [[index|휠 카탈로그]] — 보유 휠(HID Resin) Vc 25 m/s 상한 기준.
