# 홍익다이아 형상 분류 (Shape Codes)

홍익다이아 카탈로그(p.2~15)는 **FEPA 슈퍼아브레시브 휠 형상 표준 코드**(ISO 6168 / FEPA 표준)를 사용하여 12종의 형식을 표기합니다. 본 페이지는 각 형식의 단면 형상과 카탈로그 명시 치수 변수(D, T, U, X, V, H, W, S)를 정리합니다.

> 📄 출처: 홍익다이아 catalogue 영문.pdf p.2~15 + FEPA 표준 표기 규칙.

---

## 1. 카탈로그 공통 치수 변수 (Dimension Notation)

카탈로그 본문(p.2~15) 표 헤더에 사용된 변수:

| 변수 | 의미 | 단위 |
|------|------|------|
| **D** | Diameter — 휠 외경 | mm |
| **T** | Thickness — 휠 두께 (전체) | mm |
| **U** | Layer Depth — 연삭재(다이아몬드/CBN) 층 두께 | mm |
| **X** | Layer Width — 연삭재 층 폭 (반경방향) | mm |
| **V** | Angle — 휠 각도 (V형 각도) | ° (도) |
| **W** | Width — 휠 폭 (특정 형식) | mm |
| **S** | Secondary angle — 보조 각도 (12A2) | ° (도) |
| **H** | Hole — 중심 구멍 직경 | mm |

> 출처: FEPA Standard for Superabrasive Products / ISO 6168.
> 카탈로그는 H 표기에 "20 / 31.75"를 사용 — 이는 **두 가지 표준 보어 사이즈**(Ø20mm 또는 Ø31.75mm = 1¼")를 의미합니다.

## 2. 형식 12종 단면 해설

### 2.1 1A1 — 스트레이트 휠 (Flat / Peripheral Wheel)

```
       ┌───────┐
       │  연삭재  │ ← X (반경방향 두께)
       │       │
       │       │  T (휠 두께)
       │       │
       │       │
       └───┬───┘
           │ H (보어)
```

| 특징 | 내용 |
|------|------|
| 단면 | **완전 평면 디스크** — 외주면 전체가 연삭면 |
| 주 연삭면 | 외주면 (Peripheral) |
| 카탈로그 치수 | D 100~150, X 8~10, T 8~12, H 20/31.75 (p.4) |
| 그릿 (Diamond) | D46 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B126 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.4 (1A1 형식).
> FEPA 정의: 1A1 = 단순 스트레이트 휠, 연삭재가 외주면 전체에 도포된 가장 기본 형상.

### 2.2 3A1 — 프로파일 휠 (Profile Flat Wheel)

```
         ┌─────────┐
       ┌─│  연삭재  │   ← X
       │ │         │
       U │         │
       └─┤         │  T
         │         │
         └────┬────┘
              │ H
```

| 특징 | 내용 |
|------|------|
| 단면 | 외주에 **단차(step) 프로파일** — 연삭재 층이 U 깊이로 형성 |
| 주 연삭면 | 외주 + 측면 (프로파일 모서리) |
| 카탈로그 치수 | D 100~150, X 5~8, U 1~6, T 8, H 20/31.75 (p.5) |
| 그릿 (Diamond) | D15 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B91 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.5 (3A1 형식).

### 2.3 14A1 — 프로파일 휠 변형 (Profile Flat Variant)

| 특징 | 내용 |
|------|------|
| 단면 | 3A1과 유사하나 **프로파일 코너 사양 차이** |
| 카탈로그 치수 | D 100~150, X 5~8, U 1~6, T 8, H 20/31.75 (p.6) — **3A1과 표 동일** |
| 그릿 (Diamond) | D15 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B91 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.6 (14A1 형식).
> 참고: FEPA 표준에서 14A1은 1A1의 **반대편 코너 모따기/프로파일** 변형입니다. 카탈로그 표는 3A1과 동일하나 형상 코드가 다르므로 모서리 사양이 다른 것으로 추정.

### 2.4 1V1 — V각도 스트레이트 (Tapered Straight)

```
       ┌───────┐
       │ 연삭재  │  
       └──╲    │  ← V° (테이퍼 각)
           ╲   │
           │   │  T
           │   │
           └─┬─┘
             │ H
```

| 특징 | 내용 |
|------|------|
| 단면 | 외주에 **V각도 테이퍼** — 한쪽 모서리 경사 |
| V 각도 | 5° ~ 45° (카탈로그 사양 9단계) |
| 카탈로그 치수 | D 100~150, X 8~10, T 8~12, V 5~45°, H 20/31.75 (p.7) |
| 그릿 (Diamond) | D46 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B126 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.7 (1V1 형식). V 5°/10°/15°/20°/25°/30°/35°/40°/45° 9단계.

### 2.5 3V1 — V각도 프로파일 (V Profile)

| 특징 | 내용 |
|------|------|
| 단면 | 3A1의 프로파일 + 1V1의 V각도 = **단차 프로파일 + 테이퍼** |
| V 각도 | 5° ~ 45° (9단계) |
| 카탈로그 치수 | D 100~150, X 6~8, U 2~6, T 8, V 5~45°, H 20/31.75 (p.8) |
| 그릿 (Diamond) | D15 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B91 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.8 (3V1 형식).

### 2.6 14V1 — V각도 프로파일 변형

| 특징 | 내용 |
|------|------|
| 단면 | 14A1의 프로파일 + V각도 — **3V1의 반대편 코너 사양** 변형 |
| 카탈로그 치수 | D 100~150, X 6~8, U 2~6, T 8, V 5~45°, H 20/31.75 (p.9) — **3V1과 표 동일** |
| 그릿 (Diamond) | D15 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B91 |
| 본드 | Resin / Hybrid |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.9 (14V1 형식).

### 2.7 11V9 — 플레어링 컵 (Flaring Cup Wheel)

```
       ╱─────────╲
      ╱           ╲    ← V° (플레어 각)
     │             │
     │             │  T (컵 깊이)
     │   연삭재     │
     │   ┌───┐    │
     │   │   │    │
     └───┴─┬─┴────┘
           │ H
```

| 특징 | 내용 |
|------|------|
| 단면 | **플레어링 컵** — 컵 형상에 V각도 플레어 |
| V 각도 | **20°** (고정) |
| 카탈로그 치수 | D 75~150, T 30~40, U 10, X 2~3, V 20°, H 20/31.75 (p.2, p.10) |
| 그릿 (Diamond) | D15 ~ D91 |
| 그릿 (HSS/CBN) | B46 ~ B126 |
| 본드 | Resin / Hybrid |
| 주 용도 | **End Tooth / Edge Clearing** (엔드밀 끝날·여유면) |

> 출처: 홍익다이아 카탈로그 p.2 + p.10 (11V9 형식, 2회 등장 — 동일 표).

### 2.8 12V9 — 디시 휠 (Dish Wheel, 45°)

| 특징 | 내용 |
|------|------|
| 단면 | **얕은 접시(디시)** 형상 — V각도 45° 고정 |
| V 각도 | **45°** (고정) |
| 카탈로그 치수 | D 100~150, T 22~32, U 10, X 2~3, V 45°, H 20/31.75 (p.3, p.11) |
| 그릿 (Diamond) | D15 ~ D91 |
| 본드 | Resin / Hybrid |
| 주 용도 | End Tooth / Edge Clearing |

> 출처: 홍익다이아 카탈로그 p.3 + p.11 (12V9 형식).
> HSS grit 컬럼 없음 — 다이아몬드 그릿만 표기.

### 2.9 11V5 — 소서 휠 (Saucer Wheel)

| 특징 | 내용 |
|------|------|
| 단면 | 11V9의 변형 — **소서(접시) 형상**, V각도 더 완만 |
| V 각도 | 10°, 15°, 20° (카탈로그 명시) |
| 카탈로그 치수 | D 75~125, T 25, W 3~10, X 5, V 10/15/20°, H 20/31.75 (p.12) |
| 그릿 (Diamond) | D20 ~ D64 |
| 그릿 (HSS/CBN) | B46 ~ B91 |
| 본드 | **Resin 단독** (Hybrid 없음) |
| 주 용도 | **OD Grinding** (외경 연삭) |

> 출처: 홍익다이아 카탈로그 p.12 (11V5 형식).
> 11V5는 카탈로그에서 유일하게 "W" 변수를 사용 (휠 폭).

### 2.10 4B1 — 실린드리컬·스텝 (Cylindrical / Step Grinding)

| 특징 | 내용 |
|------|------|
| 단면 | 양쪽 측면에 V각도 — **실린드리컬 + 스텝 가공** 전용 |
| V 각도 | 10° (Roughing), Finishing은 V 표기 없음 |
| 카탈로그 치수 (Roughing) | D 200~250, T 20, U 3~8, X 6~8, V 10°, H 31.75 (p.13 상단) |
| 카탈로그 치수 (Finishing) | D 150, T 24, U 2~3, X 6, H 31.75 (p.13 하단) |
| 그릿 (Roughing) | D64 ~ D91 (Diamond) |
| 그릿 (Finishing) | D8 ~ D30 (Diamond) |
| 본드 (Roughing) | **Resin or Metal** |
| 본드 (Finishing) | Resin |
| 주 용도 | Endmill **외경 + 스텝** 가공 |

> 출처: 홍익다이아 카탈로그 p.13 (4B1 형식, Roughing/Finishing 2개 표 분리).
> 보어 표기 31.75만 사용 (20mm 옵션 없음).

### 2.11 6A2 — 스트레이트 컵 (Straight Cup, Vitrified)

| 특징 | 내용 |
|------|------|
| 단면 | **직각 컵 형상** — 컵의 평면이 연삭면 |
| 카탈로그 치수 | D 150, T 40, W 6~20, X 8, H 31.75 또는 40 (p.14) |
| 그릿 (Diamond) | D6 ~ D46 |
| 본드 | **Vitrified 단독** |
| 주 용도 | Endmill Flute / Gash |

> 출처: 홍익다이아 카탈로그 p.14 (6A2 형식).
> 카탈로그 형식 중 유일한 **비트리파이드 단독** 사양.

### 2.12 12A2 — 디시 (Edge / Peripheral)

| 특징 | 내용 |
|------|------|
| 단면 | **디시 형상** + 보조 각도(S) 적용 |
| V 각도 | 20° (카탈로그 명시) |
| S 각도 | 3° (보조 각) |
| 카탈로그 치수 | D 125~150, T 15, W 6~10, X 3, S 3°, H 10/12.7/15.88/25/31.75 (p.15) |
| 그릿 (Diamond) | D46 ~ D91 |
| 본드 | Resin |
| 주 용도 | **Edge Grinding / Peripheral Grinding** |

> 출처: 홍익다이아 카탈로그 p.15 (12A2 형식).
> 보어 표기 5종 (10, 12.7, 15.88, 25, 31.75) — 인치 환산 가능: 12.7 = ½″, 15.88 = ⅝″, 25.4 = 1″.
