# 휠 5도 (Ø125, #400 / 스택 1-2)

스택 1-2에 장착되는 사다리꼴 단면 앵글 휠. 평 엔드밀 End Face Gash (D10, D4) 전용.

## 1. 기본 제원

| 항목 | 값 |
|------|---|
| 형상 | 사다리꼴 단면 |
| 휠 직경 (mm) | Ø125 |
| 두께 T (mm) | 5 |
| 각도 | V 5° |
| 코너 R (mm) | R1/R2 0.102 |
| Flipped | O (뒤집어 장착) |

## 2. 연삭재 · 결합재

| 항목 | 값 |
|------|---|
| Grit | #400 |
| Bond | — (정보 미제공) |
| Abrasive | 다이아몬드(D) |
| 결합도 | R (HID 최고 경도 등급 / J→L→N→P→R) |
| 집중도 | C125 (5.5ct/cc, 높은 집중도) |

## 3. 원주속도 계산표 (Ø125) — 레진 본드 기준

| RPM | 원주속도 (m/s) | 판정 |
|-----|---------------|------|
| 2,750 | 18.1 | 레진 하한 (권장 최소) |
| 3,000 | 19.6 | 권장 구간 |
| 3,500 | 22.9 | 권장 구간 |
| **3,820** | **25.0** | **레진 상한 ← 최대 허용 RPM** |
| 4,000 | 26.2 | ⚠️ 초과 — 사용 금지 |
| 6,000 | 39.3 | 🚫 위험 — 휠 파손/버닝 |

> ⚠️ **레진 본드 제한**: Vc 25 m/s 초과 시 결합재 열화 및 휠 파손 위험. Ø125 기준 **최대 3,820 rpm**. 장비 최대(6,000 rpm) 절대 사용 금지.
