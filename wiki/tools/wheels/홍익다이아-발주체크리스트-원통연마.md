# 홍익다이아 문의·발주 체크리스트 — 원통연마 휠 A·C·D

> 🟡 **2026-08-28 긴급도 하향(문의 자체는 유지)** — 실사용 RPM이 **2,600~3,400**(Ø125 기준 17.0~22.3 m/s)으로 확인돼 사내 상한 25 m/s의 **89 % 이하**임이 확정됐습니다 [사내 확인]. Vmax 미확보 상태의 실질 위험이 낮아졌고, 이에 묶여 있던 미종결 3건도 회신 없이 종결됐습니다 → [[index]] §✅ 2026-08-28. **다만 문의는 그대로 발송합니다** — ①라벨 미부착 자체가 현장 식별 수단 부재라는 별개 문제이고 ②향후 조건 상향 시 Vmax가 다시 선결 조건이 되기 때문입니다.

> ✅ **상태: 발주 요청 완료 (2026-07-02)** — 아래 체크리스트 기준으로 한경준님이 홍익다이아에 발주 요청함. 이후 단계는 §6(답변 기록)·§7(이력) 참조.

## 4. 제조사에 확인할 질문 목록

### 4-1. 설계·형상

- [ ] 12° 경사 + Neck 원통부 형상 제작 가능 여부
- [ ] 도면 없이 구두 사양만으로 제작 가능한지, 아니면 도면(DXF/PDF) 필수 여부
- [ ] Neck 직경(목 OD)은 얼마로 설계하는가 — 공구 직경별 간섭 여부 확인 필요
- [ ] 두께(T) 추정값(Neck + 6mm, 휠 A·C 기준) 적정 여부 — 제조사 최소 바디 두께 기준
- [ ] Ø100 vs Ø125 중 이 형상에 더 적합한 외경 추천
- [ ] 휠 D의 얇은 경사부(B=7mm)가 Resin Diamond 제작 공차상 실현 가능한지

### 4-2. 재료·Bond

- [ ] 원통 연마(Cylindrical Grinding) 용도에 권장 Bond 종류 (Resin vs Vitrified vs Metal)
- [ ] Diamond vs CBN — 초경 공구 원통 연마 시 어느 연삭재 권장
- [ ] Concentration(집중도, %) 권장값
- [ ] 입자 번호 #400·#500 모두 제작 가능 여부 (또는 동일 휠로 커버 가능한 범위)

### 4-3. 안전·운용

- [ ] **최대 허용 RPM** (안전 인증값) — 반드시 서면으로 받을 것 ⚠️
- [ ] 장착 플랜지 규격 — 사내 장비에 맞는 어댑터/플랜지 필요 여부
- [ ] 초기 밸런싱 처리 여부 (공장 출하 전 밸런싱 가능 여부)
- [ ] 드레싱 권장 방법 (다이아 드레서 / SiC 드레싱 롤 / 롤러)
- [ ] 드레싱 주기 기준 (가공 공구 수 or 시간 or 조도 기준)

#### 🔴 4-3-A. Vmax(최대 안전 원주속도) 문항 — 2026-08-21 신규 추가 · 2026-08-24 3문항 증보 ★최우선

> **왜 필요한가**: 홍익다이아 카탈로그(15p) 전문을 전수 검색한 결과 **속도 관련 기재가 0건**임이 재확정됐습니다(2026-08-21). 이화다이아 카탈로그(108p, OCR 판독)에도 **권장 작업속도만 있고 Vmax는 없습니다**. 즉 **Vmax는 카탈로그로는 확보 불가**이며, 이 값이 없으면 [[index]]의 원주속도 상한(25 m/s)이 근거를 갖지 못하고 [[스택-1-1]]·[[스택-1-2]]의 4,000 rpm 판정 모순도 종결되지 않습니다.
>
> **법적 근거**: **ISO 12413:2019 §6.6** — 결합 연삭재 제품은 **휠 측면에 Vmax를 표시할 의무**가 있습니다. 즉 제조사가 반드시 보유하고 있는 값입니다.

- [ ] **⭐ Vmax (최대 안전 원주속도, m/s)를 휠 사양별로 서면 명기 요청** — ISO 12413:2019 §6.6 표시 의무 대상임을 명시하여 요청
- [x] Vmax가 **휠 측면 라벨에 표시되어 출하되는지** 확인 (표시 형식·위치)
  - 🔴 **2026-08-24 사내 실물 확인 결과 — 보유 휠 5종 전부 라벨 자체가 부착돼 있지 않음**(Vmax뿐 아니라 형번·그릿·본드 등 어떤 표기도 없음). [신뢰도: 실측 검증 — 현물 육안 확인]
  - → 문항을 "확인"에서 **"라벨 미부착 사유 및 향후 표시 계획 확인"** 으로 전환 (아래 증보 문항 참조)
- [ ] Vmax 산출 근거 — **EN 13236 회전강도 시험성적서(Rotational strength test certificate) 제공 가능 여부**
- [ ] **권장 작업 원주속도(Vc)** 범위를 **습식·건식 각각 별도**로 요청
  - 대조용 참고값 — 이화다이아 다이아몬드 레진 본드: 습식 1,400~1,600 m/min(23.3~26.7 m/s) / 건식 900~1,200 m/min(15.0~20.0 m/s) [VEN-EHWA-GRINDING-2022]
  - ⚠️ 이 값을 **먼저 제시하지 말 것** — 제조사 자체 값을 받은 뒤 대조해야 편향이 없음
- [ ] **초경(WC-Co) 절삭공구 연삭에 한정한 권장 Vc**를 별도로 요청 — 일반 연삭(평면·원통) 기준과 다른지 확인 (이화 자료에서 일반 표 23.3~26.7 m/s vs ANCA FX7 실적용 18 m/s로 **불일치** 확인됨)
- [ ] 사내 현행 운용값의 적정성 판정 요청 — **Ø125 @ 2,800 rpm(18.33 m/s)** / **Ø100 @ 3,600 rpm(18.85 m/s)** / **Ø125 @ 4,000 rpm(26.18 m/s)** 3개 조건을 그대로 제시하고 각각 가/부 판정
- [ ] 휠팩 총중량 제한 대응 — ANCA 장비 사양은 **휠팩 총중량 8 kg 이하**([VEN-ANCA-RX7GX7-MANUAL]). 발주 휠의 개당 중량 명기 요청
- [ ] 락너트 조임토크 권장값 — 장비 사양은 최소 **20 N·m** ([VEN-ANCA-RX7GX7-MANUAL])

당사는 현재 **CNC 공구연삭 설비(ANCA)의 휠 안전 운전기준을 사내 문서로 정비**하고 있습니다. 그 과정에서 귀사 납품 휠의 **최대 안전 원주속도(Vmax)** 를 확인하려 했으나, 아래 두 경로 모두에서 확인이 되지 않아 서면 회신을 요청드립니다.

- 귀사 카탈로그(영문판) 전 페이지 검토 — 속도 관련 기재 없음
- 보유 휠 실물 확인 — **제조사 라벨이 부착되어 있지 않음**

**ISO 12413:2019 §6.6**(결합 연삭재 제품 안전 요구사항)은 제품에 최고 사용 원주속도 표시를 요구하고 있어, 귀사에서는 해당 값을 보유하고 계실 것으로 이해하고 있습니다.

**■ 회신 요청 항목**

1. **최대 안전 원주속도(Vmax, m/s)** — 아래 휠 사양별로 서면 명기
2. **Vmax 산출 근거** — EN 13236 회전강도 시험성적서(Rotational strength test certificate) 제공 가능 여부
3. **권장 작업 원주속도(Vc)** — **습식·건식 각각 별도로** 기재 부탁드립니다
4. **초경(WC-Co) 절삭공구 연삭에 한정한 권장 Vc** — 일반 평면·원통 연삭 기준과 다른지 여부
5. **당사 현행 운용값 적정성 판정** — 아래 3개 조건에 대해 각각 가/부 판정
   - Ø125 @ 2,800 rpm (= 18.3 m/s)
   - Ø100 @ 3,600 rpm (= 18.8 m/s)
   - Ø125 @ 4,000 rpm (= 26.2 m/s)
6. **라벨 관련** — ①현재 납품 휠에 라벨이 없는 사유 ②향후 납품분에 형번·그릿·본드·농도·**Vmax**·로트를 표기해 주실 수 있는지 (쿨런트 노출 환경이므로 각인 또는 내유성 라벨 형태 희망)
7. **부가 사양** — ①연삭재 종류(다이아몬드/CBN) 서면 확인 ②휠 **개당 중량**(당사 장비 휠팩 총중량 제한 8 kg) ③락너트 **조임토크 권장값**
