## 2. 휠 스택 설정

실제 사용 휠을 [[tools/wheels/index|휠 카탈로그]]에서 선택해 링크로 기록합니다.

| 항목 | 값 | 비고 |
|------|---|------|
| 사용 휠 | `휠-XXX` | 예: [[휠-45도-Ø125-1-2]] |
| 형상 | | 사다리꼴 / 삼각 쐐기 / C형 컵 |
| 휠 직경 (mm) | Ø___ | 휠 페이지에서 확인 |
| Grit | #___ | 휠 페이지에서 확인 |
| RPM | | 본 기록의 실제 설정값 |
| 원주속도 (m/s) | | π × D × RPM ÷ 60,000 |

> ⚠️ 원주속도 기준 ([[anca-cnc-tool-grinder]] 공통):
> - 마찰 구간 < 20 m/s → 버닝·로딩·표면 불량
> - 전환 구간 20~25 m/s → Feed 제한, 버닝 주의
> - 권장 구간 25~30 m/s → 정상 연삭
> - 고속 주의 > 30 m/s → 열 증가 모니터링

## 5. 불량 증상 체크리스트

### 버닝 (Burning)
- [ ] 가공면 변색 (갈색/청색)
- [ ] 원주속도 20 m/s 미만 확인
- [ ] 드레싱 주기 초과 여부 확인
- [ ] Coolant 공급 불량 여부 확인

### 드래그 마크 (Drag Mark)
- [ ] 원주속도 부족으로 인한 마찰 확인
- [ ] Feed 역전 구조 여부 확인
- [ ] 휠 로딩 여부 확인

### 휠 로딩 (Loading)
- [ ] 스핀들 부하 낮음에도 표면 불량
- [ ] 드레싱 후 즉시 개선 여부 확인
- [ ] Grit 변경 검토 필요

### 치수 불량
- [ ] DOC 설정값 재확인
- [ ] 휠 마모량 보정 여부 확인

## 진단 요약 원칙

1. **원주속도 < 20 m/s** → Feed 조정 전에 RPM/휠 직경 먼저 검토
2. **Feed 구조 확인**: 중간 구간이 항상 최고값이어야 함
3. **저부하 + 버닝 = 로딩** → 드레싱 또는 Grit 교체 우선
