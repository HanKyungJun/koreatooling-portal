# 측정 장비 사용법 (투영기 · 현미경 · 툴프리셋터)

> 신뢰도: 사내 경험값. 출처: [INT-TOOLKOREA-PRODMANUAL-2026] §1 연마 외 작업 (p88~95)
> 재연마 형상 판정 기준은 [[tools/재연마-형상-치수기준]] 참고.

---

## 1. 투영기 (Optical Comparator, 수평식 광학 투영기)

### 1.1 측정 방법

1. V블록 위에 측정할 엔드밀을 올려놓는다.
2. Z축 핸들을 돌려 엔드밀 초점을 맞춘다.
3. 측정하려는 R값에 맞춰 Round된 부분의 상하점·좌우점을 R차트에 맞춘다.
4. 엔드밀을 돌려가며 R값을 측정한다.

> 렌즈 비율을 바꿔 다양한 크기의 엔드밀을 측정할 수 있다.

### 1.2 렌즈 교환

1. Y축 핸들을 돌려 측정베드와 렌즈가 닿지 않게 내린다.
2. 렌즈 끝부분을 잡고 **반시계 방향**으로 돌려 뺀다.
3. 새 렌즈를 끼우고 **시계 방향**으로 돌린다. (렌즈 나사 손상 주의)
4. 작업 중 렌즈에 이물질이 묻지 않도록 주의 — 이물질 발생 시 전용 클리너로 제거.

## 2. 현미경

### 2.1 외관·구성

| 부품 | 기능 |
|------|------|
| 접안렌즈 | 눈으로 들여다보는 렌즈. **길이가 짧을수록 고배율** |
| 대물렌즈 | 엔드밀 표본을 향하는 렌즈. **길이가 길수록 고배율** |
| 미동나사 | 관찰 대상 엔드밀의 초점을 맞춤 |
| 조리개 | 빛의 양을 조절하여 상(像) 조절 |
| 재물대 | 측정 대상을 올려놓는 대 |

> **현미경의 배율 = 접안렌즈 비율 × 대물렌즈 비율**

### 2.2 사용법

1. 측정할 엔드밀을 재물대에 올려놓는다.
2. 조동나사로 초점을 맞추고 조리개로 상을 조절한다.
3. 미동나사로 정밀하게 초점을 맞추고 접안렌즈 초점을 맞춰 측정한다.
4. **ISCapture 프로그램**으로 엔드밀 모습을 저장할 수 있다.

## 3. 툴프리셋터 (Tool Presetter, E356B)

### 3.1 개요

- **모델**: 테이블탑 프리세터 **E356B**
- **용도**: 공구 셋팅 및 측정을 용이하게 하는 장치
- **호환 스핀들**: ISO, BT, CAT, HSK 등
- **렌즈**: Bi-telecentric 렌즈 — 물체 공간·이미지 공간 모두에서 광축에 평행한 광선 경로 유지
- **구성**: 툴 홀더, X/Y축 이동(정밀 포함), 터치 패널 화면, 홀더 잠금장치, 바코드 프린터, 전원 스위치, 카메라

### 3.2 사용법

1. 측면 스위치로 전원을 켜고 대기
2. 화면의 빨간색 이동 요청 표시 확인
3. 손잡이 색상 확인 — **검정=잠김 / 흰색=풀림**
4. 손잡이를 흰색 점이 사용자 방향으로 오도록 돌린 후, 흰색 점 기준으로 상·하 이동
5. 동일하게 좌·우 이동
6. 상하좌우 정렬 완료 후 공구 위치를 화면 중심으로 대략 이동
7. 홀더를 돌려 옆날의 가장 높은 점을 찾고 잠금 장치로 고정
8. 화면을 보면서 미세 조정하며 위치 확인, 화면 내 X축·Z축 값 확인
