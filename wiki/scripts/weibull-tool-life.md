# weibull_tool_life.py — 공구 수명 Weibull 분석 스크립트

> 신뢰도: 사내 경험값 (예시 데이터로 검증 완료 2026-06-08)
> 위치: `scripts/weibull_tool_life.py`

## 1. 개요

재연마 횟수 또는 가공 수량 데이터로 **Weibull 2-파라미터 분포**를 추정합니다.
공구의 고장 모드를 진단하고, B10/B50/B90 수명 예측값을 산출합니다.

**주요 기능:**
- MLE (Maximum Likelihood Estimation) — 검열 데이터(아직 사용 중인 공구) 포함 처리
- B10/B50/B90/MTTF 수명 계산
- 95% 신뢰구간 (Fisher 정보행렬 기반)
- Weibull 확률지 PNG 출력
- Excel 결과 파일 출력 (선택)

## 2. Weibull 2-파라미터 모델

$$F(t) = 1 - \exp\!\left[-\left(\frac{t}{\eta}\right)^\beta\right]$$

| 파라미터 | 의미 | 공구 전형값 |
|---------|------|-----------|
| β (형상 Shape) | 고장 모드 지표 | 1.5 ~ 5 (마모고장 영역) |
| η (척도 Scale) | 특성 수명 (63.2% 고장 시점) | 데이터 의존 |

### β 값 해석

| β 범위 | 고장 모드 | 조치 |
|--------|---------|------|
| < 0.75 | 초기고장 (Infant Mortality) | 입고검사·조립 공정 점검 |
| 0.75 ~ 1.25 | 우발고장 (Random) | 외부 충격·조건 변동 의심 |
| 1.25 ~ 3.0 | 초기 마모고장 | 정상 공구 마모 — 교체주기 설정 |
| 3.0 ~ 5.0 | 마모고장 | 명확한 수명 한계 — B10 기준 교체 |
| > 5.0 | 급속 마모고장 | 가공 조건 재검토 권장 |

### B-life 수명 공식

$$B_p = \eta \cdot \left[-\ln(1-p)\right]^{1/\beta}$$

중간 과정 예시 (β=3.0, η=100):
- B10: t = 100 × [-ln(0.9)]^(1/3) = 100 × 0.1054^0.333 = **47.2**
- B50: t = 100 × [-ln(0.5)]^(1/3) = 100 × 0.6931^0.333 = **88.5**
- MTTF: t = η × Γ(1 + 1/β) = 100 × Γ(1.333) = **89.7**

## 4. 데이터 최소 요건

⚠️ **완전 고장 데이터(censored=0) 최소 6개 이상 권장.**

| 완전 고장 수 | 신뢰도 | 사용 기준 |
|-----------|-------|---------|
| < 6 | 매우 낮음 | 추정값으로만 사용 (신뢰구간 매우 넓음) |
| 6 ~ 15 | 보통 | 방향성 파악 용도 — 사내 경험값 |
| > 15 | 양호 | 교체주기 설정 가능 — 실측 검증 |

### 검열 데이터(Censored Data) 처리

현재 사용 중인 공구는 `censored=1`로 기록합니다.
"이 공구는 최소 N회 이상 견뎠다"는 정보를 MLE에 반영 — 데이터를 버리지 않고 활용합니다.

수식: $\ln L = \sum_{fail} \ln f(t_i) + \sum_{cens} \ln R(t_j)$

where $R(t) = \exp[-(t/\eta)^\beta]$ (생존 확률)

### Weibull 확률지 읽기

- **점이 직선에 가까울수록** Weibull 분포 적합도 높음

## 6. 주의사항

⚠️ **샘플 수 부족 시 주의:** β와 η의 95% CI가 매우 넓습니다. 데이터 < 6개이면 신뢰구간이 파라미터의 ±50% 이상이 될 수 있습니다.

⚠️ **혼합 데이터 금지:** 공구 형상·직경·피삭재가 다른 데이터를 섞으면 β 해석이 불가능합니다. 동일 조건끼리만 묶어서 분석합니다.

⚠️ **양산 적용 제한:** 이 스크립트의 출력값만으로 교체주기를 확정하지 않습니다. 실측 검증 후 현장 책임자 승인 필수.

## 7. 알고리즘 상세

### 파라미터 추정 (MLE)

로그 변환 파라미터 `[log β, log η]`로 최적화하여 양수 제약을 자동 처리합니다.

```
최소화 대상: -ln L = -[Σ ln f(t_i; β, η) + Σ ln R(t_j; β, η)]
최적화 방법: Nelder-Mead (scipy.optimize.minimize)
초기값: MoM (Method of Moments) — β₀=π/(√6 × σ_lnT), η₀=exp(μ_lnT)
```

### 신뢰구간 계산

수치 헤시안(중앙차분) → Fisher 정보행렬 역행렬 → 델타법으로 log 스케일 CI → 역변환.

### Median Rank (확률지용)

Bernard's approximation: $F_k = \dfrac{k - 0.3}{n + 0.4}$ (k번째 고장, n=총 완전고장 수)
