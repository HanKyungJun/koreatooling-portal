# 공구 사양 실험 이력 — R&D 변종 분석

> 사내 ANCA ToolRoom 데이터에서 발견된 **14개 변종 시리즈**는 사내 사양 실험으로 반복 작성된 **R&D 학습 자산**입니다 (decisions.md 2026-05-14 #3). 본 페이지는 그 패턴을 학술 프레임으로 정리·해설.
>
> 원본 데이터: `wiki/reports/anca-공구휠팩-마스터.xlsx` 시트 9 (Op시퀀스, 1202행) + 시트 10 (변종비교, 14 그룹).
>
> 데이터 한정성: `raw/tool/` 는 사내 ToolRoom의 **과거 스냅샷**, 최신 운영 데이터는 별도 위치 (decisions.md 2026-05-14 #3).
>
> ★★★ = 학술 논문 직접 근거 | ★★☆ = 패턴 추론 + 한경준님 답변 정합 | ★☆☆ = 사내 추론

## 1. 변종 시리즈의 의미 ★★★

### 1.1 변종이란

ANCA ToolRoom에서 같은 직경·형상의 공구를 **여러 번 반복 작성**한 결과물. 파일명 패턴 예:
- `2NC060_90`, `2NC060_120`, `2NC060_2`, `2NC060_3`, `2NC060_90_0703_JJ`, `2NC060_90_JJ` ...
- `2F060BA.tom`, `2F060Co.tom`, `2F060FL.tom` (Ball / Corner / Flat)
- `4F060_*.tom` 시리즈 3개

### 1.2 변종의 성격 — 한경준님 명시 (2026-05-14)

> "사내 사양 실험으로 반복적으로 만든 파일. 고객 주문 변종 아님."

→ 변종 = **사내 학습 자산**. 같은 공구 사양을 다양한 Op 구성으로 작성해서 결과 비교·축적한 R&D 표본.

### 1.3 학술 프레임 — Design of Experiments

Box, Hunter & Hunter (2005) *Statistics for Experimenters* Ch.5 — DoE(실험계획법) 관점에서:
- 동일 직경·형상에서 **Op 개수·종류만 변경하는 일련의 변종** = 단일 변수 통제 실험 시리즈
- 결과(공구 수명·표면조도·진동)를 비교하면 어떤 Op 조합이 최적인지 도출 가능

## 3. 패턴 1 — 표준화 (Standardization) ★★☆

### 3.1 2NC060 시리즈 분석

11개 변종에서 시간 순서대로 Op 개수가 감소:
- 초기: 8 Op (모든 가공 단계 명시)
- 중기: 6~7 Op (일부 통합)
- **2025-02-05 (250205, 최신)**: **4 Op (단순화 완료)**

### 3.2 학술 근거

**Sahay & Chinchanikar (2022)** *Materials Today: Proceedings* 62(3), "Tool design optimization in cutting tool manufacturing":
- R&D 단순화 사이클의 표준 패턴 — 초기 다단계 실험 → 결과 비교 → 핵심 단계만 남기는 표준화
- 사내 2NC060 시리즈는 이 학술 모델과 정확히 정합

### 3.3 사내 적용 의미

- 변종 = R&D 결과물 → **표준화된 최신 사양**(250205, 4 Op)이 사내 정답안에 가까울 가능성
- 신규 동급 공구 설계 시 이 4 Op 구성을 1차 참조

> ⚠️ 단, "표준화 완료" 여부는 한경준님 확인 필요 (`tasks.md` 미완 항목 — 챗으로 가져갈 질문).

## 4. 패턴 2 — 모듈러 형상 분기 (Modular Architecture) ★★☆

### 4.1 2F060 시리즈 (Ball / Corner / Flat)

세 변종 모두 **백본 Op 8개 동일**, 마지막 1~2 Op만 형상에 따라 분기:

```
공통 백본 (8 Op):   동일
  ↓
형상별 분기:
  2F060BA (Ball)    → 마지막 Op: f_ed (볼 마무리)
  2F060Co (Corner)  → 마지막 Op: f_odcre (코너R 형성)
  2F060FL (Flat)    → 마지막 Op: f_ed (평 마무리)
```

### 4.2 4F060 시리즈

7 Op 백본 동일, 마지막 Op만 차이 (`f_ed` vs `f_odcre`).

### 4.3 학술 근거

**Ulrich & Eppinger (2016)** *Product Design and Development* Ch.9 "Product Architecture":
- **모듈러 아키텍처** — 공통 백본 + 변경 가능한 모듈
- 장점: 설계 재사용, 검증 단순화, 변종 관리 효율 ↑

→ 사내 2F060·4F060 변종은 **모듈러 설계 원칙의 사내 적용 사례**.

### 4.4 사내 적용 의미

- 동일 직경의 새 형상 공구 설계 시 **백본 Op 재사용** → 검증 부담 ↓
- 형상별 차이는 마지막 Op만 신중히 설계
- ToolRoom 라이브러리 관리에 직접 적용 가능

## 8. 학술 근거 — 5축 공구 연삭 Op 시퀀스 ★★★

**Inasaki (1996)** *CIRP Annals* 45(2), "Surface grinding":
- 연삭 Op 순서가 잔류응력·표면조도에 직접 영향
- Digitizing(측정) → Roughing(거친 가공) → Finishing(정삭) 표준 시퀀스 학술적 정립

**Brinksmeier et al. (2010)** *CIRP Annals* 59(2), "Advances in modeling and simulation of grinding processes":
- 연삭 시뮬레이션의 발전 — 사내 ToolRoom Op 시퀀스 분석에 학술적 정합 프레임
