  - 산출물 형태: 기획서(문서) + 실제 프로토타입 병행

### 2026-09-18 제작분

1. **`estimate.html`** — 견적 문의 폼 신규 제작. 기존 `request.html`과 동일한 UX 패턴(규격/수량 다중행, 파일첨부, GAS 제출)을 재사용.
2. **`about.html`** — 회사소개·서비스 카탈로그 홍보 페이지 신규 제작. 실제 주소·전화번호·연혁 등은 `[문구 확인 필요]`로 표시해둠 — 임의로 지어내지 않음.
3. **`generate.py`** `build_portal_html()` — 메인 포털에 "견적 문의"·"회사 소개" 카드 2개 신규 추가.
4. **`dist/portal.js`** — 퀵네비 목록에 두 페이지 추가.
5. **`netlify_to_sheets.gs`**(로컬 사본) — `estimate-form` 처리 로직 추가(sheetMap·이메일 본문·시트 행 구성·파일첨부). **Apps Script 콘솔 반영은 한경준님 몫**(기존 GAS 재배포 관행과 동일).

### 남은 작업 (한경준님)

- [ ] Google Sheet(`SHEET_ID` 동일 스프레드시트)에 **"견적문의" 탭 신규 생성**, 헤더 행: `시간 | 회사명 | 담당자 | 연락처 | 이메일 | 구분 | 재질 | 규격 | 수량 | 희망납기 | 월예상수량 | 참고사항 | 첨부파일`
- [ ] Apps Script 콘솔에서 `netlify_to_sheets.gs`(갱신본, 저장소에 반영됨) 내용을 기존 배포에 반영 — **"새 배포" 없이 기존 배포에 "새 버전"으로 편집**하면 URL 유지되어 `portal.js`의 `GAS_FORM_URL` 수정 불필요 (배포 관리 → 편집 → 새 버전)
- [ ] `about.html` 회사 정보 채우기 — **2026-09-21 Cowork가 「회사 정보」 섹션 골격을 추가**했다. `dist/about.html`에서 노란 배경 `[대괄호]` **7칸**(주소·전화·팩스·이메일·영업시간·사업자등록번호·설립연혁)만 실제 값으로 바꾸면 된다. 필요 없는 줄은 `<tr>…</tr>` 통째로 삭제. ⚠️ **`dist/` 쪽만 고칠 것** — 루트 `about.html`은 `generate.py`가 자동 복사한다
  - 저장소 어디에도 실제 연락처·주소가 없어 Cowork가 채울 수 없었다(2026-09-21 전수 grep 확인). 값은 한경준님만 알 수 있다
