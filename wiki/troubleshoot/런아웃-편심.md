# 런아웃 · 코어 편심 진단 가이드

> **신뢰도**: 제조사 기준 [VEN-ANCA-ENDMILL-GUIDE] + 사내 경험값 병기.
> 측정 장비 미보유 항목은 `추정값`으로 표기.

---

## 1. 개념 정의

### 1-1. 용어 구분

| 용어 | 정의 | 단위 |
|------|------|------|
| **TIR** (Total Indicated Runout) | 공구 회전 시 외경의 최대·최소 측정값 차이 | μm, mm |
| **런아웃 (Runout)** | TIR와 동일 개념. 공구가 회전하면서 발생하는 반경 방향 흔들림 | μm |
| **편심 (Eccentricity)** | 공구 중심축과 실제 회전 중심의 오프셋. 편심 = TIR ÷ 2 (순수 편심인 경우) | μm |
| **코어 편심** | 연삭 후 플루팅 공구의 코어 직경 중심이 생크 회전축에서 벗어난 정도 | μm |

### 1-2. 런아웃과 코어 편심의 차이

```
런아웃 (TIR) → 공구가 척에 물렸을 때 실제 회전 오차
코어 편심    → 연삭 공정에서 코어 가공 중심이 회전축과 어긋난 오차
```

- 런아웃은 **셋업·척·스핀들** 문제
- 코어 편심은 **연삭 프로그램·콜릿 정렬** 문제
- 코어 편심이 있으면 날마다 절삭 부하가 불균형해지고, 1개 날에 부하 집중 → 공구 수명 급감

### 1-3. 영향

| TIR | 영향 |
|-----|------|
| < 5 μm | ANCA Premierplus 콜릿 기준 정상 [VEN-ANCA-ENDMILL-GUIDE] |
| < 2 μm | 고정밀 요구 (의료·항공우주) |
| 15 μm → 2 μm 개선 시 | 공구 수명 **3배 증가** [VEN-ANCA-ENDMILL-GUIDE] |
| > 25 μm | 가공면 불량·공구 조기 파손 위험 |

## 2. 원인 분류

### 2-1. 척·콜릿 계통

| 원인 | 증상 | 확인 방법 |
|------|------|---------|
| 콜릿 내부 이물 (칩·오일) | 공구마다 TIR 불규칙 변동 | 콜릿 내부 청소 후 재측정 |
| 콜릿 마모·손상 | TIR 지속 증가 | 콜릿 교체 후 비교 |
| 테이퍼 면 이물 | 동일 공구도 삽입 위치마다 다른 TIR | 테이퍼 청소 후 재측정 |
| 콜릿 어댑터 편심 | TIR가 항상 같은 방향으로 치우침 | 교정 핀 사용 측정 |

> ANCA: "알루미늄 먼지 한 알이나 오일 한 방울이 공구를 중심에서 벗어나게 할 수 있다" [VEN-ANCA-ENDMILL-GUIDE]

### 2-2. 스핀들 계통

| 원인 | 증상 | 확인 방법 |
|------|------|---------|
| 스핀들 베어링 마모 | RPM 증가 시 TIR 증가 | 저속·고속 TIR 비교 |
| 스핀들 축 굽힘 | 모든 공구에서 일정한 TIR | 검교정 봉 측정 |
| 스핀들 예열 부족 | 가공 초반 TIR 불안정 | 예열 전·후 측정 비교 |

### 2-3. 연삭 프로그램 계통 (코어 편심)

| 원인 | 증상 | 확인 방법 |
|------|------|---------|
| 콜릿 기준점 미설정 | 배치마다 편심 방향 무작위 | ANCA 기준점 설정 확인 |
| 플루팅 연삭 중심 오프셋 | 날 간격 불균등 | LaserPlus 측정 (사내 미보유 — 외부 측정 의뢰 필요) |
| 휠 마모로 인한 코어 직경 변동 | 배치 후반부 공구 편심 증가 | Ruby Probe 미설정 시 발생 |

## 3. 허용 기준 (사내 적용)

| 용도 | 허용 TIR | 신뢰도 |
|------|---------|--------|
| ANCA Premierplus 콜릿 정상 | **< 5 μm** | 제조사 기준 [VEN-ANCA-ENDMILL-GUIDE] |
| 일반 재연마 출하 | **< 10 μm** | 사내 경험값 (추정) |
| 정밀 가공용 공구 | **< 5 μm** | 추정값 — 사내 측정 기준 미확립 |
| ISO 230-7 일반 권고 | **< 0.003 mm** (3 μm) | 제조사 기준 [STD-ISO230-7] |

> ⚠️ 사내 전자 다이얼 게이지 측정 한계: 최소 눈금 **10 μm (0.01 mm)** [사내 확인, 2026-06-15]. Premierplus 기준(< 5 μm) 및 ISO 230-7 권고(< 3 μm)는 이 게이지로 식별 불가. 10 μm 미만 정밀 측정에는 ANCA LaserPlus 또는 외부 측정기 필요.

## 4. 진단 의사결정 트리

```
공구 TIR 이상 발생
        │
        ▼
[1] 다른 공구로 교체 후 측정 → TIR 정상?
    YES → 공구 자체 문제 (구부러짐·코어 편심)
    NO  → 척·스핀들 계통 문제 → [2]로
        │
        ▼
[2] 콜릿·테이퍼 청소 후 측정 → 개선?
    YES → 이물질 문제 → 청소 주기 강화
    NO  → [3]으로
        │
        ▼
[3] 다른 콜릿으로 교체 후 측정 → 개선?
    YES → 콜릿 마모·손상 → 콜릿 교체
    NO  → 스핀들 베어링 의심 → [4]로
        │
        ▼
[4] 저속(500 rpm)과 고속(3,000 rpm) TIR 비교
    고속에서 TIR 급증 → 스핀들 베어링 마모 → 정비 의뢰
    차이 없음 → 스핀들 축 굽힘 의심 → 검교정 봉으로 확인
```

## 5. 측정 방법

### 5-1. 다이얼 게이지 (Dial Test Indicator)

1. 공구를 척에 장착
2. 다이얼 게이지 측정자를 플루팅 부 OD에 접촉
3. 스핀들을 손으로 천천히 360° 회전
4. 최대값 - 최소값 = TIR 기록
5. 날 끝에서 10 mm 후방 위치, 날 끝 각각 측정

### 5-2. ANCA LaserPlus (인 머신)

> ❌ **사내 미보유** (옵션 미탑재, 2026-06-15 확인). 아래는 참고 스펙.

- 비접촉 레이저로 자동 측정 및 보정
- 측정 정밀도: ±0.002 mm [VEN-ANCA-ENDMILL-GUIDE]
- iGrind Total Tool Runout 측정·보정 기능 활용

### 5-3. 사내 현황

| 장비 | 보유 여부 | 비고 |
|------|----------|------|
| 전자 다이얼 게이지 | ✅ 보유 | 최소 눈금 10 μm (0.01 mm) — 5 μm 미만 측정 불가 [사내 확인, 2026-06-15] |
| ANCA LaserPlus | ❌ 미보유 | 옵션 미탑재 확인 [사내 확인, 2026-06-15] |
| 외부 측정기 (Zoller 등) | ❌ 미보유 | — |

## 6. 조치 방법

| 상황 | 조치 |
|------|------|
| 콜릿 이물질 | 콜릿·테이퍼 청소 → 재측정 |
| 콜릿 마모 | 콜릿 교체 (정기 교체 주기 설정 권장) |
| 공구 코어 편심 (연삭 문제) | ANCA iGrind 기준점 설정 재확인, Ruby Probe 활성화 |
| 배치 후반부 편심 증가 | 휠 마모 보상 설정 확인 (Ruby Probe / 드레싱 주기) |
| 스핀들 이상 의심 | 정비 의뢰 전 CTV 설정 재확인 |
