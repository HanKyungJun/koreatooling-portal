# 측면가공 공구 파손 — ae 과다 (D12 코너R 재연마 엔드밀, S45C)

## 1. 증상 요약

| 항목 | 내용 |
|------|------|
| 증상 | 측면가공 중 **공구 파절(파손)** |
| 공구 | D12 코너R2.5 엔드밀, 4날, 비코팅, 초경 **(재연마품)** |
| 피삭재 | S45C 강판 (홀 가공 완료품) |
| 조건 | RPM 2,100 / Vf 700 mm/min / ae **0.4mm** / ap 10mm |
| 원인 추정 | ae=0.4mm 과다 → 초경 재연마 공구 절삭력 과부하 |
| 해결 | ae **0.4mm → 0.3mm** 감소 후 정상 가공 완료 |

**신뢰도:** 사내 경험값 (체계적 계측 미완)

## 2. 공통 조건

| 항목 | 값 |
|------|-----|
| 장비 | CHEVALIER QP2040L (MCT) |
| 공구 | D12 코너R2.5 엔드밀, 4날, 비코팅, 초경 (재연마품) · 품번: 4CO1201100 |
| 피삭재 | S45C 강판 (홀 가공 완료품) |
| RPM | 2,100 rpm |
| Vc | 79.2 m/min |
| Vf | 700 mm/min |
| fz | 0.083 mm/tooth |
| 쿨런트 | 수용성 (농도·압력 미확인) |
| 좌표계 | G54, G41 공구경 좌보정 / X 왕복 ±85mm |

### 절삭속도 계산 (검산용)

```
Vc = π × D × N / 1000
   = π × 12 × 2,100 / 1000 = 79.2 m/min  ✓

fz = Vf / (날수 × N)
   = 700 / (4 × 2,100) = 0.0833 mm/tooth  ✓
```

> **2026-07-09 재확인:** `0.보고서_테스트 (측면 가공).hwp` 원본을 `hwp5txt`로 재파싱했으나 표/그림 위주 문서라 텍스트 결과가 추출되지 않음 — 텍스트 기록은 여전히 "미기록". 다만 `5-3. S45C 2차 가공.jpg` 이미지를 직접 열람한 결과, 가공면에 파손·균열 없이 균일한 격자형 가공 패턴이 확인됩니다 — **공구 파손 없이 가공이 완료된 것으로 추정**(사진 관찰 기반, 정량 측정치 아님). 표면조도(Ra)·치수 편차는 육안으로 확인 불가하므로 여전히 "미기록"으로 유지하며, 추정값 수준으로만 "파손 없음" 정보를 추가합니다.

## 8. 원인 분석

| 요인 | 영향 | 비고 |
|------|------|------|
| **ae 과다** | 재연마 공구에 절삭력 과부하 | ae=0.4mm → 0.3mm 감소 시 해결 |
| **재연마 공구 강성** | 신품 대비 인선부 강성 저하 가능성 | 비코팅, 재연마 횟수 미기록 |
| **비코팅** | S45C 가공 시 마찰·열 증가 | TiAlN 또는 AlTiN 코팅 재연마 검토 |
| **쿨런트** | 농도·압력 미확인 — 냉각 부족 가능성 | 농도 기록 후 재평가 필요 |

> **핵심 결론:** S45C + D12 재연마 비코팅 공구 조합에서 **ae ≤ 0.3mm** 적용.  
> ae=0.4mm는 파손 임계값 이상 — 재연마 공구에서는 더 보수적 적입 필요.
