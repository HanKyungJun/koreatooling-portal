# 채터(Chatter) — 진단·조치 가이드

> 채터는 **규칙적 진동 무늬** 또는 **고주파 비명음**으로 나타나는 자력 진동 현상입니다.
> - 채터 마크 외관은 [[표면조도-불량]] §2.3 참조
> - 연삭 메커니즘 학술 근거는 [[연삭-이론-근거]] 참조
>
> ★★★ = 학술 논문·국제 표준 직접 근거 | ★★☆ = 간접 지지 + 산업 통례 | ★☆☆ = 현장 추론

---

## 1. 채터 유형 분류 ★★★

채터는 **발생 메커니즘**에 따라 3가지로 분류합니다.

| 유형 | 원인 | 특징 | 대응 방향 |
|---|---|---|---|
| **재생형 (Regenerative)** | 이전 가공면의 진동 무늬가 다음 패스에서 증폭 | 가장 흔함. 무늬 간격이 회전 속도에 비례 | RPM 변경, 아웃피드 감소 |
| **강제 진동형 (Forced)** | 외부 가진 — 휠 불균형, 스핀들 불량, 장비 진동 | 특정 RPM에서 집중 발생. 회전수 변경 시 즉시 변화 | 휠 밸런스, 스핀들 점검 |
| **마찰형 (Frictional)** | 휠-공구 마찰계수 변동 → 부하 진동 | 드레싱 직후 일시적으로 개선 | 그릿 변경, 드레싱 조건 |

> 출처: Inasaki, I., Karpuschewski, B., & Lee, H.S. (2001). Grinding chatter — Origin and suppression. *CIRP Annals*, 50(2), 515-534. [ACA-INASAKI2001]

---

## 2. 발생 조건 및 메커니즘 ★★★

### 2.1 공진 조건

채터가 가장 심한 경우는 **가진 주파수 ≈ 시스템 고유진동수**일 때입니다.

```
가진 주파수 (Hz) = RPM / 60 × 날수 (또는 입자 접촉 빈도)
고유진동수 (fn) = (1 / 2π) × √(k / m)  [k: 강성 N/m, m: 유효 질량 kg]
```

> ⚠️ 공진이 발생하면 절삭력이 급격히 증폭되어 공구 파손·휠 손상으로 이어질 수 있습니다.

### 2.2 재생형 채터 증폭 조건

- 이전 패스의 무늬 깊이 > 현재 패스의 절삭 깊이
- 위상 지연(Phase lag)이 90°~270° 구간에서 에너지 입력 > 감쇠
- **아웃피드(Ae) 크면** 재생 루프 이득 증가 → 발산

### 2.3 강제 진동형 채터

| 원인 | 진단 방법 |
|---|---|
| 휠 정적 불균형 | 무소음 환경에서 손으로 휠 돌림 → 특정 위치에서 멈춤 |
| 스핀들 베어링 마모 | 진동계로 베어링 주파수 확인 (BPFO/BPFI) |
| 장비 공진 (floor, fixture) | 동일 조건에서 장비 위치 변경 시 개선 여부 |
| 공구 언밸런스 (긴 공구) | 공구 길이 L/D > 5 이상에서 빈발 |

## 3. 진단 의사결정 트리 ★★☆

```
채터 의심 (규칙적 무늬 또는 비명음)
   │
   ├─ 특정 RPM에서만 발생?
   │     ├─ Yes → 강제 진동형 가능성 ↑
   │     │         → 휠 밸런스 점검 (§4.1)
   │     │         → RPM 5~10% 변경 테스트 (§4.2)
   │     └─ No → 재생형 또는 마찰형 가능성 ↑
   │              → 아웃피드(Ae) 감소 (§4.3)
   │
   ├─ 드레싱 직후 즉시 개선?
   │     ├─ Yes → 마찰형 (글레이징 동반 점검)
   │     │         → 그릿 변경 또는 드레싱 조건 재설정
   │     └─ No → 기계적 원인 (밸런스·강성)
   │
   ├─ 공구 길이 L/D > 5?
   │     ├─ Yes → 공구 언밸런스 → 클램핑 점검 / 돌출량 최소화
   │     └─ No → 클램핑 점검 후 스핀들 점검
   │
   └─ 장비 이력 (베어링 교체 후 6개월 이상)?
         ├─ Yes → 스핀들 점검 권장
         └─ No → 단기 조치 먼저 (RPM 변경, 밸런스)
```

## 4. 조치 방법 ★★☆

### 4.1 휠 밸런스 점검 및 보정

**정적 밸런스 점검 (현장 즉시)**:
1. 스핀들에서 휠 탈거
2. 평탄한 축에 올려 자유 회전 — 항상 같은 위치에서 멈추면 불균형
3. 반대쪽 밸런싱 웨이트 추가 또는 위치 조정

**ANCA iBalance (동적 밸런스)**:
- 가공 중 진동 데이터로 자동 보정
- 권장: 드레싱 직후 밸런스 재확인
- ⚠️ 정적 밸런스가 크게 벗어난 상태에서 iBalance는 효과 제한적 — 정적 먼저 수행

> 신뢰도: 사내 경험값 (ANCA 매뉴얼 iBalance 섹션 기준)

### 4.2 RPM 변경 (공진 회피)

**원칙**: 현재 RPM에서 ±5~10% 변경 후 채터 변화 관찰

| 현재 상태 | 조치 |
|---|---|
| RPM 변경 시 채터 즉시 감소 | 강제 진동형 → 새 RPM 확정 |
| RPM 변경해도 동일 | 재생형 → 아웃피드·스프링패스 검토 |
| RPM 낮추면 감소 | 원심력/구심력 불균형 → 밸런스 재점검 |

> ⚠️ 고속 연삭 (Vc > 30 m/s): RPM 변경 전 휠의 최대 허용 RPM 반드시 확인. [제조사 기준]

### 4.3 절입·피드 조정

| 파라미터 | 채터 감소 방향 | 주의 |
|---|---|---|
| 아웃피드 (Ae) | **감소** — 재생형 루프 이득 감소 | 가공 시간 증가 |
| 인피드 (Ap) | 감소 | 가공 횟수 증가 |
| Feed | 경우에 따라 증가 (마찰형 감소) | 표면조도 확인 |
| 스프링 패스 | 추가 (1~2회 무절입 패스) | 시간 증가 |

> 신뢰도: 사내 경험값 + [ACA-MALKING2008] Ch.7

### 4.4 클램핑 점검

| 점검 부위 | 방법 | 기준 |
|---|---|---|
| 콜릿 토크 | 토크 렌치로 재토크 | 콜릿 규격 토크표 기준 |
| 공구 돌출 길이 | L/D 비율 확인 | 일반적으로 L/D < 4 권장 |
| 콜릿 마모·변형 | 육안 + 런아웃 측정 | 런아웃 > 0.01 mm 시 교체 |
| 스핀들 하우징 | 너트·볼트 재토크 | — |

### 4.5 장비·스핀들 점검 (장기 대응)

| 항목 | 점검 주기 | 기준 |
|---|---|---|
| 스핀들 베어링 | 6개월 또는 이상음 발생 시 | 진동계 BPFO/BPFI 이상음 확인 |
| 장비 수평도 | 연 1회 | 수평계 0.05 mm/m 이내 |
| 가이드웨이 마모 | 이상 진동 발생 시 | 제조사 기준 |
| 쿨런트 탱크 진동 | 탱크 고정 볼트 확인 | — |

## 6. 예방 체크리스트

드레싱·교체·장기 미사용 후 재가동 시:

- [ ] 휠 밸런스 확인 (정적)
- [ ] 콜릿 토크 재확인
- [ ] 공구 돌출 길이 L/D 확인
- [ ] 저속(50~70% RPM)에서 공회전 후 이상음 점검
- [ ] 첫 가공 — 아웃피드 30% 감소 후 점진 증가
