# 치수불량 — 진단·조치 가이드

> 이 페이지는 **가공 후 치수·형상 오차**를 다룹니다.
> - 표면조도 불량은 [[표면조도-불량]] 참조
> - 채터 마크는 [[채터-chatter]] 참조
>
> ★★★ = 학술 논문·국제 표준 직접 근거 | ★★☆ = 간접 지지 + 산업 통례 | ★☆☆ = 현장 추론

## 1. 치수불량 유형 분류 ★★★

| 유형 | 설명 | 측정 방법 |
|---|---|---|
| **외경(OD) 오차** | 목표 직경 대비 실제 직경 편차 | 마이크로미터, CMM |
| **런아웃 (Runout)** | 공구 회전 중심 대비 TIR (Total Indicator Runout) | 다이얼 게이지, 런아웃 측정기 |
| **코어 편심** | 코어 직경의 중심이 OD 중심과 불일치 | CMM 단면 측정 |
| **테이퍼 (Taper)** | 길이 방향 직경 변화 (선두-후단 차이) | 마이크로미터 × 2점 |
| **진원도 (Roundness)** | 단면의 원형 편차 | CMM, 라운드니스 테스터 |
| **진직도 (Straightness)** | 길이 방향 축 직선 편차 | 다이얼 게이지 스캔 |

> 공차 기준: ISO 2768 일반 공차 / 도면 지정 공차가 우선 [STD-ISO2768]

## 2. 원인별 메커니즘 ★★★

### 2.1 열변형 (Thermal Drift)

**메커니즘**: 연삭열 → 공구·척·스핀들 열팽창 → 치수 변화. 스핀들 1°C 상승 시 수 μm 이상 이동 가능.

```
열팽창 ΔL = α × L × ΔT
   α = 선팽창계수 (초경 WC-Co: 5~6 × 10⁻⁶ /°C)
   L = 공구 길이 (mm)
   ΔT = 온도 변화 (°C)
   예: L=100mm, ΔT=5°C → ΔL ≈ 2.5~3 μm
```

> 출처: Malkin, S. & Guo, C. (2008). *Grinding Technology*. Industrial Press. Ch.8 [ACA-MALKING2008]

**진단 신호**: 가공 초반(예열 전)과 후반 치수 차이 > 5 μm

**조치**:
1. 스핀들 예열 (최소 10~15분 공회전) — 사내 경험값
2. 첫 가공 후 치수 측정 → 열 안정화 후 재가공
3. 쿨런트 온도 일정 유지 (변동 ±2°C 이내 권장)

### 2.2 클램핑·런아웃 오차 ★★☆

**원인**:
- 콜릿 오염 (칩, 이물질)
- 콜릿 마모·변형
- 공구 삽입 불완전
- 스핀들 런아웃 누적

**측정 기준** (사내 경험값):
| 런아웃 수준 | 판정 |
|---|---|
| < 0.005 mm TIR | 양호 |
| 0.005~0.015 mm | 주의 — 정삭·코팅 공구에서 문제 가능 |
| > 0.015 mm | 불량 — 클램핑 점검 필수 |

**조치 순서**:
1. 콜릿 청소 (에어건 + 린트프리 천)
2. 공구 재삽입 (끝까지 밀어 넣기)
3. 콜릿 너트 재토크
4. 측정 재실행 → 미개선 시 콜릿 교체

### 2.3 휠 마모에 의한 치수 드리프트 ★★☆

**메커니즘**: 드레싱 없이 장시간 가공 → 휠 반경 감소 → 실제 절입 감소 → 공구 OD 점점 커짐 (또는 형상 변화).

**진단 신호**: 배치(Batch) 내에서 공구 OD가 순차적으로 증가하는 트렌드

**조치**:
- 드레싱 주기 단축 (공구 수 또는 시간 기준)
- 보정값(Offset) 주기적 업데이트

### 2.4 소재·공구 탄성변형 ★★★

**메커니즘**: 연삭력 → 공구 굽힘(deflection) → 실제 절입 < 설정 절입 → 언더사이즈 경향

```
굽힘 처짐 δ = F × L³ / (3 × E × I)
   F = 연삭력 (N)
   L = 돌출 길이 (mm)
   E = 탄성계수 (초경: ~620 GPa)
   I = 단면 2차 모멘트 (= π × D⁴ / 64)
```

**진단 신호**: L/D > 4인 공구에서 오버사이즈(회복 불량) 또는 언더사이즈

**조치**:
- 돌출 길이 최소화
- Feed 감소
- 스프링 패스 추가 (무절입 마무리 패스)

### 2.5 세팅·좌표 오류 ★☆☆

**원인**: 공구 좌표 기준점 오류, 기준면 설정 오류, 마모 보정 미반영

**진단**: 동일 조건 반복 시 동일한 방향·크기의 오차 발생

**조치**:
1. 기준점 재설정 (Reference)
2. ANCA ToolRoom 오프셋 확인
3. 첫 가공 후 측정 → 프로그램 보정값 수정

## 3. 진단 의사결정 트리 ★★☆

```
치수불량 발생 (OD/형상 목표 미달 또는 초과)
   │
   ├─ 오차 방향이 일정? (항상 작다 / 항상 크다)
   │     ├─ Yes, 항상 언더사이즈 → 굽힘 처짐 또는 세팅 오류
   │     │     → L/D 확인 (§2.4) / 오프셋 점검 (§2.5)
   │     ├─ Yes, 항상 오버사이즈 → 휠 마모 또는 열팽창
   │     │     → 드레싱 주기 확인 (§2.3) / 예열 상태 (§2.1)
   │     └─ No, 불규칙 → 클램핑·런아웃 문제 가능성 ↑
   │           → 런아웃 측정 (§2.2)
   │
   ├─ 배치 내에서 오차가 점진 증가?
   │     └─ Yes → 휠 마모 드리프트 (§2.3) → 드레싱 주기 단축
   │
   ├─ 가공 초반 vs 후반 오차 차이 큼?
   │     └─ Yes → 열변형 (§2.1) → 예열 시간 확인
   │
   ├─ 런아웃 > 0.015 mm?
   │     └─ Yes → 클램핑 문제 (§2.2) → 콜릿 청소·재토크·교체
   │
   └─ 형상 오차 (테이퍼·진원도 불량)?
         → ANCA 드레스 형상 확인, 가이드웨이 점검
```

## 4. 측정 방법 및 기준 ★★★

### 4.1 OD 측정

| 항목 | 장비 | 분해능 | 주의 |
|---|---|---|---|
| OD (Ø2~Ø10) | 외측 마이크로미터 | 0.001 mm | 측정력 일정하게 유지 |
| OD (Ø10~Ø20) | 외측 마이크로미터 | 0.001 mm | 앤빌 접촉면 청결 유지 |
| 런아웃 | 다이얼 게이지 + V블록 또는 척 고정 | 0.001 mm | V블록 정도 영향 큼 |
| 진원도 | CMM | 0.0001 mm | 고정밀 요구 시 |

### 4.2 사내 치수 허용 기준 (경험값)

> 사내 확인 필요 — 아래는 일반 공구 연삭 기준 추정값. 실측 후 갱신 권장.

| 공구 유형 | OD 공차 | 런아웃 공차 | 신뢰도 |
|---|---|---|---|
| 재연마 공구 (일반) | ±0.005 mm | < 0.010 mm | 추정값 |
| 재연마 공구 (정밀) | ±0.003 mm | < 0.005 mm | 추정값 |
| 신품 제작 | 도면 지정 | 도면 지정 | — |

> ⚠️ 위 수치는 추정값입니다. 실측 데이터로 갱신 필요.

### 4.3 측정 시 주의 (현장 빈출 오류)

- ⚠️ **열 팽창 측정 오류**: 가공 직후 측정 금지. 상온(20±2°C) 냉각 후 측정. [STD-ISO2768]
- ⚠️ **측정력 불일치**: 마이크로미터 래칫 반드시 사용. 손힘으로 조이면 오차 발생.
- ⚠️ **기준면 오염**: 측정 전 공구·게이지 접촉면 에어블로우 필수.
- ⚠️ **런아웃 측정 위치**: OD 최대 직경부에서 측정.

## 6. 예방 체크리스트

공구 연삭 세팅 시:

- [ ] 스핀들 예열 (10~15분 공회전)
- [ ] 콜릿 청소 (에어건 + 린트프리 천)
- [ ] 런아웃 측정 (< 0.010 mm 확인)
- [ ] L/D 비율 확인 (< 4 권장)
- [ ] 첫 가공 후 치수 측정 — 보정값 적용 후 양산
- [ ] 드레싱 주기 확인 (전 작업에서 드레싱 후 경과 공구 수)
