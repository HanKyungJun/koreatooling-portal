## 1. 표면조도 측정 기준 ★★★

### 1.1 주요 파라미터 (ISO 4287:1997)

| 파라미터 | 정의 | 한국어 |
|---|---|---|
| **Ra** | 산술 평균 거칠기 — 평가 길이 내 프로파일 편차의 절댓값 평균 | 산술평균 |
| **Rz** | 최대 높이 — 평가 길이 내 최대 산-골 차이 (5구간 평균) | 최대 높이 |
| **Rmax** | 단일 평가 구간 내 최대 산-골 차이 | 최대 |
| **Rq (RMS)** | 제곱평균 거칠기 — 노이즈에 더 민감 | RMS |
| **Rsm** | 평균 산-골 간격 | 평균 주기 |

> Ra는 가장 흔히 쓰이지만 **방향성·국부 결함을 평균이 가려버림**. Rz·Rmax를 병기해야 드래그마크·미세 파손 같은 국부 결함이 드러납니다 [출처: ISO 4287:1997 §4].

### 1.2 측정 절차 (ISO 4288:1996)

| 항목 | 기준 |
|---|---|
| Cut-off (λc) | 표면 종류·기대 Ra에 따라 0.08 / 0.25 / 0.8 / 2.5 / 8 mm |
| 평가 길이 (ln) | 일반적으로 5 × λc |
| 측정 횟수 | 최소 1회, 변동성 큰 경우 평균 3회 |
| 측정 방향 | 가공 방향에 **직각** (가장 큰 거칠기 검출) |

### 1.3 신표준 — ISO 21920 (2021~)

ISO 21920 시리즈는 ISO 4287/4288을 **단계적 대체** 중. 변경점:
- 면적 거칠기(Areal, S-parameters) 통합
- 측정 기기 종류별 절차 명시화
- 평면 형상 + 거칠기 동시 평가

> 현재 위키는 ISO 4287 기준 유지. 사내 측정기 사양에 따라 추후 ISO 21920 이행 검토.

## 2. 불량 유형 Taxonomy ★★★

연삭면에 나타나는 표면 불량을 5가지 유형으로 분류:

| 유형 | 외관 특징 | 주 원인 | 1차 조치 페이지 |
|---|---|---|---|
| **버닝 (Burning)** | 갈색·청색 변색, 산화 흔적 | 원주속도 부족, 글레이징, 쿨런트 불량 → 열 집중 | [[연삭-이론-근거]] §4 |
| **드래그 마크 (Drag Mark)** | 진행 방향 줄무늬, 광택 불균일 | rubbing 모드 진입, Feed 역전 구조 | [[연삭-이론-근거]] §1 |
| **채터 마크 (Chatter Mark)** | 규칙적 진동 무늬, 등간격 | 휠 밸런스 불량, 강성 부족, 회전수-고유진동수 일치 | (별도) |
| **글레이징 (Glazing)** | 휠 표면 광택 → 절삭력 상실 → 광택성 가공면 | Self-dressing 실패 (Feed/원주속도 부족) | [[연삭-이론-근거]] §4 |
| **플로잉 마크 (Plowing Mark)** | 깊은 긁힘·이형 패턴 | 단일 큰 입자 박힘, 쿨런트 칩 배출 불량 | (별도) |

### 2.1 버닝 ★★★

**외관**: 갈색→청색→흑색 산화 변색. 광택 사라짐. 미세 마이크로 크랙 동반 가능.

**메커니즘**: chip thickness가 minimum undeformed chip thickness 미만일 때 rubbing 모드 진입 → 접촉시간 길어짐 → 마찰열 집중 → 표면 산화·미세 변태층 형성 [출처: [[연삭-이론-근거]] §1, §3 / Malkin & Guo 2008].

**진단 체크**:
- 원주속도 < 20 m/s? → ★ 가장 흔한 원인
- 쿨런트 노즐 방향·압력 정상? ([[연삭-이론-근거]] §6)
- 휠 글레이징 상태? (휠 표면 광택 육안 확인)
- Feed 너무 낮음? (SGE 급증 — [[연삭-이론-근거]] §2)

**조치 우선순위**:
1. 원주속도 25 m/s 이상으로 확보 (RPM↑ 또는 휠 직경 확인)
2. Feed 10% 단계로 상향 (ANCA 공식 권장)
3. 드레싱 즉시 실시
4. 쿨런트 노즐 위치 재조정 ([[연삭-이론-근거]] §6)

### 2.2 드래그 마크 ★★★

**외관**: 진행 방향 줄무늬. 광택 불균일. 깊이는 보통 미세 (수 μm)지만 Ra/Rz 측정 시 검출.

**메커니즘**: rubbing/plowing 비율이 높을 때 입자가 깎아내지 못하고 표면을 밀어내며 발생. SGE 모델의 plowing 성분이 우세한 상태 [출처: [[연삭-이론-근거]] §1, §2 / MDPI Diamond Wheel Hub].

**진단 체크**:
- 원주속도 부족 (가장 흔함)
- Feed 역전 구조 — 중간 구간이 진입·마무리보다 낮은가? ([[연삭-이론-근거]] §5)
- 휠 로딩 — 부하계 낮은데 표면 불량 동시 발생? ([[연삭-조건-기록]] §4)

**조치**:
1. RPM 상향으로 원주속도 25 m/s+ 확보
2. Feed 구조 확인: 진입 ≤ 중간 ≥ 마무리 (중간 최대)
3. 드레싱 후 즉시 개선되면 → 로딩이 원인
4. 그릿 변경 검토 (#400 → #325 — 로딩 취약성 ↓)

### 2.3 채터 마크 ★★☆

**외관**: 규칙적·등간격 진동 무늬. 종방향 또는 횡방향 패턴. 청각적으로 고주파 비명 동반.

**메커니즘**: 시스템 강성 불충분 → 가공 중 자력 진동 발생 → 휠-공구 간 변동 접촉. 회전수가 시스템 고유진동수와 공진할 때 가장 심함 [출처: Inasaki, I., Karpuschewski, B., & Lee, H.S. (2001). Grinding chatter — Origin and suppression. *CIRP Annals*, 50(2)].

**진단 체크**:
- 가공 음(noise) — 일정한 비명?
- 휠 정적 밸런스 — 드레싱 직후에도 진동?
- 클램핑 — 콜릿·척 토크 정상?
- 회전수 변경 시 (5~10%) 무늬 변화?

**조치**:
1. 휠 동적 밸런싱 (필요 시 자동 밸런서)
2. 회전수 5~10% 변경 — 공진 회피
3. 클램핑 점검·재토크
4. 드레싱 (휠 형상 균일화)
5. 시스템 강성 점검 (장기 — 베어링·하우징 마모)

### 2.4 글레이징 ★★★

**외관**: 휠 표면 광택. 가공 후 공구 표면은 광택성이지만 정확한 형상 미형성, 절삭력 상실.

**메커니즘**: grain load 임계치 미달 → 다이아몬드 입자 탈락 안 됨 → 입자 위에 본드재가 덮임 → 절삭 불가 → 마찰만 발생 [출처: [[연삭-이론-근거]] §4 / ANCA 공식 / Eagle Superabrasives].

**진단 체크**: 부하계 낮음 + 버닝 동시 발생 = ★ 글레이징 강력 의심
- 휠 표면 광택? (육안)
- 드레싱 후 즉시 개선?
- Feed 너무 낮음?

**조치**:
1. 즉시 드레싱
2. Feed 10% 단계 상향 (ANCA 권장)
3. 만성 글레이징 → 그릿 변경 검토 (#400 → #325)

### 2.5 플로잉 마크 ★★☆

**외관**: 깊은 단일 긁힘 또는 비규칙적 깊은 자국. 한 방향이 아닌 산발적 분포.

**메커니즘**: 단일 큰 입자 박힘 (휠 dressing 불량 또는 입자 비정상 노출) 또는 칩 재배출 불량으로 가공면에 끼임 [출처: ScienceDirect: Resin Bond Diamond Wheel Dressing 연구].

**진단 체크**:
- 휠 외관 비정상 입자 돌출?
- 쿨런트 압력 정상?
- 드레싱 직후 재현?

**조치**:
1. 휠 재드레싱 (입자 균일화)
2. 쿨런트 압력·노즐 조정 (칩 배출)
3. 휠 검사 — 본드 균열 시 휠 교체

## 3. 진단 의사결정 트리

```
표면조도 불량 발생
   │
   ├─ 변색 있음? ──── Yes → 버닝 (§2.1) → 원주속도 측정
   │                                       │
   │                                       ├─ < 20 m/s? → RPM 상향
   │                                       └─ > 20 m/s? → 쿨런트·드레싱 확인
   │
   ├─ 진행방향 줄무늬? ── Yes → 드래그 마크 (§2.2) → Feed 구조 확인
   │
   ├─ 규칙적 진동무늬? ── Yes → 채터 (§2.3) → 회전수 변경 테스트
   │
   ├─ 휠 광택 + 부하 낮음? ── Yes → 글레이징 (§2.4) → 즉시 드레싱
   │
   └─ 깊은 단일 긁힘? ── Yes → 플로잉 (§2.5) → 휠 검사
```

## 4. 측정·점검 방법

### 4.1 표준 측정 장비

| 장비 유형 | 측정 가능 파라미터 | 적용 |
|---|---|---|
| 접촉식 (Stylus) | Ra, Rz, Rmax, Rq | ISO 4287 표준 |
| 비접촉식 광학 (Confocal/Laser) | 면적 거칠기(Sa, Sz) 포함 | ISO 21920 적용 가능 |
| 휴대용 거칠기계 | Ra 위주 | 현장 빠른 점검 |

### 4.2 측정 시 주의 (현장 빈출 오류)

- ⚠️ **측정 방향 오류**: 가공 방향과 평행하게 측정하면 거칠기 과소평가. **항상 직각** 측정.
- ⚠️ **Cut-off 부적절**: 표면 종류에 안 맞는 λc 선택 시 결과 왜곡. ISO 4288 §4 참조.
- ⚠️ **국부 결함 누락**: Ra만 보면 평균이 가려버림. Rz·Rmax 병기 권장.

## 5. 해결 기록 (사내 데이터 누적)

> 각 케이스 발생 시 [[연삭-조건-기록]] 폼으로 상세 기록 후, 핵심 결과만 아래 표에 요약:

### 5.1 기록 가이드

**증상 선택지** (§2 참조, 복수 선택 가능):
- 버닝 / 드래그마크 / 채터마크 / 글레이징 / 플로잉마크 / 치수불량 / 기타

**Ra 단위**: μm (마이크로미터)
- 일반 정삭 목표: 0.4~1.6 μm
- 거친 가공 허용: ~3.2 μm
- 거울면 마감: < 0.2 μm

**진단 분류** (§2 메커니즘 참조): 원주속도 부족 / Feed 역전 / 글레이징 / 진동 / 휠 입자 비정상 / 기타

### 5.2 케이스 기록표

> [2026-06-01] 아직 누적 케이스 없음. 불량 발생 시 아래 양식에 바로 추가.
> 장비 컬럼: **F** = 장비 1번 (Ø2~Ø8), **G** = 장비 2번 (Ø10~Ø20)

| 날짜 | 장비 | 공구·소재 | 증상 | 측정 Ra (μm) | 진단 | 조치 | 결과 Ra | 신뢰도 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

> 행 더 필요하면 빈 행을 복사해서 추가.
>
> 기재 예시 (실데이터 아님):
> `2026-06-XX | F | D6 4날 초경 | 버닝 | 1.8 → 목표 0.8 | 원주속도 18 m/s 부족 | RPM 3,200→3,850 + 드레싱 | 0.7 | 사내 경험값`

### 5.3 누적 데이터 활용 (장기)

- 6개월 이상 데이터 누적 시 빈도 분석으로 회사 특화 진단표 추출 가능
- 가장 빈번한 (증상 × 원인) 조합 → 우선 점검 체크리스트로 격상
- 조치 효과 비교 → 표준 작업 절차(SOP) 후보 도출
