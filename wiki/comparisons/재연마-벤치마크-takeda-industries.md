## 3. ANCA FX5 Linear 도입 효과

### 3-1. 생산성

| 항목 | 도입 전 | 도입 후 |
|------|---------|---------|
| 생산량 | 기준값 | **수배 이상 증가** |
| 야간·휴일 운전 | 불가 | ✅ 무인 연속 운전 달성 |
| 공차 관리 | 작업자 수동 | LaserUltra 자동 보정 |

### 3-2. 핵심 요인 분석

**LaserUltra 자동 보정:**
- 공구가 공차 이탈 시 자동 보정값 적용
- 야간·휴일에도 품질 유지 가능 → 무인 운전의 전제 조건
- Takahashi 사장: "게임 체인저(game-changer)" 직접 평가

**Simple Loader:**
- 기본 탑재 로봇 로더
- LaserUltra와 결합 → 완전 무인 운전 사이클 완성

**축 이송 속도:**
- Linear 드라이브 → 기존 볼스크루 대비 빠름
- 특히 홈(groove) 가공 속도에서 차이가 큼
- 근거리 정밀 축 이동 → 반복 정밀도 향상

## 4. 사업 모델 진화 경로

```
인서트 팁 재연마
    ↓ (네트워크 확장)
샤프트 공구(엔드밀) 재연마 전문화 (2000년대 초)
    ↓ (대기업 요청 — 스트레이트 엔드밀에 코너R 추가)
엔드밀 제조 진입
    ↓ (ANCA FX5 Linear 도입, 2022-12)
재연마 60% + 제조 40% 병행 체계 완성
    ↓ (현재)
대기업·중소 복합 고객, 월 재연마 2,000개 + 제조 800개
```

**TOOLKOREA 시사점:**
- 재연마 전문 역량이 제조 진입의 신뢰 기반
- 핵심 전환점: 대기업 수정 요청(코너R 추가) → 제조 라인 확장
- 자동화(무인 운전) 없이는 현재 수량 달성 불가
