## 1. 테스트 개요

D20 인덱서블 T드릴(Indexable Drill) **중국 제조사 6종 + 코리아테크닉스 1종** 비교.  
품질관리팀 치수 측정(편심량·인경·런아웃·경도) + 3차 가공 테스트 병행.

**신뢰도:** 치수 측정 — 실측 검증 (품질관리팀) / 가공 테스트 — 사내 경험값

## 4. 가공 테스트 조건

| 항목 | 값 | 신뢰도 |
|------|-----|--------|
| 장비 | CHEVALIER QP2040L | — |
| 피삭재 | S45C / HRC 20~25 | — |
| Vc (m/min) | 180 (1차) → 198 (2차) → 200 (3차) | 사내 경험값 |
| fr (mm/rev) | 0.08 (1·2차) → 0.09 (3차) | 사내 경험값 |
| N (rpm) | 2,850 | 사내 경험값 |
| Vf (mm/min) | 230 | 사내 경험값 |
| 가공 깊이 | 3D: 53mm / 5D: 98mm (관통홀 18mm·60mm) | — |
| 쿨런트 | 미확인 | — |

### 절삭속도 계산 (검산용)

```
Vc = π × D × N / 1000
   = π × 20 × 2,850 / 1000 = 179.1 m/min  ≈ 180 m/min (1차)  ✓
```
